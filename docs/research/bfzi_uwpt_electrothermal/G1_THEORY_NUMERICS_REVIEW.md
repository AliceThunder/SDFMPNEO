## 2. 固定物理模型和基本弱式

令 B1、B2 为不相交的旋转实心绝缘盒，Ω∞=R³ \ (B1∪B2)，σ_s>0、μ=μ0，时间约定 exp(+jωt)。完整闭合端口线源的单位势为

A_src,p(x)=μ0 C_p(x)，其中 C_p(x)=(4π)^(-1)∮_{Γp} dl'/|x-r'|。

在海水：J=σ_s E，E=−jω(A_src + μ0 G0 J)−∇φ，div J=0；在两封装边界 n·J=0。电流空间 V 的试探、测试均满足连续性和物理法向边界。将电流方程乘 v 并积分，利用 **div v=0 和恰当的完整边界迹** 消除 φ：

a(J,v)=∫Ω σ_s^(-1) J·conj(v) dV + jωμ0∫Ω (G0 J)·conj(v)dV = −jωμ0 Σp Ip∫Ω C_p·conj(v)dV。

实值合规电流基 Wm 形成

Rmn=∫ σ_s^(-1) Wm·Wn，Lmn=μ0∬ Wm(x)·Wn(y)/(4π|x-y|)，Kmp=μ0∫ Wm·C_p，

(R+jωL)z=−jωKI，Z_sw=ω² Kᵀ(R+jωL)^(-1)K。

当 R≻0、L⪰0、K 实、源闭合及积分定义一致时，Z_sw=Z_swᵀ、Herm(Z_sw)⪰0，且 0.5 Iᴴ Herm(Z_sw) I=0.5 zᴴ R z=∫|J|²/(2σ_s)。**这只是代数结构，不是离散解对真实解的准确性保证。**

### 关键假设不能省略

- MQS 需要相关长度下传播效应小、导体内位移电流相对导电电流小；材料、频率和源连续性满足模型适用条件。Ammari–Buffa–Nédélec (2000) 明确研究了涡流近似的源兼容条件和拓扑依赖。
- 海水被假定均匀、各向同性、非磁性；有磁芯、导电屏蔽、介质色散或海水显著流动的情况，不能简单沿用该基线。
- 完整线圈和回流路径必须是同一个有向闭合电流。现有 LineSource 以 Gauss 线元加权和逼近 C 和 B；对**离散**势有 B=μ0 curl C，但这不等于离散线源在分布意义下自动严格无散度。必须做源阶次、总加权线元闭合误差、源磁场与线源精确解析基准核查。

## 3. 三个最重要的理论／算法缺口

### G1-A：人工外边界与无限海水被混淆

人工有限球 Ω_R 上令 n·J=0，可得到一个数学自洽但**不同于无限海水**的边值问题。当前 basis 的边界包络还常常令球面 J 整体等于零，限制强于零法向条件。对 R 的加大同时改变包络和求积：不能把两个计算解之间的差视为纯粹外边界误差。默认场景 f=200 kHz、σ_s=5 S/m 时海水趋肤深度约 0.503 m，旧球半径尚不一定足够大。

需要区分：(i) 固定有限人工绝缘边界的真解；(ii) 采用正确磁场/电流边界迹与外区非局部 DtN 或边界积分耦合后的无限域解；(iii) 同一个连续问题的数值离散。已实现的单一球谐外推并未实现 (ii) 的内外双向耦合。**不得用一项环向 l=1 或 l=2 外推成功代表双盒透明边界认证。**

### G1-B：电流空间合规 ≠ 完备 ≠ 响应收敛

若 F∈H(curl) 且 n×F=0，则 J=curl F 能满足 div J=0 和 n·J=0。盒体距离因子、Wendland 方向基和 Piola 映射都是合理的**构造方法**，但没有建立其稠密性、统一几何稳定性和模态筛选误差证明。有限字典 whitening 进一步可能因为当前求积下小 R 特征值而丢弃正确但欠分辨的方向。

两只拓扑为实心球的绝缘盒在三维中的外部补集并不会仅因有两只盒而自动产生一阶拓扑谐和环流；真实缺失仍可能是普通的大尺度和盒间电流。必须固定物理域及一致矩阵求积，比较严格嵌套的空间加密；旧 207→229 与 27→71→211 都未形成连续参考误差证书。Hiptmair (2002) 对符合微分形式结构、逼近稳定和收敛的区分有严格论述。

### G1-C：Coulomb 磁能双积分的数值一致性未成立

真实 L 是带核 1/|x−y| 的六维体积分。uniform-ball 规则把每个正权重节点当作有限球形电流云；节点权重不是球体积单元的几何证据。该规则即使保持 L 的半正定，也无法证明与原 Coulomb 核积分相合。

**最直接的文献证据：** Passarotto–Pitassi–Specogna (2022), CMAME 392:114626，明确指出用不相同内外积分规则直接计算磁电感矩阵的对角块可能不稳定且误差非常大，并提出奇异项提取／快速分解。我们的 x/y 分别加密出现 11% 量级变化和明显非加性，恰恰应首先按“同一物理 L 核对角块的数值计算失控”排查，而不是继续增加基或不断换采样规则。该论文方法使用多面体电流空间，**不能直接声称已给出完全无网格 BFZI 的收敛定理**。

下一版需要对固定低维解析电流 W，独立建立含精确自项和邻近项的原 Coulomb 参考：可从核奇异性减除、局部球坐标、Duffy 型变换或高阶体积分奇异提取入手。Järvenpää–Taskinen–Ylä-Oijala (2003) 和 Duffy (1982) 是对应数值分析依据。**关键是对相同电流场验证原核真值，不是设计另一个恰好正定的替代核。**

## 4. 关于两种 K 弱式：它们是诊断，不是两个任意答案

对 W=curl F，利用旋度分部积分：

∫Ω (curl F)·C = ∫Ω F·(curl C) + ∫∂Ω (n×F)·C。

若两绝缘边界及人工边界 n×F=0，且 B_src=μ0 curl C，则

Kmp=μ0∫Ω Wm·C_p=∫Ω Fm·B_src,p。

因此源核的两种公式在**相同连续域**上严格等价，7% 或 20% 的离散差异是积分（或源场离散一致性）问题的强烈警告。由于当前 LineSource 的磁场核是对应离散 C 核的解析 curl，这尤其指向体积分的欠分辨。人工 sphere/shell 子域上若分别比较，必须包含彼此抵消的分区边界项；只能对完整湿区比较两式。

新建 QMC 只是另一种正权重积分规则，不具有天然准确性证书。独立 scramble、点数加倍以及 R/K 一致仅提供差异观察；强局部边界层、角部低正则性和 Coulomb 近奇异核均可能让采样结果长期振荡。随机扰乱区间不是原 L 或连续解的严格误差界。

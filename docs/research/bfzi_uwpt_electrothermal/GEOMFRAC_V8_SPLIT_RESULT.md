## 5. 决策与下一步

1. **保留 V7 为正式推理模型。** V8 候选不默认启用。
2. 保留 V8 的冷铜阻抗显式分解，作为下一阶段热源预测的新基线。
3. 下一轮优先改善温升/自阻抗切线匹配：
   以 V8 热源驱动下的自主热状态训练/校准切线，重点关注 TX/RX 自阻抗，
   并保留冷态 V7 总阻抗精度作为联合训练目标。
4. 新几何独立动态测试需要预先冻结，历史六组仅用于诊断。
5. V8 可选在线入口支持 `--cold-model runs/geomfrac_cold_v8_split.pt`，
   V7 默认仍使用 `runs/geomfrac_cold_v7.pt`。

# V11 — 双端口均衡的冷态电路与损耗约束训练

日期：2026-11-21。代码：`examples/bfzi_cold_v11_train.py`；冻结候选：`runs/geomfrac_v11_cold.pt`；开发集结果：`runs/geomfrac_v11_cold_summary.json`。本版本延续《GEOMFRAC_V10_ERROR_AWARE_TRAIN.md》中的独立模块预训练、物理一致接口和真实闭环选模路线。在线架构、参数量、热算子与电磁温度映射保持原 V8。

## 出发点

V10 在上一批4组全新BFZI V150几何8条历史上，使总体动态复阻抗10.6601%→10.4623%，但RX R22 14.2712%→14.9050%、电流1.0981%→1.1536%、铜海水功率也退化，未晋级。前一版本ColdNet训练以端口电流总范数为主，TX强响应可能掩盖RX相对误差；单纯提高平均电流精度不足以保证每个端口和各材料损耗的泛化。

## 方法

不改变原`ColdNet` 13输出结构，训练损失由已有物理9分量阻抗、4分量铜阻抗与电路敏感度外，加入三项真实BFZI电路约束：

1. 分别归一TX/RX端口电流误差，防止TX主导范数。对RX电流误差最高四分位增加训练权重；归一化在RX低耦合时加入`0.05|I_TX|`物理规模下界。
2. 对完整冷态TX/RX自阻抗的R11、X11、R22、X22施加损失，显式重建海水电抗加空气电抗，避免只拟合分量拆分而忽略电路真正感受到的自电抗。R22权重略增。
3. 使用完整两端口复电流计算物理损耗：
```text
Zsea = Ztotal - i*omega*Lair - diag(Zcu)
Psea = 0.5 * Re(Iᴴ Re(Zsea) I)
Pcu,j = 0.5 * Re(Zcu,j) * |Ij|²
```
同时监督海水焦耳损耗和TX/RX铜损，避免更好的电流预测转移成更大的材料热源误差。少数缺铜标签的训练几何仅跳过铜/功率损失，仍参与自阻抗及电流训练。使用1500组训练几何、228组冷态开发几何和226组独立冷态测试几何。

### 开发选择

对228组冷态开发几何，选择目标包含冷态Z、电流均值与P90、TX/RX分别归一电流、R22自电阻、铜/海水功率。要求各主要分项相对初始模型不退化超限，才可保存相应检查点。训练后另用15组几何41条完整物理历史的自主闭环评估；不使用以前的V9B/V10B物理盲测作V11参数选择。

有两种初始化实验：

- A 从V8 ColdNet训练70轮，最佳epoch40；226组冷态测试误差Z0.13787%、电流1.70788%、海水功率1.91907%，完整闭环开发动态Z15.94883%、电流8.44815%、材料温度RMSE0.43592K。报告`runs/geomfrac_v11_cold_a.json`。
- B 从未晋级的V10 ColdNet初始化，均衡损失权重`(Z,Cu,I,selfZ,P,sens)=(1,.2,1.2,.5,1,.1)`，学习率2e-5、50轮、最佳epoch5。226组冷态测试Z0.13461%、电流1.65385%、海水功率1.87918%。完整15组几何41条历史开发动态Z15.91200%、R11 15.45765%、R22 20.43765%、电流8.30598%、均温RMSE0.43841K、海水功率15.80422%、铜功率15.79913%。**选择B作为新物理验收候选**；报告`runs/geomfrac_v11_cold.json`，权重已冻结提交。

与正式V8基线相比，B的15组闭环开发动态Z16.23210→15.91200%、RX R22 20.72770→20.43765%、电流8.61544→8.30598%、均温RMSE0.45211→0.43841K、海水功率16.47941→15.80422%。V10上轮开发动态Z15.78604%虽更低，上轮全新几何独立验收出现RX、电流和功率退化，本版优先改善端口均衡和物理损耗泛化。

## 冻结独立验收

`runs/geomfrac_v11_blind_plan.json`在物理参考生产前固定4组独立于动态训练和开发的几何，前2组采用g1外电路、后2组采用g2外电路。每组60s持续激励和300s切换激励，共8条BFZI V150 S5 ultra完整电磁热参考；训练/网络参数不因盲测结果变化。新物理历史不同于V9B、V10B；这些几何来自未参与冷态训练/开发的V7冷态测试池，已用于冷态聚合指标评价，因此几何级冷态评估和本次完整动态物理参考的独立性分别记录。

固定模型比较：正式V8 versus 仅替换ColdNet为V11-B（冻结热SOE、SkinTanV3、ParZ48和热算子）。指标包括冷态Z、动态复阻抗六分量及其自身归一误差、两端口电流、材料温度和铜/海水功率；新电路与几何的关键分项也需达到冻结晋级条件。运行`examples/bfzi_v11_blind_accept.py`，输出`runs/geomfrac_v11_blind_summary.json`。

## 盲测验收门槛冻结（2026-11-21）

在读取V11B物理参考结果前，验收脚本`examples/bfzi_v11_blind_accept.py`已补齐总体与逐几何双层门槛。模型仍只允许替换ColdNet，V8热SOE、SkinTanV3、ParZ48和热算子保持相同权重及配置。

总体指标要求：
- 动态复阻抗误差必须优于V8。
- 冷态复阻抗误差不高于V8的1.03倍。
- TX/RX自电阻误差不高于V8的1.02倍；TX/RX自电抗误差不高于1.03倍。
- 电流、材料均温RMSE、海水功率和铜功率误差不高于V8的1.03倍；材料最大温度误差不高于1.05倍。
- 两个模型的能量预算最大绝对误差均不超过`1e-8 W`。

逐几何门槛：
- 每组几何的冷态阻抗、动态阻抗、四项自阻抗、电流和材料均温误差不高于对应V8结果的1.10倍。
- 每组几何的材料最大温度误差、海水功率误差和铜功率误差不高于对应V8结果的1.15倍。
- 每组几何能量预算最大绝对误差不超过`1e-8 W`。

只有总体门槛和四组逐几何门槛全部通过，V11才标记为`blind_improved`。验收脚本同时输出每项门槛的布尔结果，便于直接定位未通过的指标。该门槛在V11物理参考数据生成期间冻结，不根据盲测结果调整。

## 3. 一键独立评估

```bash
python -m examples.bfzi_geom_free_v7_accept \
  --selection runs/geomfrac_free_v7_selection.json
```

入口 `examples/bfzi_geom_free_v7_accept.py` 在测试前强制核对：冻结几何与激励、各组唯一锚、18 个教师文件、每条物理历史 `candidate`、结束时刻，以及全部固定模型文件。随后调用 `bfzi_geom_free_eval` 的共享预测内核，不发生新几何冷态 BFZI 求解或新热基构造。

输出 `runs/geomfrac_free_v7_accept_raw.json` 和 `runs/geomfrac_free_v7_accept.json`，包括每条时程、各几何平均值和总体统计。指标：

1. **复阻抗**：冷态相对 L2、动态变化相对 L2、全时程相对 L2，并记录六个 TX/RX 端口电阻和电抗分量对动态总误差的贡献。
2. **电流与电功率**：复数 TX/RX 匹配电流的相对 L2 与最大绝对误差，海水损耗、铜耗的相对 L2。电流真值直接使用原 BFZI `currents_A`。
3. **五材料温度**：海水、TX 封装、RX 封装、TX 铜、RX 铜的材料均温 RMSE 和最大误差；原三维场节点上的整体 RMSE、最大误差，以及常规海水、海水薄层、双封装区域的误差。
4. **守恒与成本**：五材料热预算的最大残差；首次新几何预处理与推理时间、重复推理时间及物理真值生成时间。三维全节点重建单独计时并与在线 6 点查询区分。
5. **溯源**：原始冷态/动态阻抗误差、海水/铜源功率误差、五材料与区域温度误差互相对照，先确定主导误差再改进相应模块。

误差计算以 BFZI 的 60、300、600 s 实际物理输出为参照。动态阻抗采用 `(Z(t)-Z(0))` 的六分量 L2 相对误差，防止完整冷态阻抗掩盖热反馈误差。

# BFZI V150 电磁热物理直接法最终验收 V1

2026-11-14。最高优先级：物理直接法最终验收；神经代理暂缓。将热参数作为**工况输入**，不以拟合某一固定材料常数作为验收前置条件。

## 1. 冻结被验收对象

BFZI V150 原生电磁复阻抗 + 铜损/海水损耗 + 三维铜/封装/海水热演化 + 温度反馈。输入为线圈连续圆角方形/圆形几何、位姿、封装尺寸、端口电压波形、介质反馈参数、热参数。热参数包括绝缘有效热导 `ins_k`、绝缘厚度 `ins_t`、封装热导 `pkg_k`、封装—海水界面换热 `pkg_sea_h`、热皮层厚度 `skin_m`。命令行默认值保持向后兼容，独立案例的 `thermal` 字段可覆盖这些值。后续将海水热导与体积热容也开放为工况输入。

## 2. 验收矩阵与独立性

既有 F12、F14P、F16P、F23P 为**开发/收敛验证组**，不可重复计作新的盲测样本。新增至少 **12 个冻结未见工况**，包括圆形、连续过渡圆角方形、不同错位/倾斜/旋转、不同封装尺寸、至少三档功率与不同通断电时序。热参数至少覆盖绝缘热导低/中/高、封装热导低/高、界面换热低/高，并包含组合变化，禁止仅单参数扰动。使用独立随机种子生成并一次性冻结工况清单；不得根据计算结果反复筛选容易通过的样本。

高功率工况须完整 600 s，采用物理有效的通电占空比；若超出单相海水/固态铜物性域，记录越界时间、温度和能量，不得标为通过。报告全部样本，含失败样本。

## 3. 每个样本验收门槛

- **物理有效**：完整规定时程；海水 271.15–373.15 K、铜温 <1357.77 K；所有温度/阻抗/功率有限。
- **电功率**：端口输入与海水、铜、引线、外电路功率总和相对差 ≤1e-10；海水端口功率与空间焦耳损耗相对差 ≤1e-10。
- **热能守恒**：最大热节点及全局功率残差 ≤1e-4 W，水热皮层热容量守恒。
- **时间收敛**：同一网格实际热步 1.875 s/1 s，动态复阻抗相对 L2 ≤1%，铜/封装全程最大温差 ≤0.5 K。
- **空间收敛**：原生湿 FV 2668/3729（随几何实际计数记录），动态复阻抗相对 L2 ≤2%，铜温度 ≤1 K、封装温度 ≤1.5 K。
- **四组合交叉**：两个网格 × 两个真实热步均完整，时间与空间两方向在两档配置均通过。时间比较必须使用同一输出时刻；比较不可仅使用有效前缀。
- **动态过程**：通断电瞬间响应、电阻与电感变化、断电后热扩散应记录全时程曲线与峰值时刻。

验收通过定义：12/12 冻结样本均满足以上要求；若存在不通过样本，报告根因并修复物理/数值实现后重新运行**原冻结样本全集**。验收指标不因失败而放宽。

## 4. 执行顺序

1. 锁定案例生成器、热参数输入与电磁/热守恒诊断；完成局部单元测试。
2. 运行 12 组原生 ultra 网格、实际热步 1.875 s 的完整时程，记录全部异常。
3. 对全体样本运行 1 s 时间对照和 superfine 空间对照，完成四组合。
4. 汇总样本级判定、误差分布、最大误差样本及材料/功率/几何覆盖；将 JSON、验收表和复现命令提交仓库。
5. 全部闭合后冻结物理直接法参考版本，再推进神经代理。

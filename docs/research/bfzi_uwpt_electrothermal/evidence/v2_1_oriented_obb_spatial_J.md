## 1. 发现及物理修正

此前 P03、P07 原姿态的两个**实际旋转封装实体发生相交**；原 BFZI 海水体积构造使用旋转封装的世界轴对齐包围盒(AABB)及其他装配空腔，而五材料三维热模型使用真实定向封装盒(OBB)。两个几何所代表的湿体积并不一致。原始 P03/P07 可继续衡量对**既定离散模型**的代理逼近精度；要验证真实空间物理，应先使用无相交封装与统一排水边界。

新增 `sdfmpneo_bfzi/sea_obb.py`：重用原 BFZI V150 完整笛卡尔海水 FV 网格、Green/GMRES、源项投影与双端口，沿每只封装的6个世界空间平面把原立方 FV 切为凸多面体湿区；使用正体积四面体积分权重重建 FV 湿体积、质心与源/Green 空间积分记录，保留全湿单元原2阶高斯积分。对两只旋转封装进行 OBB 碰撞检测，要求封装与水箱边界相容；明确排除额外干式竖管与非物理扩展 AABB。参数入口：

```powershell
python -m examples.bfzi_param --bfzi-root D:/work/bfzi-et-v2.1/BFZI --sample M4 --sea-void oriented --pkg-sea-model face-resistance --sea-tangent-rank 6 --sea-tangent-cold-subspace
```

新模式仅替换**海水排水的体积几何**，电磁求解公式及分数阶神经网络保持 BFZI V150 原架构。原 `--sea-void aabb` 默认保留。没有为新几何训练使用 P03/P07 的动态真值。

M4 轴对齐封装控制实验：AABB 与 OBB 水单元数均384、总体积一致，冷态复阻抗相对差 `0.003857%`。OBB多面体解析几何裁剪及正体积积分测试通过。P03 572单元时总海水体积相对几何残差为 `9.59e-7`；P07残差约 `3.37e-15`。

P03/P07 为消除原封装实体相交，分别对接收端增加 `16.8131mm`、`30.6017mm` 的世界 y 方向位移（包含5mm预留间隙），然后**分别重建原 BFZI 的电磁 Green、端口、热 FV 与动态直接法**。以下所有直接法/代理测试均对应新的、不相交的物理几何，不沿用旧几何的热真值。

## 4. 零新增动态 BFZI EM 的三维电流 J 空间改进

原代理的海水单位端口电流形状来自冷态 BFZI 场：`J_base(x,T)=J_cold(x)*sigma(T)/sigma_0`。只按局部电导率缩放，忽略温度变化引起的全空间电势再分布。

新增 `GeomHeat.corrected_J`，保存原 BFZI 冷态 FV 投影矩阵 `B`、物理导纳权重和邻接边。对冷态原单位电流场对应的 `P0=J_cold/(-j omega mu sigma_0)`，计算：

```text
P_corr(T) = P0 + Project_sigma(T)(P0) - Project_sigma0(P0)
J_corr(T) = -j omega mu sigma(T) * P_corr(T)
```

两次投影差使 `T=ambient` 时冷态单位J**完全不变**；任意温变采用一个稀疏标量FV电势投影，避免新的 BFZI Green/GMRES 电磁求解。之前直接重新投影冷态P0会破坏冷态J；此处的冷态扣除是实算选定的物理一致实现。该物理投影只作用于**最终 J 输出**，热源仍使用经双端口海水损耗归一化的原弱式 q。经真实原 BFZI 温变场对照，直接用 `|J_corr|²` 缩放q会降低q精度，因此目前保持已有q计算。

| 完整自主代理末次通电时刻 | 原冷态J局部温度缩放，体积加权误差 | FV电荷守恒增量投影后J误差 | 动态代理耗时原/新 |
|---|---:|---:|---:|
| P03 115V | 0.064766% | **0.012306%** | 0.098 / 0.198 s |
| P07 150V | 0.255520% | **0.052502%** | 0.230 / 0.493 s |

对真实温度和真实端口电流固定比较的空间J误差分别为 P03 `0.06487%→0.01235%`、P07 `0.25667%→0.05260%`，排除了温度预测/端口误差。端口Z与热源q在开启J修正前后完全一致，`qsea_W_m3` 最大差为0，`z6` 最大差为0。新方法仍比对应原BFZI完整动态直接法快约21～22倍。

新模式采用 `rom.rollout(..., correct_J=True)` 显式启用；默认 `False` 保持既有推理速度和存量锚文件兼容。新生成的 `GeomHeat` 锚保存原BFZI FV投影结构，旧归档锚无投影时沿用原J计算。

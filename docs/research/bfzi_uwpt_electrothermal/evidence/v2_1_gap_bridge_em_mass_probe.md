# BFZI V150：真实封装窄间隙热桥与温变电磁近源积分一致性

日期：2026-11-14  
分支：`research/bfzi-uwpt-electrothermal-surrogate`  
状态：**P03/P07 实际 BFZI V150 直接法与网格诊断均已完成；既有高精度默认保留。**

## 一、研究目标与工况

继续前轮真 OBB 排水、572/1312 原生海水FV、1312精确湿面面积、物理不相交的双倾斜独立封装、600s高功率直接法。P03采用115V，P07采用150V/15s通断工况；两个真实封装之间的最小物理水隙约5mm。现有2mm深、8层、8点体积守恒热层已将铜/封装温度跨网格误差显著降低，完整动态海水复阻抗增量差仍达约1%。本轮分两条独立路线检验：

1. 实际双封装面对面水隙是否需要直接导热支路；
2. 当海水温度场固定且与热算子无关时，原 BFZI V150 温变电磁阻抗自身的空间离散误差。

不使用P03/P07真值训练神经网络，不改变原BFZI Green/GMRES、端口及弱式焦耳热基本方程。

## 二、两封装面对面水隙的被动热桥

新增 `sdfmpneo_bfzi/gap_bridge.py`、`BFZIV148Skin3D(gap_bridge=True)`。对两个独立旋转盒实际外表面面片进行面积高斯采样，只在面片外法线与对侧表面相交、法向相向、间隙小于12mm时建立两个**最外侧海水热层状态之间的导热边**。每个连接的热导：

```text
G_gap = k_sea * A_overlap / L_eff
L_eff = D_faces - 2*skin_depth + thickness_outermost_skin_layer
```

导热边是对称、正系数、无源的，热流在两侧等量异号。面片已分配到热桥的有效面积按比例从该面片连至远场粗海水FV的热导中扣除，避免同一面积重复耦合。原FV水体热容量和焦耳热按先前的8点保守空间体积映射，保持不变。

两封装的5mm最小间隙仅在局部倾斜区域形成狭小的相向面片传热区域。这种几何下**真实直接间隙热桥的传热面积有限**，并非完整动态阻抗空间误差主因。因此新热桥是可选物理模式，不替换默认物理热层/封装界面。

## 三、固定空间温度场，直接测量原BFZI电磁网格误差

新增 `examples/bfzi_obb_em_grid_probe.py`。在572/1312湿FV网格上使用**完全相同的解析空间温度函数**，原 BFZI V150 分别求解同一5K温度扰动与各自293.15K冷态，再比较纯海水复阻抗增量：

```text
e_EM = || [Z_572(T)-Z_572(T0)]-[Z_1312(T)-Z_1312(T0)] ||
        / ||Z_1312(T)-Z_1312(T0)||
T(x) = T0+5K * exp[-distance(x,physical_OBB)^2/(2*ell^2)]
```

其中 `ell` 是相对于两个实际旋转封装表面的距离尺度。铜温度均固定，原热求解器与神经网络均不参与。

| 封装附近3mm | 66.63855% | 89.52060% |

这里测的是**物理温变阻抗增量**跨网格差，未将其与完整Z相对误差或神经模型误差混合。此独立实验明确表明：原 BFZI **电磁温度响应**即使在相同热场下仍有网格依赖，单独加密热网格不足以使物理直接法的动态阻抗收敛。

## 四、定位近源质量积分项与 Green 主响应的离散抵消

原 `BFZIV148Adapter.solve` 严格保持原BFZI复海水阻抗公式，其局部近源矩修正为：

```text
Z_sea = Z_Green + Z_mass
Z_mass = (omega*mu)^2 * sum_i sigma_i(T) * M_i
dZ_mass = (omega*mu)^2 * sum_i [sigma_i(T)-sigma_i(T0)] * M_i
```

因此可**无需额外电磁计算**从真实 BFZI 的温变Z中代数拆出 `dZ_Green` 与 `dZ_mass`。

在全海水均匀5K升温的原截断近源算法中：

| 原BFZI贡献项的572→1312变化 | P03 | P07 |
|---|---:|---:|
| 完整 `dZ_sea` 相对差 | 2.943% | 3.773% |
| `dZ_Green` 相对差 | 14.348% | 15.194% |
| `dZ_mass` 相对差 | 101.991% | 101.219% |

主项与近源矩部分互相抵消，局部源二阶矩修正具有较强网格敏感性。

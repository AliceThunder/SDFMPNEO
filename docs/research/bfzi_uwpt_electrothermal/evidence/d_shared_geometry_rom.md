# D 阶段：跨几何共享 32 阶热 ROM 与电磁温度灵敏度

日期：2026-11-14。严格使用《BFZI_MAINLINE_CLOSURE_V1》D 闭合指标：P03/P07 和一个额外圆形—圆角方形变化整几何留出，动态复阻抗增量相对 L2 ≤3%，铜/封装温度最大误差 ≤2 K，逐新几何离线成本相对 BFZI 冷场+热算子+8 电磁灵敏度基线减少至少 50%。

## 方案

新几何仅执行原 BFZI V150 的 **原生 Green FV 几何与一次冷态电磁求解**，其中温度源积分选用较快的 `legacy` 冷场掩码。由训练几何的真实 `subcell` 与 `legacy` 冷态差值形成六实分量冷态近源损耗修正；训练几何不包含任何留出几何的动态真值。新几何无热算子构建、无电磁温度微扰、无新训练。热 ROM（含守恒状态）、热源分布和六分量电磁切线全部从已训练几何共享。与 C 阶段相同，在线通过双端口电路、非线性铜损与隐式 32 阶热 ROM 完成电磁热因果闭环；推理时零次 BFZI Green/GMRES。温度场经近邻 FV 体积中心插值到目标的原生海水坐标，双封装/铜/热层保留本体索引。

新几何冷场属于实际物理预计算，不能算作零物理计算。精度验收目标是同一目标几何、驱动、介质、时间采样下的真实 BFZI V150 source-skin 物理时程。保存模型 `sdfmpneo_bfzi/geom_shared_rom.py`；构建训练几何数据入口 `examples/bfzi_d_donor.py`；留出和时间分项计量入口 `examples/bfzi_d_shared.py`。

### 训练/整几何留出

训练几何仅 G1 和 G2：其原 A2 真值已按既定配置生成，分别为 P03 额外 Y 平移 20 mm、P07 额外 Y 平移 25 mm。对训练几何分别建立五材料 `2406→32` 热 ROM 和 32 个原 BFZI 物理方向灵敏度，保存 G1/G2 的 `cold` 源掩码修正。P03、P07 整几何未参与 D 的供体构建、方向选择或模型拟合；其 600 s 原 BFZI V150 时程用于**最终验证**。G3 固定为另一个未见几何：发射端圆形 `alpha1=1,core1=0`、接收端圆角方形 `alpha2=0.88,core2=16 mm`、接收端盒 228 mm、额外 Y 平移 +10 mm、roll/yaw/pitch 增量 22°/6°/8°；首次按锁定 source-skin V150 物理方法重新计算 600 s、57.5 V 启停参考真值。P03/P07 的驱动与物理真值来自 A 阶段已归档 600 s 原始时程。3 个留出几何均与 G1/G2 训练集隔离。

## 闭合结论与下一项 E

P03/P07/G3 的完整动态 ΔZ、温度和离线总成本全数达到 D 的验收阈值，**D 关闭，不再增加跨几何调参**。受体保留一次原 BFZI 低成本冷态物理求解，共享热动态和切线；当前目标空间水体温度采用供体场插值，端口功率—目标坐标海水 q/J 场的统一能量约束与近源空间查询交给 E 阶段验收。SOE 分数阶/指数残差已在 C 阶段独立通过，D 采用无需动态再训练的**共享物理 ROM 通道**，消除 C 的单几何额外训练成本。该通道与 C 的可选记忆网络接口相容，D 的整几何留出精度由共享物理通道独立提供。

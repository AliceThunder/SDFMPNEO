# V2.1 原 BFZI 三维 J/q 在真实湿 FV 交集上的空间对照

日期：2026-11-14。真实 P03/P07 非相交旋转双封装、原 BFZI V150、572/1312 湿FV和2mm八层被动海水热层。沿用已保存的12条600s直接法空间J/q，不重新运行电磁热时程。

## 方法

先重新构建两级原 BFZI 原生真实湿FV几何。对任意一对相交矩形FV，复用 sea_obb._wet 对两真实旋转OBB封装进行多面体裁剪，构造精确湿体积交集 V_ij。用同一个交集体积矩阵，对两网格的原生分片常数J/q场积分比较；再采用 F_fine→coarse,i = sum_j(V_ij F_fine,j)/sum_j V_ij 将细网格场守恒平均到粗网格，实现同一可分辨空间尺度对照。原FV高斯点的对称共同采样也保存在JSON作为独立对照。

原生空间场的相对L2指标等价于 sqrt(sum_ij V_ij |F_coarse,i - F_fine,j|² / sum_j V_fine,j |F_fine,j|²)。另外分别记录总体场、去掉驱动幅值的归一化J空间形状、以总海水电损归一的q形状及其冷态至当前时刻的变化。

## 核心物理判断

原生网格冷态空间J/q在真实共同湿域上的不一致约为48%～52%，而将细网格场按精确湿体积守恒平均到粗网格后约为15%～18%。同一套温变质量协方差subcell修正虽然已明显改善P07完整动态端口ΔZ跨网格差，原生空间J仍然采用单元常值；因此各源积分模式的冷态J空间差几乎相同。局部湿FV内的近源场重建是目前最有价值的物理推进方向。

下一项直接在原 BFZI Green/GMRES与已保存的源求积场 C(q) 上重建真实求积点 J(q,t)，使细尺度q与端口海水弱式焦耳热同源；再使用本轮精确几何交集与多网格实算评价空间场。此后继续五材料32阶热ROM和40维几何分数阶神经代理的全新姿态、功率、时间及介质外推，同时降低离线计算成本。

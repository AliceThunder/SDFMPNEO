# V2.1 八层海水热状态与 BFZI 原湿 FV 亚网格温变：600 s 实算

日期：2026-11-14。原 BFZI V150，P03/P07 非相交旋转 OBB、精确湿 FV 公共面，572/1312 湿 FV、2 mm 八层海水被动热网络。每个几何、网格与源项积分模式均独立完成 600 s 原 BFZI 动态电磁热直接法。

## 物理计算与守恒温度映射

原 `BFZIV148Skin3D` 中的八层RC状态通过实际封装表面面片、旋转法向、面内尺度与各层厚度映射到原湿FV的高斯求积点。求积点位于热层外时取原 FV 的体热状态；通过 `skin_mix` 和原湿 FV 体积分配构造 Green 计算所需的准确体积均温 `(V_bulk*T_bulk + skin_mix*T_skin)/V_wet`。

新 `BFZIV148Adapter.solve(...,sea_temp=fn,sea_mean=True)` 在近源质量项中使用同一热状态产生的求积点温度，逐 FV 将求积点温度平移至保守体积均温。局部零均值温度与原 BFZI 源场 `C(q)^T C(q)` 的协方差保持不变；修正同时作用于复阻抗和同源弱式焦耳热。没有新增海水电磁 FV 或方向求解。所有模式保留原 Green/GMRES、铜趋肤复阻抗、真实 OBB 排水、准确湿面与守恒热时程。

阻抗采用 `Z(t)-Z(0)` 的六实分量全时程相对 L2 差；全Z列为整个复阻抗时程的相对 L2 差。温差是同一物理铜/封装节点时程中的最大绝对差。海水体积均温采用两个网格各自真实湿体积加权。

## 判断与继续推进

P03/P07 的完整动态热反馈显示 `subcell` 均改善复阻抗温变增量的两网格差，其中 P07 改善明显。仅把源质量矩扩展到全部湿 FV 的 `all` 没有获得同样的改善。三维空间 J/q 的跨网格采样差仍约为十余至二十余个百分点；建议下一轮将物理空间场的共同采样、近源积分与网格收敛作为重点，保持原 `legacy` 默认高精度基线，`subcell` 保留显式选项。

物理可信度进一步提高后，再让32阶五材料热ROM和40维几何分数阶神经代理学习这套热层—求积点反馈，独立扩展位姿、功率、时间程序、介质参数；减少新几何冷场、热算子与电磁切线的离线计算。

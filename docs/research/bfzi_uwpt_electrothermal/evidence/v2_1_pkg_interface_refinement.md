## 物理改进

此前 BFZI 温度模型已将两只封装盒独立旋转与尺寸映射至真实三维 FV，封装—海水耦合则采用每盒固定总导热系数 `0.6 W/K`，每个封装外表面 FV 面片仅连接最近一个海水 FV 中心。P03/P07 大倾角下，此接口海水中心到封装表面距离中位数为约63～92 mm，使单最近单元映射成为主要局部离散问题。

本轮增加 `pkg_sea_model="face-resistance"`，保留原 `nearest` 默认/基线。对每个沿线圈坐标系旋转的封装表面 FV 面片，按2×2或更高张量积分生成真实世界表面位置与外法向，选取该面片外侧的多个原 BFZI 湿 FV 单元。各面片局部总热导由三段串联热阻决定：

```text
G_face = A_face /
    [ (delta_pkg / (2*k_pkg)) + (1/h_surface) + (d_wet / k_sea) ]

d_wet = sum_i w_i * |x_wet_i - x_face|
w_i ~ 1 / (|x_wet_i - x_face|^2 + eps^2)
sum_i w_i = 1,  G_face_i = w_i * G_face
q_face_i = G_face_i * (T_pkg - T_wet_i)
```

`delta_pkg` 为对应法向的封装 FV 单元宽度，`d_wet` 为邻近湿 FV 中心到面片的加权距离。该双向热流对海水和封装方程分别取相反号，生成正系数且对称的材料界面 H；原海水 FV 源/Green/GMRES、电流J、弱式q、铜Bessel趋肤、40维分数阶网络与五材料守恒 ROM 不变。

本轮统一采用 `k_pkg=0.25 W/(m K)`、`k_sea=0.6 W/(m K)`、`h_surface=20 W/(m² K)`、每表面边长两个积分点、每积分点4个外侧湿 FV。每盒新热界面为约290～310条聚合空间导热边（原42～50条），继承双线圈各自的全部SE(3)旋转与独立封装尺寸。

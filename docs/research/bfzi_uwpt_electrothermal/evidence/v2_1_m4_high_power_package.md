# BFZI V150 M4 高功率下的海水—封装盒—铜温度反作用

实算日期：2026-11-12。原 BFZI 源仓库 `bfzi-v150-turn-scan`（`9f3fa48e6a0a133c363e244379a95f9e55f8b558`）。执行环境：XEnergy，研究分支 `research/bfzi-uwpt-electrothermal-surrogate`。全部结果与三维海水场快照已归档至 `runs/`。

## 研究问题与热结构

保持原 BFZI V150 的 M4 两圆形极限线圈与原 V148 完整 2×2 复阻抗后端。动态热态包含：
- 海水：原 BFZI 384 个三维 FV 单元，逐单元 `Tsea(x,t)` 和 `J/q`；
- 两只封装盒：每盒独立有效温度 `Tpkg[0/1](t)` 与热容量；
- 两只铜线圈：每线圈独立 `Tcu[0/1](t)`，温度更新内部复阻抗。

热接口及符号方向为铜→封装盒→海水→外海边界。每步输出 `Qcu_to_pkg_W[2]`、`Qpkg_to_sea_W[2]`、`Qsea_to_ambient_W`，另保存分材料储热 `Esea_J`、`Epkg_J[2]`、`Ecu_J[2]`。每个单元的离散能量预算为：

```text
delta(Ecu_i) / dt  = Pcu_i - Qcu_to_pkg_i
delta(Epkg_i) / dt = Qcu_to_pkg_i - Qpkg_to_sea_i
delta(Esea) / dt   = Psea_volume + sum(Qpkg_to_sea) - Qsea_to_ambient
```

封装盒初版采用**每盒一个有效热容/温度节点**；盒内三维温度梯度/表面热点尚未离散，下一轮独立物理热参考需完善。海水保持三维分布。热物性为第一版模型参数：`sea_rhoc=4.0e6 J/(m³ K)`、`sea_k=0.6 W/(m K)`、`pkg_rhoc=1.5e6 J/(m³ K)`、`cu_rhoc=3.45e6 J/(m³ K)`、`Qcu_to_pkg=(Tcu-Tpkg)*0.8 W/K`、`Qpkg_to_sea` 总界面导热系数 `0.6 W/K`、海水外边界换热系数 `10 W/(m² K)`。

**关键现象：** 断电后铜温度迅速下降，接收封装因铜→封装的残余传热在最初 60 s 内继续升温（100 V 为 +0.33498 K，150 V 为 +0.80028 K），随后缓慢降温。封装温度本身是历史状态并影响其后海水受热及铜的热反馈。这项现象可作为训练与测试的“相同驱动、不同热历史”基准。

## 联合物理 ROM：高功率留出 100 V

电磁 ROM 继续使用原 BFZI 温度加权 FV + Green/resolvent 小规模复矩阵投影；训练采用 3 V、30 V、150 V 三条实算时程，共 **66 个电磁快照列**、电磁 rank 8。热 ROM 采用 **5 个强制守恒材料模式**（海水、两封装、两铜）与其他空间 POD 模式，热 rank 12，训练热快照 33 个。

# A2 独立样本验证：六条 BFZI V150 物理时程

## 结果来源
- 原 BFZI V150、OBB、subcell 原生积分、source skin 八层热模型。
- 固定六条时程：G1/G2 各 medium/extra；G1_drive(extra)；G2_mat(extra)。
- 完整数值：`runs/bfzi_a2.json`、`runs/bfzi_a2_*.npz`。
- 执行：`python -m examples.bfzi_a2 --bfzi-root <BFZI路径> --runs runs --out runs/bfzi_a2.json`。
- G1/G2 分别从 P03/P07 锚点增加相对 y 平移 20/25 mm；激励样本电压缩放 0.65 且 240–330 s 停机；材料样本改变海水电导率温度系数至 0.8 倍。此处材料变化并非冷态电导率变化。

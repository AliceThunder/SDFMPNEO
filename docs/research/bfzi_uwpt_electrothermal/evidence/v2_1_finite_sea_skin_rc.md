## 1. 物理动机

海水热扩散率 `alpha=0.6/(4e6)=1.5e-7 m²/s`。15s热扩散长度约1.5mm，600s约9.5mm；目前的原BFZI电磁海水 FV单元为数十毫米。增加整个三维电磁网格至足够分辨水侧导热层的规模将大幅增加冷态算子及离线成本，因此需要局部热层。

此前半无限海水物理热阻 `Z_skin(s)=1/sqrt(k*rho*c*s)` 已由32正权重指数模态 `SeaSkin` 实现，其阶跃解析温升误差约0.012%以内。现在新增有限深度的正热容/正导热 RC 梯形热层，用于在实际三维原BFZI水体中**保守地替换原近表面热传递体积**。有限 RC 梯形网络作为被动有理传递函数，在短时刻近似半阶扩散、长时刻与原大尺度水体FV相连。

## 2. 实施内容及守恒性质

`sdfmpneo_bfzi/sea_layer.py:BFZIV148Skin3D` 基于 `BFZIV148Pkg3D`，为两个独立姿态的封装表面每个物理热FV面片建立一条具有 `skin_layers=8` 个状态的法向热 RC 梯形网络。默认研究深度 `skin_depth=2mm`，8层厚度按1.4几何级数递增；共128个实际表面面片、1024个局部热状态。真实内部电磁BFZI海水节点数量保持572或1312。

每个面片从封装热节点到第一海水热层节点的总电阻：

```text
R_pkg = (1/h + 0.5*d_pkg/k_pkg + 0.5*d_0/k_sea)/A
```

层间热导 `G_i = k_sea*A / (0.5*(d_i+d_{i+1}))`；末层至原BFZI湿FV的热阻以原实际湿FV面片附近的质心距离为基础，扣除已解析的热层深度，保持相近的总稳态热阻。所有耦合均为正热导、双向等量异号热流；原导热矩阵仍对称。

**水体热容量绝对守恒：** 按每层实际几何体积 `A*d_i`，从相应原BFZI海水FV的 `rho*c*V` 中扣除并转移到热层，防止凭空增加海水容量。原程序的局部弱式Joule `q_i` 同样按相同体积分数分配给剩余粗FV与新热层，保证 `sum(Psea)=sum(q_i*V_i)`。温变原BFZI电磁直接法使用粗FV与细热层体积加权的温度作为原电磁湿单元 `sigma(T)`，避免热层额外隐藏热量。

增加8点 Gauss 空间分配 `skin_map=2`：在每个三维热层体积沿两个面内维度及深度各取两个Gauss点，将体积份额守恒归属给被真实几何切割后的原湿FV，替代原 `skin_map=1` 整层质心单元分配。减少 FV 单元归属跳变，保留以便验证分辨率影响。

核心方法测试：正热容量、对称被动热导、全海水 `rho*c*V` 绝对守恒、每原BFZI湿单元Joule功率守恒、温变电磁FV水温平均一致性。独立8层热RC在2秒恒定表面热流下对半无限海水解析升温的误差约1%，符合有限层短时刻的半阶扩散特征。

## 4. 下一步应处理的关键物理空间问题

保持当前原BFZI V150六方向高精度神经代理与原 `face-resistance` 默认物理基线不变，有限层方案作为显式新选项继续发展。

已排除纯热容量重复计算、铜到封装单位热响应主导误差，以及仅增加有限体积湿面积/切线方向能解决空间问题的路线。下一项决定性物理工作是**两个真实旋转封装之间的窄海水间隙热交换，以及热层外缘与粗原BFZI海水网格的温度/通量匹配**：

1. 当前 P03/P07 非相交封装特意留有约5mm物理最小间隙；真实海水热扩散在600s覆盖约9.5mm。仅各自建立半独立2mm海水层，再接到距离较远的原FV质心，仍缺少相对封装表面经薄海水间隙的直接热耦合。
2. 建立**真实面片间隙导热**：依据封装实际朝向、相邻面片的物理距离和遮挡，连接两边热层的外缘，按去重后的水体积和导热通道分别与原湿FV网络连接；以无源被动RC确保总热量守恒。
3. 对照“一个封装受热、另一个封装无源”的二维包间热交换时程、完整真实BFZI高功率动态Z和海水J/q，先实现跨网格收敛，再考虑让 `GeomHeat/GeomHeatROM` 代理吸收这一完整热层状态，复用SOE记忆完成低成本训练/推理。

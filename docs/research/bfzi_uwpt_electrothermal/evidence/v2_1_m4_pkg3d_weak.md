# BFZI V150 M4 三维封装热场与端口一致海水热源

**真实执行：** 2026-11-12，XEnergy，原 BFZI 独立仓库分支 `bfzi-v150-turn-scan`（`9f3fa48e`），研究分支 `research/bfzi-uwpt-electrothermal-surrogate`。沿用原 V148/V150 海水 Green/resolvent、空气自感互感、源局部质量修正及完整复 2×2 端口阻抗。实际运行 **12 passed**。

## 1. 两只封装盒由单温度节点扩展为三维热场

新增 `sdfmpneo_bfzi/v148_pkg3d.py::BFZIV148Pkg3D`，每个封装盒按 `4×2×4` FV 单元离散，2 盒共 **64 个封装热单元**；原 BFZI 海水 384 FV 单元及两只铜线圈各自的温度节点继续保留，总热态维数为 **450**。

- 各封装单元取自原 BFZI 包装盒包络范围；内部相邻单元通过 `G=k_pkg A/d` 传热；本轮 `k_pkg=0.25 W/(m K)`。
- 铜—封装换热由 BFZI 实际线圈中心线的有向线段长度分配到空间附近的封装单元，盒—海水换热按盒外表面单元面积分配到临近原 BFZI 湿单元。
- 继续使用原参数：每盒总铜—封装换热导纳 0.8 W/K、封装—海水 0.6 W/K，海水外边界传热系数 10 W/(m² K)；封装等效体积热容 1.5e6 J/(m³ K)。
- 每步输出每盒**热容加权平均温度、空间最高温度、每单元温度与坐标**、铜→盒→海水界面热流、分材料储热和能量收支；通过 `--pkg-shape 4 2 4 --pkg-k 0.25` 显式启用。
- 当前封装模型对应包装盒占据范围的**等效均匀固体热容量**；盒内空腔及具体壳体壁厚分布尚未单独定义，后续可在这一 3-D 结构内引入非均匀材料占比。

## 2. 1.15% 海水端口损耗与物理电流平方积分差异的精确定位

新增 `examples/bfzi_sea_energy.py`，直接从原 BFZI M4 `(I+G_0 V P_φ)X=C` 及原端口读出 `Z_ij=Z_rect(C_i,X_j)-Z_rect(G_i,G_{X,j})+Delta Z_ij` 计算三套指标：端口海水电阻矩阵、`|J|²/σ` 加局部源质量的体积分，以及上述端口双线性式按单元分解的弱形式损耗。

真实 M4 200 kHz、σ=5 S/m 的诊断结果：

| 指标 | 数值 |
|---|---:|
| 原 BFZI `R_port[1,1]` | 0.12781381449951715 Ω |
| 物理 `J²/σ` 积分 `R_J2[1,1]` | 0.1263611167857569 Ω |
| 端口局部弱形式积分 `R_weak[1,1]` | 0.12781381449951715 Ω |
| 原 FV 场再次投影误差 `||P(PX)-PX||/||PX||` | 0.0235510 |
| 原 FV 源再次投影误差 | 0.0235408 |
| 两损耗矩阵相对差 | 0.0118429483 |
| 弱形式积分与端口矩阵相对差 | 2.031e-16 |

端口计算所使用的原 FV 投影在 3-D 体积电流平方内积下非严格幂等/正交，从而造成原 `J²` 积分与原 `Z_rect` 功率读出之间的离散差。这一差异来自实际算子及读出方式，不涉及实验值或附加拟合系数。

在原 BFZI 电磁求解器及完整复阻抗保持不变的前提下，新增可选 `--sea-heat port-weak`：

```text
R_ij,p^(weak) = (omega*mu)^2 sigma_p
  Re[ 0.5*(C_i dot X_j + C_j dot X_i
             - G_i dot G_Xj - G_j dot G_Xi)
      + Delta M_ij,p / volume_p ]

q_p^(weak) = 0.5 * I^H R_p^(weak) I
```

其中 `R^(weak)` 是**单位体积的实功率矩阵**。每个海水单元的积分自动恢复原 BFZI 的 `Re(Zsea)`；与物理的 `q_J2=|J|²/(2σ)+局部质量项` **并列保存**，分别用于研究原 BFZI 的端口能量一致性和独立空间电流物理误差。它是原方程的离散弱形式能量分配，未使用全局经验缩放；对本轮全部 M4 时间步，局部弱形式 q 非负。选择 `--sea-heat j2` 仍可使用前一种源并保持旧结果兼容。

# BFZI 统一几何驱动的水下 WPT 电磁热联合代理：研究起点

> 状态：**理论研究草案（2026-10-31）**。用于收存前期文献分析、架构讨论与后续决策；**不是已经验证的性能结论，不代表现有代码已实现这些能力**。

## 目的

在 **SDFMPNEO** 中建立独立研究线：以 [0UnifiedModelingUWPT](https://github.com/AliceThunder/0UnifiedModelingUWPT) 中的**最新版圆形—圆角方形统一平面螺旋**作为几何基础，研究含封装（安装盒）、导电海水、任意六自由度相对位姿、谐振电路及温度演化的高精度快速电磁热联合代理。

**明确排除误用：** 这里的 BFZI 几何**不是**旧版“双阶数超椭圆”统一模型；不得将超椭圆形状阶数直接作为最新版 BFZI 的几何参数。

本分支从 SDFMPNEO 的 `main`（基线提交 `3b0c5b6fb5f15ba0057cd77cb36a27412b6e4ed6`）建立，现阶段**仅增加研究文档**；保持现有代码、测试、`theory/`、`README.md` 和各历史分支不变。

## 设计决策摘要

- **几何权威来源**：`0UnifiedModelingUWPT/sections/02_geometry_model.tex`；物理基底参照 `03_package_seawater_impedance.tex` 和 `04_geometry_induced_fast_computation.tex`，而不是依赖记忆重写另一套线圈。
- **保留 SDFMPNEO 原有 REFERENCE / FAST / CERTIFIED 分离原则**，研究方案须在适当位置与之整合，而不是静默替换正确性后端。
- **无固定世界网格推理**是方法目标；离散积分、局部求积、实验和 FEM 教师数据允许存在，不能把“无固定世界网格”误说成“完全不用数值积分”。
- **物理因果链**：BFZI 几何与位姿 → 复数电磁场 / 端口响应 → 电路电流 → 逐材料空间损耗 → 守恒热演化 → 温度依赖材料 → 更新电磁响应。
- **研究范围**：先处理线性、各向同性、非磁性封装和分段均匀海水的可靠闭环，再评估磁芯、导电屏蔽、温度非线性、海流、谐波和复杂介质；不要首版就宣称“任意介质均可靠”。
- **研究创新是待证实的假设**：BFZI 跨匝仿射结构与学习算子的结合；受约束的海水非局部响应；随体/世界双坐标场；守恒时域低阶状态；谐振电路闭环。

## 重要定义与约束

本研究中的“电磁热联合代理”必须区分：

- **单向电磁→热**：先计算电磁损耗，驱动温度演化，但温度不再反作用电磁。
- **双向耦合**：温度修改电导率、电阻、磁导率等，进而影响阻抗、实际电路电流和新的损耗。
- **全场代理**与**监测点回归**：输出局部峰值/测温点不等同于任意位置连续三维电磁与温度场。
- **快速端口代理**与**空间场代理**：只拟合 (L,M,R) 不足以保证空间损耗及热源正确。

所有精度、加速比和泛化声明均须附基准范围、分母、硬件、误差定义与实验来源。

# 共享 32 维隐式热演化及 42 几何泛化实验

**状态（2026-11-18）：隐式 ROM、神经–ROM 混合及热算子替换诊断已完成。42 组几何增量训练和全新 BB01–BB06 独立物理参考已启动。正式模型保留 V6，上一轮 V5 候选保留。**

## 1. 研究问题与新实现

上一轮发现 AA01–AA06 动态复阻抗误差约 38%，其中预测铜导体温度所产生的解析铜阻抗误差约占总动态变化的 34%，而海水阻抗分量约为 8%。解析铜热容量、铜—封装导纳及七模态接触核均能显著提高局部参数的准确性，直接替换到先前已训练的 V5 闭环后仍未降低开发集动态 Z 误差，表明存在热算子与神经热状态的误差补偿。

新增 `sdfmpneo_bfzi/geom_free.py::rom_step`，直接在共享 32 维容量正交热坐标求解

其中电路电流、铜耗和海水损耗均由当前隐式热状态与原 BFZI-free 端口阻抗切线闭环计算。Picard 迭代收敛后再进行物理温度非负性校正。每步仅涉及 32 阶线性系统，不调用新几何 BFZI 冷态求解、不重新构造三维热基、不构建新几何热网格。

运行入口：`examples.bfzi_geom_free_eval --heat-mode rom`；原在线方法 `--heat-mode neural` 仍为默认。另加入 `--heat-mode hybrid --rom-mix w`，可将物理 ROM 与原神经状态头的 27 个空间热模态按权重混合，五材料预算仍经过 5×5 物理校正。新增 `tests/test_bfzi_geom_free.py` 测试隐式求解的可重复性、有限温度、五材料能量预算和零 BFZI 求解调用。针对性测试 3 passed。

## 2. 开发集完整闭环对照

沿用原 V5 的 5 组开发几何、15 条 S5 时程，以及完全相同的冷态/端口/海水热切线/三维空间解码器。

混合不改善开发阻抗误差，且要同时执行神经和物理热步，在线速度也更低，所以保持为可选研究入口，不升级。

## 3. AA01–AA06 旧诊断集

此批物理数据已经在 V5 研究中开封，仅用于诊断，不再作为新方法独立验收。

| 指标 | 原 V5 神经热演化 | 32D 全隐式热演化 |
|---|---:|---:|
| 18 条时程平均动态复阻抗误差 | 38.3564% | **37.8286%** |
| 完整三维温度 RMSE | 0.20992 K | **0.16569 K** |
| 重复推理耗时 | 0.19236 s | **0.09117 s** |
| TX 铜温 RMSE | **1.35260 K** | 1.37591 K |
| RX 铜温 RMSE | 1.52176 K | **1.48452 K** |

动态阻抗误差只有 **2/6 组几何、8/18 条时程**改善，平均改善主要来自 AA06（45.41%→35.13%）；AA02/AA03 则退化。隐式 ROM 在六组几何上均改善完整三维温度 RMSE。该方法的确定优势是**三维温度精度更高、计算更快**，而动态阻抗泛化尚未达到升级条件。

## 4. 隐式热演化的参数与物理教师替换诊断

固定神经阻抗代理和 32D 隐式热步，比较解析铜输入和原 S5 冷锚点热输入，以下均为原开发集动态阻抗误差：

后面三项是需要真实 S5 冷锚点的**诊断实验**，不属于新几何自主推理方案。结果表明，单独更换冷态热源或算子并不能消除当前闭环阻抗误差，热状态、材料预算、空间模态与端口阻抗切线已形成互相补偿。下一步优先通过训练几何覆盖改善在线热演化的跨姿态泛化，而非继续修改单个热矩阵元素。

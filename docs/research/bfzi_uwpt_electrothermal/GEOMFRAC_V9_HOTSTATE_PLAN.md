# V9 独立热态电磁监督：400 样本先导实验

## 动机

V8 原训练有48组几何、132条热历史；大量时间点沿少数高度相关轨迹采样。原训练TX铜温升中位数6.61 K、RX 4.57 K；高温升与双端独立空间温差覆盖不足。现有固定热场实验表明，TX/RX局部海水扰动对各自电阻的真实敏感度明显高于跨侧敏感度，而原ZFix+SkinTan+ParZ48存在伪跨侧响应。75轮SkinTan真实热态训练将验证真热态海水阻抗相对误差61.78%降至53.74%，自主闭环动态Z从16.23%退化至17.29%。需先独立学习空间温度到复阻抗，再处理闭环。

## 第一阶段：400个独立热态

复用现有V8X0001–V8X0004四组**训练几何**的BFZI V150 S5 ultra电磁构造及真实热历史温度场，每组100个固定温度场，约400个BFZI电磁标签。取两条物理热历史中的温度场进行凸组合，再分别扰动TX、RX附近skin和整体湿海水温度，控制温升0–80 K。使用BFZI直接计算6个海水复阻抗分量与总复阻抗相对冷态增量；保存45维几何描述、48维温度状态、几何ID与标签。采样种子9031，10个样本保存一次，单几何失败继续下一几何。

生成器：`examples/bfzi_v9_hotstates.py`。命令：

```bat
cd /d D:\work\geomfrac-v6
set PYTHONPATH=D:\work\geomfrac-v8
python -u D:\work\geomfrac-v8\examples\bfzi_v9_hotstates.py --bfzi-root D:\work\geomfrac-s5-BFZI --per-geom 100 --out runs\geomfrac_v9_hotstates.npz
```

该阶段先检查温度场生成的物理合理性、热状态投影误差、BFZI电磁标签是否能被准确重建。之后基于冻结几何互斥的15组开发几何比较旧映射和新映射的**真实热态误差**，并继续比较自主闭环误差。开发集不参与模型梯度训练。

## 第二阶段：数据规模实验

将训练扩展到1200和3200个独立热态，并逐步增加不同几何，而不是仅在原4组几何上密集采样。以每几何32个独立热态为目标，最终约100组几何。优先增加RX主导温升、TX/RX温差反转、不同位姿及封装参数。

训练首先固定ColdNet与共享热算子，只重训海水复阻抗温度映射，监督6分量阻抗增量、冷态零增量及BFZI有限差分温度敏感度；再以独立动态历史对热模型进行训练，最后进行受物理监督约束的闭环联合优化。保留V7/V8冻结模型用于配对比较，减少重复的残差补偿分支。

## 完成标准

400样本先导：物理参考成功率、样本温度与几何分布、独立热态阻抗误差与自主闭环动态Z误差均有报告；若物理标签本身出现数值异常先处理标签。1200/3200阶段只在先导有效时启动。正式晋级需在新的几何互斥物理盲测上同时改善整体动态Z及TX/RX自身阻抗误差，温度、电流和功率不能显著退化。

## 2026-11-20 第一批400样本结果与数据分配调整

首批400个BFZI V150固定热态已生成：V8X0001–4各100个，训练集320、同几何留出80。相同几何留出集上，旧切线真实热态相对误差256.4%，新残差映射6.84%。此数值只证明四组已见几何内的温度插值能力。

将该模型接入完整闭环，在原15组独立开发几何、41条历史上，动态Z误差由原V8的16.2321%升至137.3646%，TX/RX自阻抗也明显恶化。原因是第一批400样本只覆盖4组几何，随机热态拆分又把同一几何同时放进训练与验证；模型通过几何记忆获得很低的验证误差，无法跨几何外推。该checkpoint不晋级，保留作为热态插值对照。

因此第二批不再增加单一几何的温度密度，改为复用原48组训练几何及其3条BFZI真实热历史，每组生成8个独立温度场，共384个几何多样样本；与第一批400样本合并后，按几何分组留出约20%的48组几何作为验证集，四组V8X密集热态只留在训练集。训练损失按几何等权，防止四组密集几何压制其余几何。再使用原15组独立开发几何做完整闭环评估。

第二批生成器：`examples/bfzi_v9_hotstates_multi.py`；几何分组训练器：`examples/bfzi_v9_hot_train.py`；残差映射及加载器：`sdfmpneo_bfzi/geom_hotz.py`；闭环验收：`examples/bfzi_v9_hot_accept.py`。当前XEnergy任务job-164正在生成384条BFZI固定热态参考。

## 2026-11-20 主线修订：完整物理直接法动态历史优先

**结论：V9 主训练数据采用 BFZI V150 完整电磁热直接法历史。**
本文件之前提出的任意空间热态组合仅保留作为定向敏感度研究资料，不继续作为主要增量训练数据。V8 已在 48 组几何、132 条完整 BFZI 历史上训练，V9 先前盲目增加独立热态，未解决动态物理状态与闭环训练之间的耦合。

实际完成情况：

1. 人工构造独立热态 400 + 768 = 1168 个，其中 768 个覆盖原 48 组训练几何；48 几何的 768 个均完成 BFZI V150 电磁标签，失败 0。四几何 400 热态模型在同几何留出样本中海水阻抗相对误差 256.4%→6.84%，但 15 组开发几何动态复阻抗误差 16.23%→137.36%；拒绝。
2. 1168 样本合并、**以真实几何分组**留出的训练（包括 V8X 与 V8T 的几何别名合并，避免同几何数据泄漏），9 组几何上热态海水阻抗误差 895.0%→166.2%，15 组开发几何动态复阻抗误差恶化至 202.70%；拒绝。
3. 已从 **48 组原训练几何、132 条完整 BFZI 物理直接法历史**中提取 2544 个非初始温度状态，完整历史保留在 `runs/geomfrac_s5_v8_full_manifest.json` 对应的物理参考文件内。提取物理一致热态的脚本 `examples/bfzi_v9_hot_history.py` 与数据 `runs/geomfrac_v9_hotstates_physical.npz`。相同训练方式下，在 9 组几何互斥的真实物理热态评估中，海水阻抗误差 68.01%→53.50%，而原 15 组开发几何的动态复阻抗 16.23%→18.68%，TX R11 自身15.78%→18.67%，RX R22自身20.73%→26.81%；仍拒绝该静态电磁残差 checkpoint。

**根因判断：**
(1) 人工热态并非热方程真实演化结果，局部海水 skin 加热可能引入温度空间不协调；虽经 BFZI 电磁求解得到阻抗标签，不能代替完整的物理电磁热历史。
(2) 将完整历史逐时刻拆成独立的 `(g,a,ΔZ)` 样本，丢失相邻时间状态、驱动、电流和热源之间的约束。
(3) V8原有温度网络和阻抗补偿网络经过闭环训练已有误差相抵；仅重训静态EM残差会破坏这种关系。
(4) 2544 个时刻来自132条高度相关的物理历史，并非2544条独立热演化过程；真正的增量应优先增加**几何和不同驱动下的完整历史**。

### 新的执行顺序

1. **复用完整历史，避免重复生成已有物理样本。** 继续使用 `runs/geomfrac_s5_v8_full_manifest.json`、`examples/bfzi_geom_multi.py:prepare` 读取原来的时间、驱动、48维真实热状态、三维材料温度、完整复阻抗和铜/海水损耗相关量。保持零时刻一致、时序递推和几何互斥。
2. **联合监督电磁与热演化。** 保留统一ColdNet、共享rank48热表示及SOE热模型作为初值；用真实 `ΔZ(t)` 训练海水阻抗响应，用真实 `a(t+Δt)` 与功率/温度历史训练热演化。完整闭环rollout对动态Z、TX/RX自身阻抗、电流、各材料温度和功率计算误差，并在训练阶段使热状态预测和电磁映射保持一致。
3. **先利用现有48组完整历史调试训练，随后增加新的完整物理历史。** 新增参考需要覆盖TX/RX功率不对称、不同开关历史、60/300/600s尺度与未见几何。优先增加几何×驱动组合，不再以每几何100个任意高温静态场扩量。
4. **验收与选择。** 原15组41条几何互斥开发历史用于选模，禁止用已冻结V8P/H/S盲测做参数选择。候选必须在开发集同时改善动态复阻抗和TX/RX独立自阻抗指标，热、电流、功率不明显退化，再冻结模型做新的独立几何物理验收。

当前V8冻结权重不变。此前三个静态热态模型均未晋级。本路线的下一份实现应直接修改现有**时序闭环训练入口**，复用物理历史，不新增独立残差网络。

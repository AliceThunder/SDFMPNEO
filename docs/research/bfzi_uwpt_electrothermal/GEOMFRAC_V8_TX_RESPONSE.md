# V8 TX 自阻抗温度响应专项改进

日期：2026-11-20
状态：误差归因和三轮轻量校准完成；增强物理训练数据生成中；V7 正式版本与 V8 已验收候选保持冻结。

## 1. 问题定位

已通过热学独立盲测的 V8 配置：原 rank48 主网络、ParZ48 强度0.5、`thermal_mix=0.25`、原 SkinTan V3。V8H0004 的300s长脉冲误差仍主要集中在 TX 自电阻 R11。

使用同一模型的真实闭环预测与物理参考热状态，重新调用 `circuit` 做离线归因。使用预测热状态重建的端口复阻抗与原 `rollout` 完全一致。

| V8H0004 300s状态 | R11动态误差（对整段总动态Z增量归一化） | 全动态Z误差 |
|---|---:|---:|
| 自主预测 | 31.0658% | 32.9081% |
| 仅使用物理参考铜温度重算铜阻抗 | 24.0443% | — |
| 用物理参考替换五材料均温 | 24.5655% | 25.1503% |
| 用物理参考替换全部48维温度状态 | 23.4152% | 24.6538% |

该物理参考的末时刻真实与预测TX铜温升分别为34.990 K、29.994 K；真实与预测TX封装温升分别为26.071 K、22.176 K。铜温度误差解释部分R11偏差，其余主要来自温度状态映射至复阻抗的跨几何误差。

V8H0004 的60s历史对应R11：自主15.0708%、真铜温度10.0851%、五材料均温10.4668%、完整48维热状态8.4218%。这些是已见盲测样本的**归因诊断**，不用于新参数选模。

## 2. 原48/15训练开发划分下的专项校准

全部试验采用 `thermal_mix=0.25`，冻结rank48热主网、SOE、GeomInit、ColdNet、SrcFix与SkinTan。132条原训练历史和41条开发验证历史、48/15组互斥几何。验证使用完整自主电磁热闭环。

原 ParZ48 开发集：动态Z 16.23210%，R11分通道误差11.17461%，X11分通道误差5.69960%，材料RMSE 0.45211 K。

1. **原ParZ48最后输出层局部岭回归**：仅拟合TX的R11/X11，其他通道不变。12组合中最佳完整动态Z为16.21137%，R11为11.05892%。相较原模型改善0.02073个百分点，低于升级阈值，拒绝晋级。记录：`runs/geomfrac_v8_tx48.json`。
2. **原ParZ48 TX-R11增益扫描**：0、0.5、1.5、2倍分别得到16.75488%、16.37660%、16.32234%、16.69855%，均未优于原模型。记录：`runs/geomfrac_v8_txgain.json`。
3. **基于焦耳热源投影的TX单系数物理修正**：使用`init.src[:,0]`与rank48温升状态构造物理加权特征。训练拟合系数-0.003102；四种缩放中最佳开发动态Z16.21707%，R11为11.12064%。改善0.01503个百分点，不推广。记录：`runs/geomfrac_v8_txphys.json`。

以上试验说明：在原有物理历史上调整少量残差权重，跨几何闭环收益有限。正式候选仍保持原ParZ48，无新增网络或推理步骤。

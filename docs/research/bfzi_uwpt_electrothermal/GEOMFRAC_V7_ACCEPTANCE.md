# V7 统一电磁热代理：核心适用域最终验收

日期：2026-11-20  
状态：**核心推理域内 V7 主网络验收完成；并联残差 V1 消融完成、未启用**

## 1. 冻结的系统结构

推理输入包括两线圈几何、相对位姿、封装与材料热参数、驱动电压时间序列。主推理链为：

1. 已训练的统一 `ColdNet`：一次输出完整双端口冷态复阻抗和空气电感。
2. 跨几何共享 `GeomInit` 与 `SrcFix`：预测48维共享热状态所需算子及海水 Joule 热源分布。
3. 冻结 `GeomFracET` rank48：随时间更新热状态、分数阶记忆及热—电反馈。
4. 冻结 `SkinTanV3` 与物理端口电路：根据温度预测动态复阻抗、电流和材料损耗。
5. `geom_cold_domain`：只接受标定过的核心域几何；域外返回 `out_of_domain`。

V7 推理链不串联 `PortSelf`、`ColdRes` 和 `MutFix`。并联 `ParZ` V1 只用于独立实验，正式入口保持关闭。

## 2. 参考数据和冷态独立测试

原生 BFZI V150 新增 1295 组高精度冷态参考，自动续跑完成。与历史有效样本合并，共有 1954 个唯一几何：

| 划分 | 数量 |
|---|---:|
| 训练 | 1500 |
| 验证 | 228 |
| 独立测试 | 226 |

训练集包含核心1050、边界300、极端150组，极端样本参与训练，正式推理限制于核心域。

统一 ColdNet 600轮训练，最佳检查点 epoch590。在226组独立测试上：冷态复阻抗相对误差0.14668%、空气电感误差0.14760%、端口电流误差1.82225%。旧 ColdNet 同集相应阻抗误差1.10679%、电流误差14.44211%。

核心域 gate 使用最近训练几何标准化距离阈值2.64860；核心验证集123/130被接受，核心独立测试集113/120被接受。对于测试集中这113组可推理几何，V7冷态复阻抗误差0.11174%、电流误差1.37741%；85组边界测试几何全部被拒绝。

## 3. 六组核心动态闭环独立验收

冻结以下几何：`C0416`、`C0725`、`V7D0001`、`V7D0002`、`V7D0003`、`V7D0004`。共12条动态历史，包括60秒和300秒两种激励。新增四组八条BFZI V150教师历史全部生成成功（失败0）。

冻结同一rank48热模型，对比V5冷态基线、历史冷态网络与统一V7：

| 指标 | V5 | V7 |
|---|---:|---:|
| 动态复阻抗增量相对L2误差 | 11.2155% | **9.9217%** |
| 完整复阻抗相对L2误差 | 0.7417% | **0.1231%** |
| 端口电流相对L2误差 | 8.6982% | **1.5563%** |
| 五材料平均温度RMSE | 0.4667 K | **0.2574 K** |
| 五材料平均温度最大误差 | 1.2730 K | **0.8421 K** |
| 海水损耗功率相对L2误差 | 26.4522% | **24.7713%** |
| 铜耗功率相对L2误差 | 11.1534% | **2.2224%** |

这里的“动态复阻抗误差”先减去各自初始阻抗，再计算时序L2误差，对较小的温致阻抗增量进行相对归一化。因而约9.92%的动态增量误差可与0.123%的完整阻抗误差同时出现。

V7的内部五材料能量预算最大残差在本轮统计约为3.7e-12 W；保留参考损耗功率相对误差以继续追踪物理预测质量。

## 4. 剩余误差定位

V7动态阻抗增量误差主要分布于自阻抗：R11误差占总增量L2约5.8846个百分点，R22约5.6420个百分点，X11约3.6135个百分点。互阻抗分项相对较小。

离线BFZI真热态替换实验（仅用于诊断，正式推理不使用教师状态）：

| 替换对象 | 动态阻抗增量误差 |
|---|---:|
| V7主模型预测的完整热状态 | 9.9217% |
| 只替换五材料平均热状态 | 6.8385% |
| 只替换16维海水局部热状态 | 9.8992% |
| 只替换高阶形状热状态 | 14.0038% |
| 替换全部48维热状态 | 12.2106% |

这说明材料平均温升和阻抗切线之间的耦合仍有改进空间，并且现有切线与部分空间热状态的匹配有不足。后续若继续优化，优先围绕平均材料热态、自阻抗动态响应、海水损耗参考误差展开。

## 5. 并联动态阻抗支路 V1 消融

已实现轻量 `ParZ`，与主模型共用45维几何/工况特征，依据五个材料平均温升输出TX/RX动态自阻抗的四个实数修正分量。约2132个可训练参数，零温升时输出为零，可选地参与完整电磁热反馈。

训练使用23组核心几何69条历史，验证使用5组核心几何15条历史；强度只在验证集选择，六组核心动态测试保持独立。

| 指标 | 未加并联支路 | 并联支路V1 |
|---|---:|---:|
| 验证集动态阻抗误差 | 25.6830% | **24.9090%** |
| 六组独立测试动态阻抗误差 | **9.9217%** | 10.5533% |
| 独立测试电流误差 | **1.5563%** | 1.5589% |
| 独立测试材料温度RMSE | **0.2574 K** | 0.2576 K |

本轮最佳epoch50，验证集选定强度0.5。部分测试几何获得改善，另有几何出现明显恶化，整体独立精度未达到升级条件。**并联支路保留为可选研究模型，不进入正式V7推理链。**

进一步研究的直接路径是扩大独立几何的动态残差训练数据，重点改善材料平均温度的条件化响应，以及训练集与实际预测状态的一致性；先验证独立泛化收益，再决定是否升级。

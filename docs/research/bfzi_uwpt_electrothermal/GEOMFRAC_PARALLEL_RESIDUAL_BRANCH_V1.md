# V7 后的并联误差校正支路评估

日期：2026-11-19

## 结论

建议保留这条思路，并将它作为 V7 主模型完成后的单独消融实验。它与串联堆叠多个经验补偿头不同：主模型保持完整的物理—神经电磁热闭环，并联支路只学习主模型相对 BFZI 物理参考的剩余误差，最后将小幅校正加回主模型输出。

这条支路有机会降低长链路中的系统性误差累积，同时不必把主网络本身做得更深、更复杂。它应当是一个小型、受约束、可关闭的误差头，而不是第二套完整电磁热模型。

## 建议结构

令主模型为
`y_main = F_theta(g, u, h)`
，其中 `g` 为统一几何编码，`u` 为工况输入（材料/封装热参数、激励及边界条件），`h` 为当前热状态或历史状态摘要。

并联支路为
`delta_y = G_phi(g, u, h)`
，最终输出
`y = y_main + alpha * delta_y`
。

`G_phi` 应使用与主模型共享的几何与工况编码器，内部只保留一个小型 MLP/低秩头。针对动态电磁热闭环，输入至少应包含热状态摘要、时间或时间步信息、当前/上一时刻激励；只输入静态几何无法表达随温升演化的阻抗误差。

## 校正对象与注入位置

优先校正动态复阻抗的实部/虚部，按 TX 自阻抗、互阻抗、RX 自阻抗组织输出。主模型的热状态演化仍由现有热 ROM 与热网络完成。支路先只修正阻抗，不直接改写温度、热源、热容量或导热算子，以免同时改变多个物理反馈环节。

训练目标采用物理参考与主模型输出之差：
`delta_target = y_BFZI - y_main`。
损失包含归一化复阻抗残差，并可附加端口电流残差。校正幅度采用零初始化输出头和小幅系数 `alpha`；训练完成后由验证集确定 `alpha`，不允许在测试集调参。

## 防止过拟合与误差放大

1. 残差训练样本必须来自未参与主模型拟合的预测结果，或通过按几何分组的 out-of-fold 主模型预测生成，避免支路只学习主模型训练集上的乐观残差。
2. 几何必须按完整样本分组切分；同一几何的时间片不能跨训练、验证和测试集。
3. 支路输入和输出均做尺度归一化，输出头零初始化。
4. 只允许在 V7 适用域 gate 接受的核心域内启用；超出域时令 `alpha=0`。
5. 用验证集选择固定校正系数，必要时按输出通道设置少量系数；不增加复杂的动态门控网络。
6. 支路必须允许关闭，且校正后需同时检查动态阻抗、端口电流、温度场、能量预算和热源功率。

## 实验安排与闭合标准

V7 当前优先完成冷态参考生成、ColdNet 训练和核心域验收。之后在冻结主模型上训练并联支路，保持同一训练/验证/测试几何划分。

比较三组结果：
- 主模型 F；
- 并联校正 F + G；
- 仅主模型、但参数量/训练预算相近的对照（用于识别收益是否来自单纯增加容量）。

核心域独立测试至少报告：
- 动态复阻抗相对 L2；
- TX/RX 自阻抗和互阻抗分项误差；
- 端口电流误差；
- 五材料温度 RMSE/最大误差；
- 海水/铜耗功率误差及能量预算残差；
- 推理时间和额外参数量。

只有当并联支路在未见几何上稳定降低动态阻抗与电流误差，且温度、功率和能量预算不恶化，才合并进默认模型。若改善只发生在训练几何，或需要很大的校正幅度，则保留为诊断分支，不进入部署模型。

## 与现有实现的关系

当前 `sdfmpneo_bfzi/geom_free.py` 已存在可选 `extra` 注入点：它把额外阻抗修正加到主电磁热闭环的海水动态阻抗项中，并在每个时间步参与电流—损耗—温升反馈。接口改动应保持最小：将当前传给 `extra` 的 18 维静态 `encode(case)` 输入，替换为主热网络 `GeomFracET` 已使用的同一 45 维几何/工况特征 `g`，并继续输入归一化热状态、时间和当前激励。这样残差支路与主网络共享完全相同的几何/工况编码，再通过一个小型残差头输出 6 个动态复阻抗分量。修正仍注入海水动态阻抗项并参与原有闭环，无需构造独立热求解链。

V7 冷态 ColdNet 本身仍按当前方案独立训练与验收。并联支路不应混入 V7 冷态主干训练，也不应成为新的串联补偿链。

## V1 最小可运行消融实现（2026-11-20）

已实现共享45维几何与工况特征的轻量并联动态阻抗支路：

- 共享主模型的 `g`（45维），不额外训练第二套几何编码器。
- 使用主网络预测的五个材料平均热状态 `h[:5]`；几何小头输出 `4×5` 响应系数，线性映射热状态增量到 `R11/X11/R22/X22` 修正值。互阻抗保持原主网络预测。
- 几何条件小头宽度为32，约2132个可训练参数；零初始化最终输出层，零温升时精确输出零。
- 修正注入现有 `geom_free.rollout(extra=...)` 通道并参与原有非线性电磁热反馈；原有 `extra` 的18维旧输入兼容保留。
- 冻结V7 ColdNet、rank48 GeomFracET、皮肤切线及热源；在36/11几何历史中只使用适用域通过的23/5组训练/验证核心几何。训练目标为 BFZI 动态复阻抗增量与主网络增量之差。
- 使用验证几何选择强度 0、0.5 或 1，六组独立核心动态参考只做最终测试。未能改善时强度选择0，保持现有V7。

物理动机来自已冻结六组动态验收：V7 动态阻抗增量误差为9.9217%，而完整阻抗误差只有0.1231%，电流误差1.5563%、平均温度RMSE 0.2574 K。阻抗分项的主要剩余误差位于R11和R22。将BFZI真实五种材料平均热状态代入原切线后，动态误差可降到6.8385%；将全部热状态代入反而升至12.2106%。因此首轮并联支路优先学习材料温升条件化自阻抗校正。

代码：`sdfmpneo_bfzi/geom_parallel.py`、`examples/bfzi_cold_v7_parallel.py`。输出：`runs/geomfrac_v7_parallel.pt` 和 `runs/geomfrac_v7_parallel.json`。

## V1 消融测试结论（2026-11-20）

轻量分支已完成训练与真实闭环测试。使用23组核心几何69条历史训练、5组核心几何15条历史验证，最佳训练epoch为50，验证集选择强度0.5。验证动态Z误差由25.6830%降至24.9090%；冻结六组核心独立测试由9.9217%升至10.5533%。电流由1.5563%到1.5589%，温度RMSE由0.2574 K到0.2576 K。

**V1 并联分支保留为独立研究候选，正式 V7 不启用。** 当前23组动态训练几何对几何条件残差的覆盖仍较少，个别未见几何出现明显负迁移。后续研究优先改善材料平均热态与阻抗切线的一致性，并进一步扩展独立核心动态几何用于训练、验证，再决定是否采用并联结构。详细数据见 `runs/geomfrac_v7_parallel.json` 与 `docs/research/bfzi_uwpt_electrothermal/GEOMFRAC_V7_ACCEPTANCE.md`。

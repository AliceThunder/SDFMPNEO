## 2. 阶段和验收

**阶段 A — BFZI 基底独立可用**
- 连续绕行曲线、线元、导体截面、端口/馈回流；圆形极限及 \(\alpha=1\) 等距偏置特例。
- 任意刚体位姿；两侧封装合法几何组合。
- 与 BFZI 原论文空气电感、源项匝号结构化积分的一致性比较（参考实现需先可运行）。
- 输出：几何/源项/端口参考结果及明确误差预算。

**阶段 B — 海水电磁与损耗**
- 非导电封装、有限/无限海水域处理、\(\nabla\cdot J_s=0\)、界面条件及复场基底。
- 每个材料分区的热源，端口电磁耗散与体积分一致；六自由度扫描。
- 先准确参考求解，再实现学习残差；独立报告端口误差、局部 \(E,J,B\) 和 \(Q\) 热点误差。
- 特别记录截断域/辐射条件收敛与局部数值求积误差。

**阶段 C — 热物理与时间动力**
- 几何条件化热基、守恒容量矩阵和空间温度重构。
- 测量启动、功率阶跃、关断、连续充电、海水温度/流速变化下的热点和稳态误差。
- 长时间预测绝不能只依据训练窗口内的短时误差声明可靠。

**阶段 D — 完整电路耦合**
- 先选一种确定补偿拓扑和基波工作模式，校准实际电流与功率；再扩到 LLC/CLLC 和谐波。
- 单向与双向耦合对比；温度→材料→阻抗→电流→损耗→温度闭环。
- 报告固定电流与固定电压/电源补偿下的差异，并覆盖电路失谐。

**阶段 E — 训练与加速**
- 只有在参考物理计算和损耗闭合成立后，才训练场散射/热基修正网络。
- 同一几何范围按**形状、安装盒尺寸、六自由度位姿、导电率、频率、功率、时间历程**划分训练与外推测试；避免只随机拆分同一场景的点位造成虚假泛化。
- 所有加速报告都同时给出基准方法、硬件、预计算与加载、显存/内存、单点/批量查询、总体场重建时间。

## 4. 不应被忽略的理论风险

1. **精确几何不是完整物理导体**：有限截面与回流电流、集肤/邻近需要独立处理。
2. **海水反作用是非局部问题**：端口拟合好不保证真实海水损耗空间分布。
3. **局部边界存在尺度差异**：匝间近场、盒壁薄层、皮肤深度、远海水响应必须采取多尺度误差控制。
4. **端口矩阵需严格物理约束**：互易只在适用材料条件下要求对称，被动性需 Hermitian 部分半正定。
5. **运动耦合边界**：所谓任意姿态并不等于任意运动速度；缓慢位姿变化与电磁运动感应是不同问题。
6. **介质覆盖声明**：分段均匀各向同性海水基线先于强非线性、频散、各向异性、湍流。
7. **热 ROM 的稳定性**：保证容量和耗散不够，复杂外部加热、海水尾迹及跨域热能还需验证。
8. **新颖性边界**：各单项技术已有先例；创新必须体现在 BFZI 结构化场核、统一损耗状态、空间动力耦合及实证消融。

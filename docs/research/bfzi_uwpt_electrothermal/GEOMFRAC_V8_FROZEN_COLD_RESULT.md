# V8 冷态主干冻结与动态切线微调：XEnergy 实验结果

日期：2026-11-20
状态：两轮候选实验完成；正式 V7 保持原状。

## 背景

V8 首版统一13输出 ColdNet 能将六组核心历史动态海水功率误差从
V7 的24.7713%降至1.6643%，但226组独立冷态测试阻抗误差从
0.14668%升至0.18419%，电流误差由1.82225%升至2.31542%。
动态阻抗增量误差由9.92166%升至10.17288%。
下一轮目的是保留V7冷态精度，同时改善热损耗分解和动态阻抗泛化。

- 使用原先23组核心训练几何/69历史以及5组核心验证几何/15历史。
- 以V8闭环自主热状态预测，学习教师动态阻抗增量与现有切线的差值。
- 最佳验证模型在第10轮，训练至60轮早停；6组核心历史只做最终回溯。

TX/RX铜阻抗实部、虚部。不额外串联任何网络，不再次训练主干。

## 下一关键问题与决策

新物理分解明确改善海水功率，而动态阻抗增量仍有10%左右误差。
本次针对自主热状态的直接微调在独立几何上出现负迁移。
继续扩大动态训练几何的覆盖面，之后再研究与热反馈一致的阻抗切线，
比继续添加小型并联补偿网络更符合当前的精度与简洁目标。

**冻结主干V8保留为新热源分解候选；原V7仍是正式模型。**
上述六组动态是历史回溯证据，升级前要重新冻结并生成未见几何的动态参考。

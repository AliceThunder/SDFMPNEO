## 1. 唯一总目标与架构

建立可训练、保存、加载和查询的统一水下无线电能传输电磁热代理系统。输入为**双连续 UMFC 多匝线圈**（圆形/圆角方形）、两个非磁性非导电封装、各自独立 SE(3) 位姿、海水电导率、频率、选定电路及运行功率/负载/时间；输出为**复 2×2 端口阻抗、单位端口及实际电流下三维 E/B/H/J、海水空间热源 q、功率效率与温度 T(x,t)**。

主计算链：

```text
UMFC 解析几何 / 两个绝缘封装 / 两端口有向闭合源
                        ↓
海水合规电流基 W0 → 同源 R / L / K → 单位端口状态 X
                        ↓
端口 Z_EM ↔ 谐振补偿电路 → 实际复电流 I
                        ↓
同一状态 J=WXI → 空间 q(x)=|J(x)|²/(2σ) → 热投影
                        ↓
温度基 Φ / 热 ROM ODE / 温度网络 → T(x,t)
                        ↓
温度更新材料和阻抗、再次解电路与电磁场（循环）
```

电磁网络输出**电流模式组合** `Sθ(g,ω,σ)`，热网络选择有效温度模式并辅助物理传热。网络不独立回归彼此无关的 `Z`、`J`、`q`。

## 2. D0 物理契约

- 两个独立连续 UMFC 多匝线圈，圆形与圆角方形，真实有向馈电和回流；封装互不穿透，均非磁性绝缘；基线为均匀静止海水。
- MQS、峰值相量 `exp(+jωt)`、`μ=μ0`；先核实 `ωε/σ`、波传播尺度及皮肤深度。外域有限截断必须报告 R 收敛。
- 两个独立单位电流端口 `(1,0),(0,1)`；检验 `(1,1),(1,-1),(1,j)` 的场叠加、损耗交叉项和端口互易。
- 对海水求 `J=-σ(jωA+∇φ)`，在绝缘边界 `J·n=0`、导电区域满足 `∇·J=0`；正确处理多连通环流、零空间和规范。
- 细丝线源仅作为有定义的外部磁源/海水增量近似；总铜自阻抗须用 GMD/有限截面约定，铜内皮肤与邻近效应另行建模，损耗分账防重复。
- 锁定相同几何、边界、源与材料后才比较独立方法；实验曲线只用于后续外部验证，数值精度由内部收敛、能量和同源方法对照判断。

## 3. M1：物理直接法完整闭合（当前最高优先级）

### M1.1 几何与源（复用已有代码）

统一 `geometry/scene/source`：UMFC 八段中心线、圆形极限、匝间规律、每端口闭合有向导线、两个独立 SE(3)、封装合法性。解析有限直线段磁矢势及适当求积产生单位端口激励 `C_p`；利用 UMFC 匝号和刚体变换加速源积分。避免把旧超椭圆线圈重新引入基线。

### M1.2 合规海水电流基和 R/L/K

在真实双绝缘封装海水域建立 `W=[W_1,…,W_m]`，每列满足散度为零、封装上零法向及必要的全局环流约束；随几何调整且保留可追溯的空间重构。

```text
R_mn = ∫_Ω σ⁻¹ W_m·W_n dV
L_mn = μ₀ ∫_Ω W_m·G₀ W_n dV
K_mp = μ₀ ∫_Ω W_m·C_p dV
A_s = R + jωL
X   = −jω A_s⁻¹ K
z   = X I
J   = Wz
Z_sw = ω² Kᵀ A_s⁻¹ K
q(x) = |J(x)|²/(2σ(x))
P_sea = ½ zᴴRz = ½ Re(IᴴZ_sw I)
```

磁场由两端口源场及海水二次场叠加，`Z_EM` 在清楚的铜/空气/海水分账约定下输出。**同一 z 同时决定 Z、J、q、功率**；任意两端口复电流先相加再平方，保留交叉项。所有磁块采用一致的正能量积分，电阻 Gram 使用正权求积。

### M1.3 双端口及真实场景最小闭环

第一组可运行场景必须是**真实双 UMFC 线圈 + 双封装 + 海水**，可以先采用小规模/可控空间离散，再逐级提升。运行入口能够输入几何、`I`、`f`、`σ`，直接输出 `Z_EM`、`J/B/E/q` 和海水功率；支持单位端口场缓存与空间点查询。

**M1 功能完成判据**：相同场景的两个单位端口、复数叠加、场重构、非零海水损耗、端口海水功率恒等式完整运行；互易性与被动性通过局部检查。**M1 数值参考 PASS** 独立报告，与“功能可运行”分开。

### M1.4 独立数值验证的停止策略

既有 Elmer 26.2 TEAM-7 50/200 Hz 时域/频域、原始 Whitney B、h/R/Δt 和同源磁能量保留为**求解器参考证据**。当前 TEAM-7 原始 B 的 gap025→gap02 四周期间隙相邻差约 4.25%，上方空气约 8.76%，铝板约 3.07%；原生功率尚未空间收敛。只对实际阻断 M1 参考可信度的问题进行定向改进：导体趋肤方向离散、稳定 H(curl) 频域参考与本项目物理源桥接。优先**稳态谐波频域**，相同问题不得反复启动四周期长积分。

对于每个参考算例单独报告 `h`、外域 `R`、离散阶数/场恢复、参考不确定性、源一致性及端口/损耗误差。若 TEAM-7 验证仍 OPEN，允许先实现真实双 UMFC 的功能及确定性 ROM 原型；**正式高精度训练标签不得伪称已认证**。不通过放宽阈值宣布 PASS。

## 4. M2：确定性电磁降阶

用 M1 物理参考对形状、封装、双位姿、频率、电导率采样，分别获得两个单位端口电流响应。采用能量加权 POD/SVD 或贪心法，构造有效合规子空间。真实组装或一致投影 `R_r=SᵀRS, L_r=SᵀLS, K_r=SᵀK`，保持 `J_r=W_0S z_r`，输出 Z/J/B/q。检验不同基数下场、端口、局部热源误差及**包含组装成本的端到端**速度。完成判据：相对于直接法可重复的精度—速度收益。

## 5. M3：神经电磁子空间

网络输入几何、封装、位姿、`ω`、`σ`，输出实满列秩模式组合 `Sθ`；仍由 `(R_r+jωL_r)z_r=-jωK_rI` 决定复电流。损失包括复 Z、空间 J/B、q、海水总功率与跨端口组合。先与确定性 ROM 对照，再训练；测试集按**整个几何场景**隔离，评估跨尺寸、错位、旋转及材料泛化。报告网络推理+投影+解方程+重构的总耗时。

## 6. M4：谐振电路

第一版明确选择一套补偿拓扑及基波近似，接入 `Z_EM` 与线圈给定铜电阻，计算两个端口实际电流/电压、输入/输出功率、效率与负载变化。单位端口 `X` 可复用；实际电流改变时直接组合 `J=WXI`。检查物理功率收支。

## 7. M5：三维热态 ROM 与神经热加速

构建几何相关热模式 `Φ`、热容量 `M_T`、导热/换热 `K_T`。同源热源投影：

```text
Q_a,mn = ∫ φ_a W_m·W_n / σ dV
b_a = ½ zᴴ Q_a z
M_T(a,g) da/dt + K_T(a,g)a = b(q)+fθ
T(x,t) = T_ref(x)+Φ(x)a(t)
```

常数热模式满足 `Q_0=R`；包括启停、升温、冷却和长时间积分。热网络学习模式选择与受能量约束的传热修正。独立热参考比较三维 T、热点、最大温升、热量收支与时间演化。

## 8. M6：电磁热双向闭环

热步中：`T→σ(T),R_cu(T)→Z_EM→补偿电路求 I→J/q→热 ROM→下一步 T`。按需要在同一热步内固定点迭代。保留材质分区损耗；关断时热衰减继续计算。

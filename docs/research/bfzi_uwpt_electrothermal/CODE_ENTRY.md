## 二、不再反复讨论的算法路线

1. **REFERENCE 先行。** 按 BFZI 原文公式实现连续直边、四角部和有向线元；先逐匝直接求积，接收完整馈回流；空气自项按明确 GMD/截面规则处理。
2. **海水参考路径。** 采用确定性局部 curl/Piola 模式，按真实绝缘盒体界面构造海水无散度/零法向电流空间，近间隙、远场和必要的全局拓扑环流单独处理；有限外域变大时检查场收敛。
3. **构造同源 R/L/K。** R 由实电流模式的正权电阻 Gram 产生，L 由对称/正能量磁积分产生，K 由 BFZI 单位端口场源产生；网络暂不参与。
4. **求海水两端口单位响应。** (R+jωL) X = -jω K，Z_sw = ω² Kᵀ (R+jωL)^(-1) K。对于任意给定端口复电流 I，先计算 J(x)=W(x) X I，再由 q(x)=|J(x)|²/(2σ) 生成局部耗散。
5. **快速求解后置。** 先以确定性投影基 S 构造 W_r=W_0S 和 R_r=SᵀRS、L_r=SᵀLS、K_r=SᵀK；真实加速需要缓存/几何重用，不得只报告一个小线性系统的求解时间。
6. **学习仅替换基选择。** 教师场和 ROM 相容并验证后，才以网络预测几何条件化低维子空间，不另外训练相互矛盾的端口阻抗/海水损耗。
7. **其它导电材料用联合 Schur 补。** 铜皮肤/邻近与导电盒体未来必须在同一导电场中求解，不能相加独立阻抗补丁。
8. **复杂热电路后接。** 由同一空间热源投影至保热容量/耗散的热 ODE，再将温度依赖阻抗接入真实谐振电路，最终实现双向反馈。

## 三、最小文件结构与接口合同

在现有仓库新增独立 Python 子包 **sdfmpneo_bfzi/**。已检查 pyproject.toml 的包发现规则包含 sdfmpneo*，不必先重构庞大的 sdfmpneo_vnext/，也不能直接将旧 SuperellipseSpiral 改名为 BFZI。

建议按顺序建立：

| 文件 | 主职责 |

| geometry.py | BFZICoil、直边/角部与线元、圆形极限、SE(3)、 Gauss 采样 |
| scene.py | BfziScene、Seawater、Package、绝缘域和合法几何 |

| thermal.py | 后续：空间热源到守恒热 ODE |
| circuit.py | 后续：谐振电路与温度反馈 |
| neural.py | 后续：几何条件化合规子空间选择器 |

第一轮外部调用的语义：

- 传入两根 BFZI 线圈、封装、静态位姿、海水参数与频率 Hz；
- 输出两端口复数阻抗 Z_total_baseline、Z_sw、L_air；
- 可查询单位端口 E/J/B 响应、任意给定双端口复电流对应的 q_sea(x)；
- 返回场景有效性与参考误差/收敛范围，不能跨几何/温度偷用缓存。

**数值约定：** 长度 SI m、电导率 S/m、频率 Hz，角频率 2πf，峰值相量 e^(jωt)，体积耗散 W/m³。

## 四、首个运行里程碑的真正验收门槛

1. 连续导体段端点、线元、圆形极限、六自由度位姿、跨匝仿射结构与 BFZI 权威公式一致。
2. 封装与人工外边界的海水电流零法向条件成立；电阻 Gram 在当前离散基下满秩。
3. 数值 Z_sw 对称、被动；在**同一求积下**端口海水耗散等于体积焦耳热；复杂双端口热源含交叉项。
4. 外域增大、海水基数和求积阶数上升时，端口与局部场逐步收敛。内部代数功率一致不等于真实场精度已经验证。
5. BFZI 逐匝与结构化核在目标误差容差下比较，并报告**总体**参考/快速流程的耗时。

这些检查都可纳入主要物理模块的少量直接单元测试，不建立大型审核/审计系统，也不使用 GitHub Actions。

## 二、不再反复讨论的算法路线

1. **REFERENCE 先行。** 按 BFZI 原文公式实现连续直边、四角部和有向线元；先逐匝直接求积，接收完整馈回流；空气自项按明确 GMD/截面规则处理。
2. **海水参考路径。** 采用确定性局部 curl/Piola 模式，按真实绝缘盒体界面构造海水无散度/零法向电流空间，近间隙、远场和必要的全局拓扑环流单独处理；有限外域变大时检查场收敛。
3. **构造同源 R/L/K。** R 由实电流模式的正权电阻 Gram 产生，L 由对称/正能量磁积分产生，K 由 BFZI 单位端口场源产生；网络暂不参与。
4. **求海水两端口单位响应。** (R+jωL) X = -jω K，Z_sw = ω² Kᵀ (R+jωL)^(-1) K。对于任意给定端口复电流 I，先计算 J(x)=W(x) X I，再由 q(x)=|J(x)|²/(2σ) 生成局部耗散。
5. **快速求解后置。** 先以确定性投影基 S 构造 W_r=W_0S 和 R_r=SᵀRS、L_r=SᵀLS、K_r=SᵀK；真实加速需要缓存/几何重用，不得只报告一个小线性系统的求解时间。
6. **学习仅替换基选择。** 教师场和 ROM 相容并验证后，才以网络预测几何条件化低维子空间，不另外训练相互矛盾的端口阻抗/海水损耗。
7. **其它导电材料用联合 Schur 补。** 铜皮肤/邻近与导电盒体未来必须在同一导电场中求解，不能相加独立阻抗补丁。
8. **复杂热电路后接。** 由同一空间热源投影至保热容量/耗散的热 ODE，再将温度依赖阻抗接入真实谐振电路，最终实现双向反馈。

## 2026-11-01：第三轮核心数值和热源实现

- 原 `air_inductance` 在低阶 Gauss 源节点上直接对相同节点使用软核自作用，正对角会造成约 `dl²/a` 的分辨率偏差。现按 BFZI 连续组/回流路线生成短直线段，自段采用解析的正则核双积分 `2[h asinh(h/a)-sqrt(h²+a²)+a]`，不同段仍使用带分块内存限制的 Gauss Neumann 积分；与单位端口海水场所用的粗 Gauss 源分辨率解耦。可通过 `air_panel_length_factor`、`air_panel_gauss_order` 独立细化；仍非精确外部场 GMD/复杂邻近解。
- 海水软化 Green 磁耦合采用**对称分块**组装，非对角块及其转置只算一次，有限内存从 `chunk * Q` 改为 `chunk²`；电阻/磁能/耦合共享同一离散模式，端口耗散身份仍应保持。

- `BFZICurrentControlledEnvelope` 和 `BFZIVoltageControlledEnvelope` 支持 vNext 热 ROM 的二输入（仅两路铜热）或三输入（含海水热）源算子，允许额外热状态；前两路解码温度必须代表两路导体，保持电阻温度反馈与源通道一致。
- 收敛脚本拆分为**默认轻量**和 `--full` 细化，并同时检查端口海水阻抗与固定湿区采样点焦耳热；完整模式还独立比较空气自段长度、Gauss 源阶数，避免将空气自感误差隐藏在海水收敛曲线下。

## 2026-11-01：据本地收敛日志修复盒壁角向漏采

用户本地反馈：此前 `python run.py --mode bfzi` 的离散海水功率积分闭合到约 `1e-16` 相对误差，但原球坐标射线方案在 4/6/8 到 5/8/12 求积加密时出现 `dZ≈0.70843`、固定湿区 `dq≈0.93457`；两个盒壁切向模态时 `dZ≈0.51916`。这些是明显未收敛，不可将能量闭合当作精度凭据。根因候选是角向采样无法解析厚度 30mm 的封装附近 `wall_scale≈1.125mm` 海水电流变化。

已将 `SeaMQSConfig.quadrature_scheme` 默认切至 `box_shell`，另保留 `ray` 做回归：
- 在每个独立 SE(3) 定位的绝缘盒外构造由六个互不重叠矩形薄层组成的近壁积分区域；体积由正权张量高斯规则求积，其中法向前 `1.5 wall_scale` 单独细分，避免薄边界层被低角分辨率忽略。
- 原球坐标射线只对**扩大后的盒外剩余区域**积分，沿光线排除外扩盒的径向区间，不对近壁壳层重复计数。
- 扩张薄层若相互接触或碰到外球边界，则自动减小薄层厚度，保持正定、互不重叠的几何域分区。

- 收敛脚本现在首先比较旧射线与盒壁薄层法，再独立比较法向、切向、远场阶数、模态、半径和磁核软化。打印总求积点数、几何海水体积误差、阻抗差和固定湿区热密度差。

设计保留原有 Galerkin `R,L,K`、端口耗散通道及热源接口，避免以变更物理方程去掩盖求积缺陷。此方法仍需真实本地数值实验确认各误差是否收敛；目前还没有运行新默认方案的实际结果。

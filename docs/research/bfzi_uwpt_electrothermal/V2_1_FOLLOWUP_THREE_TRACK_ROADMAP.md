# BFZI 动态电磁热代理后续三条研究主线

日期：2026-11-13  
项目：UMFC BFZI Dynamic Electrothermal Neural Surrogate  
基线分支：`research/bfzi-uwpt-electrothermal-surrogate`

## 目标与架构约束

当前高精度主路径保持为：原 BFZI V150 统一圆形—圆角方形线圈及相对 SE(3) 位姿 → 温度相关海水/铜复阻抗与双端口电路 → 因果40维分数阶 SOE 神经代理 → 原 BFZI 三维 J/q 空间场 → 五材料能量守恒热 ROM → 物理切线校正。

后续研究固定沿以下三条主线推进。它们共同服务于一个目标：让同一个代理在更广几何、运行条件和介质域中保持可信的动态复阻抗与三维空间场精度，同时降低新几何部署所需的原 BFZI 离线计算。

## 主线一：提高神经代理的外推能力

### 当前基线

- 40维显式几何条件与分数阶 SOE 动态记忆已覆盖连续线圈形状、相对 SE(3) 位姿和双独立封装尺寸。
- 完全留出的 P03/P07 纯神经动态阻抗误差约为 3%～4%。
- 使用新几何原 BFZI 冷态八模态物理切线校正后，完整动态复阻抗误差已达到约 0.002% 量级。
- 已实现一致物理热模态对齐、跨几何切线残差网络，以及从既有真实温度/复阻抗时程恢复切线的零新增方向 EM 教师路径；新切线模型的 P03/P07 真实精度仍待实算。

### 推进内容

1. 将物理切线作为神经代理的显式学习对象。网络学习跨几何切线的基线与残差，预测海水复阻抗对一致物理热模态温度的方向导数；动态神经预测提供先验，物理切线负责纠正局部热阻抗变化。
2. 扩大几何覆盖：两线圈独立圆角参数、圆形极限、匝数/尺寸、完整相对平移和旋转、两封装独立平面尺寸及姿态。
3. 扩大运行覆盖：电压/电流与功率等级、不同启停序列、时间步长、运行和冷却总时长。训练划分按整条时程及整种几何隔离。
4. 显式加入介质物性条件，例如海水电导率、介电参数及其温度依赖；介质变化同时进入原物理端口/场/热源教师，不只作为神经输入标签。
5. 研究切线与三维场的联合表示，使网络能够学习阻抗切线、J/q 的空间变化及其与热模态之间的联系。

### 验收指标

- 以整几何留出和整运行程序留出评价，报告完整动态复阻抗、海水单独复阻抗、海水/封装/铜温度误差。
- 纯神经模型相对当前 P03/P07 的 3%～4% 基线持续改善；物理切线混合模型在独立留出上保持现有约 0.002% 高精度参考水平。
- 记录各电压、时间步长、介质参数和几何边界上的最差误差，不以随机时刻拆分替代整工况外推。

## 主线二：降低每个新几何的离线物理计算成本

### 当前成本构成

新几何部署仍需构建原 BFZI 冷态电磁空间场/端口锚、三维热容量与导热算子、热 ROM，以及高精度方案使用的八模态海水复阻抗灵敏度。单侧差分可将方向求解由16次降至8次；已有真实动态时程可拟合切线，从而避免新增温度扰动方向求解，但它仍依赖已有几何冷态物理锚与真实时程，不能等同于完全免除新几何冷态计算。

### 推进内容

1. 首先完成既有 P01/P02/P04/P05/P06 时程切线教师训练，并在 P03/P07 上与原16次双侧切线作同温度、同时间、同三维热 ROM 对照；同时验证8次单侧方案。
2. 将冷态物理量分解为可跨几何共享的表示：冷态双端口复阻抗、海水 J/q 空间场、热容量/导热算子、材料界面参数、八模态热基及其复阻抗 Jacobian。
3. 训练几何条件的冷态场/算子/热基代理或低秩插值模型。先从相邻几何的物理插值、共享基与小残差校正开始，再逐项替代昂贵原 BFZI 计算。
4. 保留原 BFZI 直接计算作为教师与精度回退路径。逐项替代并测量误差，不将“零方向 EM”误报为“零冷态 EM”。
5. 为新几何部署建立统一成本表：原 BFZI 冷态调用次数与耗时、空间场构建、热算子/ROM 建基、切线构建、神经训练、单条时程推理耗时。

### 验收指标

- 每个阶段均与原 BFZI 冷态端口、J/q 空间场、热算子及最终动态复阻抗比较。
- 分别报告方向扰动求解次数与冷态几何构建成本，避免把二者合并成单一“求解次数”。
- 降低新几何离线时间的同时，完整动态复阻抗和三维热场精度达到相应物理基线；无法达到时保留原物理计算路径。

## 主线三：提高空间场与几何边界真实性

### 当前基线

现有代理已输出原 BFZI 三维海水电流密度 J、焦耳热 q、海水/双封装/铜温度，并通过原三维 FV 热算子及五材料 ROM 维持能量守恒。显式双封装旋转和独立尺寸已接入空间坐标查询与热模型。下一阶段要进一步覆盖更大倾角、更多封装尺寸与介质物性变化，并独立检查空间场及材料交界。

### 推进内容

1. 建立大倾角与多姿态独立几何集，覆盖双线圈完整相对旋转、偏移和双封装独立旋转/尺寸；对 P03/P07 之外的姿态保留新的整几何留出。
2. 在原 BFZI 同一空间采样点上比较代理与直接法的三维 J 和 q，分别报告向量 J 的相对 L2、分量/幅值误差、方向夹角、q 的相对 L2、局部峰值和空间分布。
3. 验证热源局部非负、海水 q 体积分与海水端口损耗一致，并检查不同几何下局部场映射与 FV 体积积分的一致性。
4. 针对封装—海水界面，检查封装表面法向、有效接触面积、局部换热系数、界面热流连续性和五材料能量收支；用局部网格加密或独立表面采样检查界面离散误差。
5. 将海水电导率/介电参数及温度依赖纳入空间场验证，区分介质变化导致的电磁场变化与热传导/界面参数变化。
6. 检查冷态 J/q 与热态阻抗/热源之间的反馈一致性，避免只凭端口阻抗正确就认定空间场正确。

### 验收指标

- 每种留出几何均有原 BFZI 直接法三维 J/q 参考场及可复算的空间坐标/材料掩码。
- 报告 J/q 的空间误差、热点位置偏差、局部非负性、海水端口功率差、界面热流差及五材料能量闭合误差。
- 大倾角、封装尺寸和介质参数边界均有独立留出；不以单一小倾角几何的端口精度代替空间真实性验证。

## 执行顺序与当前任务

按以下顺序推进，三条主线长期并行：

**阶段 0：闭合当前切线迁移实验（当前最高优先级）**
- 运行 `examples/bfzi_tangent_data_study.py`，检查五个训练几何历史切线的有效秩和拟合误差。
- 在完全留出的 P03/P07（含 P07 150 V、15 s 两条时程）上比较原16次双侧切线与零新增方向 EM 的历史拟合/神经残差切线。
- 用相同分数阶网络、原三维 J/q、32阶五材料热 ROM 比较完整动态 Z、三材料空间温度、q 功率闭合与材料能量预算。
- 完成同条件8次单侧/16次双侧原 BFZI 精度及离线耗时比较。根据结果选择物理教师，不提前替换高精度默认路径。

**阶段 1：跨几何共享物理表示**
- 将一致热模态切线学习推广到冷态 J/q 与热算子/ROM；优先实现共享物理基加低秩残差。
- 增加几何、功率/时间和介质条件，按整几何/整工况留出验证外推。
- 同步建立大倾角与封装—海水界面独立空间场验证集。

**阶段 2：降低新几何部署成本并扩大适用域**
- 逐项替代冷态场、热算子/ROM 和切线的原 BFZI 新几何离线计算。
- 完成多介质、大倾角、双封装尺寸与高功率工况的端口、空间场和热界面联合验收。

每轮提交必须报告：最新提交、实际完成的主线、独立留出精度、离线原 BFZI 计算次数/耗时、单条动态推理耗时、空间 J/q 与能量闭合指标，以及尚未实测的部分。未执行的实验不得写成已完成。继续保持原 BFZI V150 物理定义、相对 SE(3)、分数阶因果记忆、三维 J/q 与五材料守恒热架构；不使用 GitHub Actions。

## 1. V7 的目标

V7 将工作重点从逐个异常样本增加独立补偿模块，转为统一冷态电磁代理、分层训练数据和明确的推理适用域。

系统需要同时满足：

1. 冷态代理跨几何共享，直接预测双端口完整冷态阻抗及空气电感分解。
2. 训练数据包含核心、边界和极端几何，极端样本用于学习物理变化趋势。
3. 正式推理限定在数据覆盖充分的核心工作域。
4. 保留已建立的跨几何 rank48 热状态与分数阶时间演化主体。
5. 通过独立冷态测试和冻结动态闭环共同验收。

## 2. 统一模型结构

### 2.1 冷态电磁主体

V7 以现有 sdfmpneo_bfzi/geom_coldnet.py 的 ColdNet 为统一冷态模型起点。

- 输入：16 维几何特征，包括两线圈 alpha/core、封装尺寸、相对平移、三个相对转角，以及两线圈面积/周长趋势特征。
- 主体：共享 MLP，隐藏宽度 96，三层隐藏映射。
- 输出：9 个物理分解量，覆盖 TX/RX 自阻抗、互阻抗的非空气部分，以及三个空气电感分量。
- 组合：由统一输出直接恢复完整双端口 z0 和 air。

V7 冷态推理链不再串联 PortSelf + ColdRes/ColdResPose + MutFix。这些旧模型保留为对照基线，不作为 V7 的在线补偿链。V7 的 ColdNet.apply 已直接输出完整双端口结果，动态评估入口对 V7 跳过 MutFix，避免再次覆盖统一模型预测的互阻抗。

训练目标除冷态阻抗分解损失外，加入外部电路族上的电流损失，使模型同时学习端口阻抗与负载电流响应。电流目标由冷态参考阻抗和已知外部电路解析计算，不需要额外生成热历史。

### 2.2 保留的物理模块

| 模块 | V7 处理 | 原因 |
|---|---|---|
| ColdNet | 统一冷态主体 | 一次预测完整双端口冷态响应 |
| ColdRes、ColdResPose | 只作历史对照 | 不再逐层叠加独立自阻抗补偿 |
| MutFix | V7 冷态路径移除 | 互阻抗已由统一冷态主体预测 |
| SrcFix | 暂时保留 | 输出海水降阶 Joule 热源场，属于独立物理输出；现有标签规模与冷态端口标签不同 |
| GeomInit / rank48 Atlas | 保留 | 提供跨几何热算子与共享热状态坐标 |
| rank48 GeomFracET | 保留冻结基线 | 负责热状态时间演化、分数阶记忆和热—阻抗反馈 |

后续若扩充了足够的空间热源标签，可研究把 SrcFix 并入共享几何编码器的多任务输出头。当前不为此增加新的独立补偿层。

## 3. 训练域与推理域

### 3.1 全局几何参数域

V7 第一阶段沿用已建立的 BFZI M4 几何域：

| 参数 | 全局范围 |
|---|---:|
| alpha1、alpha2 | 0.70–1.00 |
| core1、core2 | 0–25 mm，并满足 BFZI 绕组可行性 |
| shift X | -16–16 mm |
| shift Y | 80–116 mm |
| shift Z | -12–12 mm |
| tilt、yaw | -20–20° |
| pitch | -18–18° |
| box1、box2 | 210–242 mm |

所有候选样本还必须通过原生 BFZI 端部引线净距检查。几何无效或引线冲突样本不进入训练、验证或测试。

### 3.2 三个训练区域

对 12 个几何参数分别按全局范围归一化，定义距边界的归一化距离。

- 核心域：全部 12 个参数均位于归一化区间 [0.05, 0.95]。
- 边界域：有 1–2 个参数进入全局范围外侧 5% 区域。
- 极端域：至少 3 个参数进入全局范围外侧 5% 区域。

训练集目标分配为：

| 区域 | 训练样本 | 比例 | 用途 |
|---|---:|---:|---|
| 核心域 | 1050 | 70% | 主要精度与正式推理 |
| 边界域 | 300 | 20% | 学习工作域边缘的变化趋势 |
| 极端域 | 150 | 10% | 学习极端组合下的物理变化 |
| 合计 | 1500 | 100% | |

验证集和独立测试集分别另设 150 组新几何，均按核心/边界/极端 105/30/15 分层。现有历史验证和测试样本继续保留，因此最终合并数据规模大于上述最低数量。

### 3.3 正式推理范围

V7 正式推理默认只允许核心域样本。

推理入口使用两级判定：

1. 核心参数边界：任一参数超出核心域即标记为域外。
2. 数据覆盖判定：以 16 维冷态模型特征计算到核心训练样本的标准化最近邻距离。阈值由核心验证集最近邻距离的 95% 分位数标定。

边界域和极端域继续参与训练与离线压力测试，默认不进入正式推理。被拒绝的输入返回 out_of_domain，不输出正式预测值。域判定模型由 sdfmpneo_bfzi/geom_cold_domain.py 和 examples/bfzi_cold_v7_domain.py 实现。

## 5. 训练与验收

### 阶段 A：冷态参考数据闭合

闭合条件：

- 新增 995/150/150 组全部生成成功，或失败样本已补齐至目标有效数量。
- 合并后训练/验证/测试分别达到 1500/228/226。
- 三个 split 的几何完全不重合。
- 训练集区域计数为核心 1050、边界 300、极端 150。
- 所有入选样本通过 BFZI 端部引线净距检查。

合并入口：examples/bfzi_cold_v7_merge.py。

### 阶段 B：统一冷态代理训练

训练入口：examples/bfzi_cold_v7_train.py。

- 从头训练单一 ColdNet，不以 ColdResPose 作为 V7 推理基座。
- 使用 1500 组训练数据。
- 只用验证集选择检查点。
- 使用冷态物理分解损失和外部电路电流损失联合训练。
- 独立测试集仅在检查点冻结后评估。
- 报告整体及核心/边界/极端分组的冷态 Z、空气电感和电流误差。

比较对象：PortSelf V5、旧 ColdNet、ColdResPose V2。所有模型使用相同的冷态参考和电路负载集合。

### 阶段 C：适用域标定

使用训练核心域样本与验证核心域样本标定最近邻距离阈值。报告验证/测试核心域覆盖率，并检查边界与极端样本是否被正确标记为域外。

### 阶段 D：动态电磁热独立验收

使用冻结 rank48 热模型、Atlas、SrcFix 和皮肤切线，在原六组独立几何、12 条动态历史上进行同配置对照。

- V7 冷态路径使用统一 ColdNet，不再调用 MutFix。
- 正式动态精度统计只计入适用域判定通过的核心几何。
- 边界/极端几何单独记录离线压力测试结果，域外样本不进入正式推理。
- 比较动态阻抗、电流、材料温度误差及能量预算。
- 只有核心域静态精度、动态闭环精度和热学守恒同时通过，才升级 V7 正式模型。

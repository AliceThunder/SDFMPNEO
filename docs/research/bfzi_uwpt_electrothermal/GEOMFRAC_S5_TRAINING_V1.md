# GeomFracET S5 非冻结教师生产与时间步对齐 V1

2026-11-15。目标：让 BFZI V150/S5 五阶热物理直接法与 GeomFracET 共享 32D 热状态网络使用**完全相同的通断电时间定义**，建立首轮跨几何训练需要的真实样本生产入口。

## 1. 时间推进修复

此前神经模型在区间 `[t[k-1],t[k]]` 上把 `v[k]` 用于热输入和热量收支，物理直接法 `bfzi_physics_recheck.march` 则使用 **`v[k-1]` 作为整段区间的激励**。通断电边界发生一格时序错位。

已将两侧统一：

- 训练特征：第 k 步采用 `v[k-1]`、上一时刻复阻抗 `Z[k-1]`、上一时刻铜温。
- 自主推理：第 k 步的 SOE 和记忆热状态使用上一时刻电压，五材料热守恒校正也按上一时刻电压求热源。
- 右端观测：在得到 `T[k]` 和 `Z[k]` 后，重新用 `v[k]` 计算当前瞬时电流、海水电流密度、焦耳热和端口功率输出。
- 物理区间能量残差由上一段驱动计算；输出瞬时功率由当前驱动计算。这两类量严格区分。

沙箱针对通电 15 秒后恰好关闭电源的案例验证：`T[15s]>T[0]`、`I[15s]=0`、五材料热预算残差通过，且教师输入特征与上一时刻电压一致。相关 6 项沙箱局部测试通过。

**之前 P07 的 0.3205% 动态阻抗与 0.2349 K 铜温误差来自时间修复前的模型及训练；旧数据保留作历史对照。修改后模型必须重新训练，旧数值不得直接视为本版最终精度。**

## 2. 非冻结 S5 首批实验

`runs/geomfrac_s5_plan.json` 已定义四组原 BFZI V150 M4 线圈几何，其中圆形、圆角方形以及混合线圈，包含相对平移和姿态、不同封装大小、电导温度系数、绝缘/封装导热率及水侧换热系数。

- T01/T02/T03：三组共享训练几何，各两条 600 s 通断电历史。
- T04：全新留出几何，两条不同 600 s 通断电历史。
- 共 8 条历史，每条 41 采样点，15 s 输出间隔，实际热时间步上限 1.875 s，五阶近场源项，海水细层深度 2 mm。
- 几何与几何之间在训练/验证中完全不重叠，且不使用已冻结 U01–U12 验收工况。

先由 BFZI `create` 在每组几何构建一次真实电磁/热模型；运行一次 S5 冷态物理求解并保存 `bfzi_s5_Txx_ultra_anchor.npz`，继而用不同电压波形执行真实 S5 五阶物理热步。一个几何的多条激励共享其几何和冷态 FV 算子，免去重复建模。

每条物理教师必须返回 `candidate` 且达到 600 s 41 点，方写入完整 NPZ；其中包含当前采样电压、六个复阻抗实分量、原 S5 全三维温度与原始端口电流，保持单一时钟定义。

使用同一冷态热网格构建几何共享 32 维空间模式并直接投影完整温度场，生成原海水主体、TX/RX 海水薄层、两个封装和两个铜节点的最大温度误差、均方根误差及热点误差。每个几何/激励的投影误差与物理收支一起写入报告。

## 3. 直接复现

在具备原 BFZI V150 代码和计算依赖的执行环境内运行：

```bash
python -m examples.bfzi_s5_buildset \
  --bfzi-root ../BFZI --plan runs/geomfrac_s5_plan.json \
  --runs runs --grid ultra --inner-step 1.875
```

可选 `--max-skin-K 1.0 --max-pkg-K 1.0`，以最大三维温度误差作为**训练前空间投影门槛**，超过则停止导出待训练教师。

产物：

- `runs/bfzi_s5_Txx_ultra_anchor.npz`：各几何独立 S5 冷态热物理数据（训练网络统一 45 维几何/物理输入）。
- `runs/bfzi_s5_Txx_ultra_drive1.npz` / `drive2.npz`：完整 BFZI V150 五阶 S5 物理时程。
- `runs/geomfrac_s5_build_report.json`：原物理有效性、热守恒与共享热坐标三维空间投影指标。
- `runs/geomfrac_s5_manifest.json`：自动生成的跨几何训练、验证清单。

物理教师全部生成且空间投影满足选定门槛后执行：

```bash
python -m examples.bfzi_geom_multi \
  --manifest runs/geomfrac_s5_manifest.json \
  --init-model runs/bfzi_geom_diverse.pt \
  --epochs 500 --patience 90 \
  --out runs/geomfrac_et_multi.pt \
  --report runs/geomfrac_et_multi.json
```

`geomfrac_et_multi.json` 报告留出几何的自主动态复阻抗、全场/双铜/双封装最大温差、材料预算、空间基最大投影误差；随后再做冻结 U01–U12 的独立验收。

## 5. 热方程训练损失精简与原 BFZI V150 依赖定位（2026-11-15）

训练采用的是**预测与教师的相对热方程残差**。定义热状态 `a`、物理热算子 `K`，时间区间长度 `dt`，则预测残差和教师残差的差值为：

```text
r_pred - r_teacher =
    [(a_pred[k] - a_teacher[k])
     - (a_prev_used - a_teacher[k-1])] / dt
    + K @ (a_pred[k] - a_teacher[k])
```

两侧完全相同的教师源项 `q[k]` 在相减时严格抵消。因此删除原来每个历史采样点执行一次 `rom.source` 和一次复数端口电路求解的冗余预处理。训练、验证和跨几何 `prepare` 均改用直接差值表达式，保留原教师相对残差损失的数学定义和梯度。

沙箱随机双精度试验：两式逐项差异最大 `3.55e-15`，反向梯度最大差异 `8.53e-14`。相关 13 项本地局部测试通过；真实 S5 教师需要原 BFZI 运行后才能继续训练。8 条、每条 41 点的新训练时程共省去 **328 次**在线外的完整教师热源重构。这个优化降低数据准备成本，也避免将体积近似热源误用于监督目标。

另外已核实原始 `AliceThunder/BFZI` 仓库的 **master 分支没有 `run_v150.py`**，V150 脚本位于分支 **`bfzi-v150-turn-scan`**。`examples/bfzi_param.originals` 现在明确检查该文件及运行脚本版本，防止直接按 BFZI 的默认分支运行 S5 数据生产时发生模糊的模块导入失败。预备 BFZI 目录应执行：

```bash
git -C ../BFZI fetch origin bfzi-v150-turn-scan
git -C ../BFZI switch bfzi-v150-turn-scan
```

随后按第 3 节命令生成 T01–T04 真实物理参考并联合训练。当前沙箱没有原 BFZI V150 的完整求解源码以及这些新时程，阶段状态继续保持**待真实教师运行**。

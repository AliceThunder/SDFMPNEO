# UWPT：一次训练的几何参数代理与长时间查询

`run.py` 默认训练 **一个** `GeometryResearchModel`。网络输入为 `(G, a0, U, t)`；保存文件包含一个解析 DAG、一个共享电磁基、一个参考热基，以及连续几何网格图。改变域内几何输入后，无需另训模型、选择邻近模型或重新求热特征向量。

## 运行与配置

```bash
python -m pip install -e '.[cad,gui]'
python run.py --mode train
python run.py --mode predict
```

训练默认使用 PyQt 窗口，或以 `--headless` 运行。暂停、恢复、停止及日志读取机制继续有效。几何构建和几何初始响应阶段也显示进度阶段名称。

- `TRANSMITTER`、`RECEIVER`、`ENVIRONMENT` 定义参考 UWPT 网格。
- `GEOMETRY_FAMILY.parameters` 定义本次一次训练覆盖的几何参数盒。
- `TRAINING` 定义初始坐标、电流、时间和网络计算预算。
- `PREDICTION.geometry=None` 查询保存域的中心；字典形式可指定该保存模型的全部几何参数。实际名称、参考值和边界自动写入 `geometry.domain.json`。
- `FILES.resume_model` 可继续已保存的几何网络；此时几何域、材料和空间基采用保存文件中的定义，`TRAINING` 仍可修改。
- 旧的固定几何 NPZ 保持可加载。它们不能凭空获得几何输入；需要新训练几何模型。`GEOMETRY_FAMILY.enabled=False` 保留固定几何训练入口。

当前默认连续参数如下，所有长度单位为 m：

| 参数 | 含义 | 默认训练范围 |
|---|---|---|
| `tx_planar_scale` / `rx_planar_scale` | 发射/接收线圈局部平面缩放 | 0.97–1.03 |
| `tx_thickness_scale` / `rx_thickness_scale` | 各线圈厚度缩放 | 0.95–1.05 |
| `rx_offset_x` / `rx_offset_y` | 接收相对发射中心的世界坐标横向偏移 | −0.0002–0.0002 |
| `rx_gap` | 两线圈中心的世界坐标 z 间距 | 0.0098–0.0102 |
| `tx_package_scale` / `rx_package_scale` | 各封装外表面相对自身中心缩放 | 0.98–1.02 |
| `seawater_radius` | 实际海水外球半径 | 参考网格外球半径的 0.98–1.02 倍 |

`planar_scale` 同比例改变线圈外径、匝距和导体宽度；这三者在当前参数图中联动。厚度、两线圈的缩放、接收位置、封装外尺寸和海水外径独立变化。形状类别、匝数和材料连接拓扑固定；圆形与圆角方形可分别建立参考参数族。本模型不宣称一个固定网格图能够跨越任意拓扑变化。

网格控制点分别位于导体、封装/海水界面及海水外表面；内部位移由离散调和延拓给出。参数控制的是这个共形网格图，而非每个查询重新 CAD 布尔建模。整盒非退化界检查失败时，构建明确报错；不会偷偷缩小用户填写的范围或接受倒置单元。修改范围和参考网格后可重新训练一个更合适的参数族。

## 统一坐标与物理方程

参考热基 `Phi` 在相同节点/单元编号下随材料网格拉回。不同几何使用同一组系数 `a`：

\[
T_G = T_{amb}+\Phi a,\quad
M_r(G)=\Phi^T M(G)\Phi,\quad K_r(G)=\Phi^T K(G)\Phi.
\]

真实训练残差为

\[
R=\dot a-M_r(G)^{-1}\{q_r(G,a,U)-K_r(G)a\}.
\]

这里不会把变化几何下的 `M_r` 错当单位阵，也不会把 `K_r` 错当参考对角谱。电磁 Nédélec/P1 算子、端子面积载荷及焦耳热均在相应几何上重新组装；材料与温度相关电导率保持原定义。初温场投影使用几何自身的质量矩阵。

电磁降阶空间通过几何中心、上下角点、各轴端点和额外 Halton 锚点的残差–Riesz 增广共同建立。完整一遍检查通过后才接受同一最终基。没有电磁解快照或瞬态轨迹标签。锚点误差仅描述这些几何/热候选点；完整推理仍返回查询点自己的 EM 残差诊断。

所有几何归一化到 `[-1,1]` 后与电流一起进入一个解析 DAG。几何初始响应利用零温升电磁热源的电流二次型及几何热算子生成；随后用完整非线性方程残差更新权重/增长节点。初始化多项式不替代实际残差方程。

`max_nodes`、`max_degree`、`max_parent_responses` 和 `max_realization_dimension` 均是可见计算预算。候选超过预算会跳过；训练未满足独立残差检查时保留 `budget_exhausted` 或 `stalled`，不会写成收敛。已有网络即使达到节点上限，恢复训练时也先尝试更新现有权重。

## 时间域与无穷时间

默认有限训练窗为 `0–100000 s`。`time_sampling="mixed_log"` 将一半有限配点分布在 `time_min=1e-6 s` 到时间上限的对数坐标，另一半线性覆盖后期，并显式包含初始点。`include_steady_state=True` 对每组抽样的初态/电流/几何增加稳态物理残差检查。训练与独立检查使用不同 Halton 序列；自适应补点后的新检查仍保留相同时间策略。

推理支持任意非负有限浮点时间，包括大于训练上限的时间。`allow_time_extrapolation=True` 默认开启，独立于初态/电流外推开关；设为 False 可要求有限训练窗。几何始终需要位于保存的有效网格参数盒。

```python
PREDICTION["times"] = [0, 1e-6, 1, 1e3, 1e5, 1e6, "inf"]
PREDICTION["geometry"] = None  # 或完整几何字典
```

`"inf"` 表示 **稳态极限**，不是一个很大的伪造时间。每个响应满足 `y'+lambda*y=source`、`lambda>0`。静态输入恒定、初值衰减为零，递推得到 `y_inf=source_inf/lambda`，导数为零。计算实现保留重根/近重根结构，通过常量状态和衰减状态分离以及矩阵半群缩放计算长时间响应，避免直接形成溢出的 `A*t`，不把查询时间截断到训练上限。

稳态物理解释要求该工况确实存在稳定热平衡；若存在热失稳，不能将网络的有界极限当作真实稳态。有限配点和稳态点并不能证明所有时间上的误差都达标；这里提供可执行的长时间外推和稳态评估能力，并输出查询点的物理残差。恒定电流、固定几何和环境边界是每次时间查询的物理假设，不表示在过程中突然改变几何或电流后的新轨迹。

## 保存与查询输出

单个 NPZ 包括参考网格/材料、共享基、几何方向、几何域、电流映射、训练配置/报告和同一个网络。`state_only=True` 在加载之后仅执行解析网络、网格坐标变换及温度重构，不组装或求解新的 EM/热空间。

完整推理额外组装/缓存查询几何的物理算子，并输出阻抗、电感、材料损耗、物理残差与电磁诊断。返回的 `mesh_vertices` 对应查询几何；温度数组始终沿用保存网格的节点编号。`time_extrapolated` 标明是否超出有限训练窗，`steady_state` 标明稳态查询。

原有 `python -m sdfmpneo predict` 也支持几何模型，`--geometry geometry.json` 读取完整几何字典；不提供时使用域中心，`--times inf` 可查稳态。该入口的 `validate` 仍用于原有固定几何瞬态参考对照。

## 本次集成检查

使用根目录参考 UWPT 网格（446 节点、2023 个四面体）及默认 10 维几何范围进行实际运行：27 个几何锚点形成一个 35 维共享 EM 基，锚点最大能量误差界约 `8.46e-7`，低于 `1e-6` 目标。采用 `sample_count=12`、`validation_count=12`、`max_nodes=24`、`residual_tolerance=1e-4`，其余时间/物理/几何参数按默认配置，训练得到 20 个响应节点；训练/独立检查最大残差分别约 `7.61e-5` / `6.48e-5`。这是流程集成检查配置，不能解释为默认 `1e-5` 目标已被该次运行证明。

随后用两个未参与训练的几何输入查询 `0`、`0.027`、`421`、`1e6`、`1e300` 秒和稳态，检查初值、有限输出、物理残差及端口功率/区域焦耳损耗一致性；通过 `run.py` 加载、推理和 JSON 保存也已跑通。PyQt 实际几何任务的暂停、恢复、停止、主线程响应及几何检查点重新加载均已检查。数值残差仍不是实测温度精度或全时间误差证书。

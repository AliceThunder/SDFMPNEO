# SDF-MPNEO completion work tree

This file is the execution order for finishing the production SDF-MPNEO method. It is subordinate to `docs/SDFMPNEO_theory.tex` and `docs/SDFMPNEO_implementation.md`. A task is not marked complete because a prototype runs; it is complete only when its production exit criteria are satisfied and the full repository CI passes.

Status legend:

- **DONE**: production theorem, implementation and regression/CI are closed.
- **ACTIVE**: current blocking work.
- **PARTIAL**: substantial implementation exists but one or more production proof obligations remain.
- **PENDING**: production implementation has not yet been closed.

## W1. Scalable electromagnetic Riesz action — ACTIVE

### Existing
- state-dependent physical metric `H(a)=K+D(a)`;
- contrast-independent coercivity `beta_H >= 1/sqrt(2)`;
- certified inexact Riesz-action protocol;
- certified PCG action;
- physical magnetic/scalar block theorem;
- snapshot-free sparse residual-Riesz ROM;
- high-contrast copper/seawater regression;
- preliminary curl-factor and face-circulation magnetic auxiliary constructions.

### Remaining
1. Finish topology-exact face-circulation magnetic auxiliary action `P_A=S^T W S <= K_A`.
2. Select a square/full-rank face row set by exact topological/integer rank logic.
3. Prove/verify that the implementation does not collapse to one global magnetic factorization on refinement.
4. Replace scalar conductive correctness blocks by a scalable certified auxiliary/multilevel action.
5. Run complete high-contrast single-/multi-port ROM with global `splu` disabled in the production Riesz path.
6. Retain a factorization-free certified gamma bound.

### Exit criteria
- no full magnetic/scalar/global `H` factorization is required by the production Riesz path;
- block sizes/coarse dimensions are generated by topology/certificates, not configured thresholds;
- Riesz iteration/error certificate remains valid for `sigma_Cu/sigma_sea >= 1e7`;
- joint-port ROM and certified `Z/R/L/M` pass with the old reference Riesz LU disabled;
- complete CI green.

## W2. Continuous nonlinear electromagnetic-domain certification — PARTIAL

## W10. Unified certification and physical validation — PENDING

### Remaining

### Exit criteria
Every reported engineering output contains a complete finite certificate or is explicitly marked uncertified, and independent numerical/experimental validation confirms the certified claims.

No new model branch should be introduced unless a proof obligation above shows that the current architecture is mathematically insufficient.

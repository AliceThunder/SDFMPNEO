# SDF-MPNEO 0.10 科研训练与推理

## 1. 数学模型与实现范围

空间离散使用一阶 Nédélec 电磁单元与 P1 热单元。规范消元后的电磁方程和热模态方程为

```text
A(a) x(a,U) = b0 + B U,       A = K + i D(a)
T = T_ref + Phi a
q_j(a,U) = Re[x_r^H H_j(a) x_r]
F(a,U) = -Lambda a + q(a,U)
da/dt = F(a,U)
```

铜的电导率由线性电阻率律求倒数。组装、损耗和导数使用同一空间本构；倒数级数及其导数截断受 `constitutive_relative_error` 控制。科研封装默认使用常数环境温度和外边界 Dirichlet 条件。未加入流体速度。

电磁基来自残差的 Riesz 提升，不来自 `A(a)^-1 b` 的全阶解快照。科研入口显式使用稀疏直接 Riesz 参考后端以便复现；原有 Morse/PCG 后端仍可通过原始 core 接口使用。

热全空间默认保留全部离散自由度；JSON 可用 `thermal_rank` 请求部分低频热特征空间。该参数是数值截断，不宣称自动达到热尾误差目标。研究中应增加热秩、细化网格并改变外域半径检查收敛。原有 `thermal_truncation` 证书选秩接口可选，但不能与显式 `thermal_rank` 同时设置。

## 2. 无解标签的解析网络训练

网络自由衰减部分严格为 `a0_i exp(-lambda_i t)`，每个新增响应节点满足

```text
y' + lambda_i y = weight * product(parent_nodes),  y(0)=0.
```

空乘积表示常数热源。静态参数、初始衰减节点和已有响应节点都可成为父节点。由此，每次插入节点都保持原始初始条件，推理无需时间步进。

参考态电磁解在电流参数上是仿射的，因此其焦耳热严格为二次多项式。训练先在**已有 EM ROM** 上计算该二次型来提出初始响应节点；这不是采集瞬态标签，也不改变电磁基构造。

接下来使用物理残差

```text
R = da_hat/dt - F(a_hat,U)
```

进行训练。新节点的候选方向来自解析响应和物理状态雅可比，权重通过残差切向下降提出；每次插入后重新计算完整非线性残差。联合权重更新使用

```text
dR/dw = d(da_hat/dt)/dw - (dF/da) (da_hat/dw)
```

的解析雅可比进行 Gauss–Newton 修正和回溯。只有实际残差下降才接受更新。节点数和字典次数是计算预算，预算耗尽不会被标记为收敛。

训练点采用固定种子的 Halton 输入点。独立检查点不含任何参考解。若独立检查暴露误差，扩充物理残差配点后保留一组新的独立检查点。`numerically_converged` 只表示这些有限检查满足数值目标；原有连续域证明接口独立保留。

稳定求值用矩阵指数实现响应代数。工况与网络权重的导数通过乘积规则传播到状态空间初始向量，避免在近共振处对相近指数项进行相减。训练、保存后推理和雅可比使用一致的网络语义。

## 3. 使用方式

```python
from sdfmpneo import (
    demo_research_model, ResearchTrainingConfig, ResearchElectroThermalModel,
)

model = demo_research_model()
config = ResearchTrainingConfig(
    initial_lower=(0.,), initial_upper=(2.,),
    operating_lower=(1000., 0.), operating_upper=(3000., 1000.),
    time_horizon=.25, residual_tolerance=.002,
    sample_count=16, validation_count=16, max_nodes=12, max_degree=2,
)
report = model.train(config)
model.save("results/model.npz")
model = ResearchElectroThermalModel.load("results/model.npz")
prediction = model.predict(.2, a0=[1.], operating=[2000., 500.])
print(report.status, prediction.maximum_temperature)
```

`examples/research_workflow.py` 包含完整可执行代码，包括验证和结果写出。

保存文件包含实际网格、材料律、热矩阵/空间基、电磁空间基、端口源、工况映射、网络节点、训练域和训练报告。加载不会重新训练或重新计算特征空间。保存的是数值模型，不把它当作独立物理验证证据。

每个模型固定空间几何和频率。改变几何、频率或材料定义后重新构建对应模型。多个模型可以用于扫描设计参数；单一跨几何网络仍使用原有 geometry-family 接口，并需要满足其坐标图假设。

## 4. 真实 UWPT 配置

运行 `examples/create_uwpt_mesh.py examples/configs/uwpt_research.json` 可生成示例配置使用的网格。导体以折线中心线的矩形带状截面拉伸构造，转角使用共用斜接顶点，避免原 OCC 分段扫掠产生的重叠面。折线的中心线弦误差由曲线二阶导数上界控制。

| 字段 | 含义 |
|---|---|
| `mesh` | 相对于配置文件的 Gmsh 2.2 ASCII 网格路径 |
| `geometry` | 示例网格生成使用的尺寸、形状、位姿和离散设置 |
| `frequency_hz` | 固定激励频率，Hz |
| `ambient_temperature` | 环境和初始参考温度，K |
| `materials` | 以体物理标签为键的材料参数；必须覆盖每个四面体 |
| `electrical_conductivity` | 参考电导率，S/m |
| `resistivity_temperature_coefficient` | 电阻率温度系数，1/K；省略即常数电导率 |
| `thermal_conductivity` | 热导率，W/(m K) |
| `volumetric_heat_capacity` | 体积热容量，J/(m³ K) |
| `relative_permeability` | 相对磁导率，默认为 1 |
| `terminal_pairs` | 每个端口的正、负端子面物理标签 |
| `current_offset`、`current_matrix` | 可选的复电流映射 `I = I0 + C U`；默认 `I=U` |
| `em_candidate_states` | 电磁基构建的模态状态输入，不是解快照 |
| `em_energy_error` | 单位端口源的 EM 能量状态误差目标 |
| `thermal_rank` | 可选数值热截断阶数 |
| `training` | 初始状态/工况/时间域、残差目标和计算预算 |

端子电流使用峰值相量，正负端子施加等量反向电流。复映射系数可用 JSON 字符串，例如 `"1j"`；`U` 本身为实向量。固定相位差可编码在 `current_matrix` 中。负载电路并未被悄悄视为独立电流输入；如需特定负载关系，应另外定义对应电路约束。

初始状态 `a0` 是质量正交热模态坐标，不能直接填入摄氏温度。已有全节点开尔文温度可用 `model.project_initial_temperature(T0)` 投影；边界必须符合规定的环境温度。推理温度包含参考值、全部自由节点和边界节点，`maximum_temperature` 是这些 P1 节点的最大温度。

不提供参考温度/热网格给旧 `Executable...` 入口时，保留其旧的自由节点偏差输出语义；新科研入口始终恢复物理温度。

## 5. 独立数值验证

```bash
python -m sdfmpneo validate results/model.npz --a0 1 --operating 2000 500 --times 0 .05 .1 .2 .25
```

默认用 Radau 积分求解同一热模态动力学，但每次电磁平衡使用全阶稀疏系统。网络训练过程不调用该函数。`--rom-reference` 可改用电磁 ROM 进行对照，以单独检查解析演化误差。

这一区分很重要：保留相同热空间的参考轨迹不能验证热空间截断本身，也不能代替网格收敛研究或 Maxwell/COMSOL/实验比较。

0.10 开发验证中，快速非线性示例使用 6 个响应节点达到数值目标；一个独立工况 `(a0=1, U=[2000,500])` 上，在 `t=[0,.05,.1,.2,.25]` 的最大温度差约 `2.51e-4 K`。数值来自该离散示例，不能外推为实际线圈的精度保证。完整参数检查和其他工况也在回归测试中运行。

真实 CAD 流程也已实际运行：所附圆形配置生成 446 个节点、2023 个四面体，保留 2 个热模态并训练出 6 个响应节点。最大训练残差为 `1.414e-7`，独立参数检查最大残差为 `1.717e-7`，满足 `1e-5` 目标。保存后重新加载，在 `a0=[0,0], U=[8,3], t=[0,.25,.5,1]` 上与全阶稀疏电磁 + Radau 的最大温度差为 `1.37e-7 K`。这是粗网格、低热秩、小温升条件下的流程验证；尤其不能据此声称线圈热点温度已经空间收敛。网格数量和末位数值可能随 Gmsh/数值库版本变化。

剩余工作主要是具体科研问题的精度与适用性研究，而非部署功能：

1. **空间收敛性**：对目标线圈增加热秩、细化铜截面/趋肤层网格、扩展海水外域，比较阻抗、损耗和热点温度。目前所附粗网格只用于快速运行。
2. **目标工况精度**：在实际电流、初温与时间范围重新训练，增加独立残差点并做瞬态对照；预算未收敛时需要增加节点/字典能力或缩小模型域。
3. **外部物理验证**：与可信 FEM 求解器或实验比较，确定磁准静态假设、材料参数、边界条件及几何离散对目标研究的影响。
4. **扩展物理输入**：受载接收电路、时变激励、跨频率或跨几何单网络，需要相应的电路/参数化算子和训练接口。当前完整入口处理固定几何与频率、静态规定电流，不声称这些扩展已经完成。

上述范围内已经形成可执行的科研代码包。有限残差检查、离散参考解吻合与连续方程正确性是不同层次的证据；原有证书模块也应逐项满足自身假设，不能由一次训练成功替代。

\begin{abstract}
本文冻结 SDFMPNEO 的生产理论体系：首先以经过开放域、网格、功率守恒和几何连续性验证的 Maxwell truth model 生成几何相关端口阻抗与复 Hermitian Joule tensors；神经网络仅学习几何到这些低维电磁参数的映射；任意复端口电流通过解析二次型进入 Joule heat 与端口功率；温度演化始终由真实 reduced thermal mass/stiffness 和连续时间 ODE 控制。当前材料模型下 Maxwell operator 不随温度变化，因此固定几何只需一组电磁参数，thermal trajectory 中不重复求解高维 Maxwell 系统。本文同时定义训练前必须通过的 Physics Gate，以保证 surrogate accuracy 建立在物理闭合、离散一致和数值收敛的 truth system 上。
\end{abstract}

\begin{abstract}
本文冻结 SDFMPNEO 的单频生产理论体系。Maxwell truth model 在统一的 $e^{+i\omega t}$ 峰值相量、端口、开放域、物理 source regularization 和离散能量约定下生成复对称场阻抗 $Z_{\rm field}$、总海水体耗散矩阵 $D_{\rm vol}$ 与 thermal-modal Hermitian Joule tensors $H_j$；truth outward power 独立由 Poynting/吸收边界双线性型计算。神经网络仅学习几何到这些低维参数化电磁对象的映射。固定物理解码层保持 reciprocity/Hermitian structure，并联合施加 $D_{\rm vol}\succeq0$、$\operatorname{Herm}(Z_{\rm field})-D_{\rm vol}\succeq0$ 以及 $\phi_j^{\min}D_{\rm vol}\preceq H_j\preceq\phi_j^{\max}D_{\rm vol}$，使端口 passivity、总体耗散与 modal Joule 位于同一矩阵级能量框架。任意复端口电流通过显式 quadratic forms 产生 cycle-averaged heat；若工作点由电压源、补偿网络或负载决定，则由确定性 circuit equations 求取端口电流。温度演化始终由真实 reduced thermal mass/stiffness、明确的 wire-temperature constitutive law 和连续时间 ODE 控制。共享 thermal basis 在最终 $H_j$ 标签之前构建，完整覆盖 quadratic-current source span 与声明的 initial-condition family，并以多时间尺度 resolvent 的能量/dual-norm 相对误差和 completely-held-out full transient audit 验证。本文同时冻结 Physics Gate、误差预算、production domain 与模型适用边界，明确区分能量稳定性、pointwise positivity、局部稳态稳定性和严格证书，保证 surrogate accuracy 建立在物理闭合、离散一致且数值收敛的 truth system 上。
\end{abstract}

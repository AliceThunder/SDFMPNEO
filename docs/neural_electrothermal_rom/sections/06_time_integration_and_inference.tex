\section{时间推进与推理}

\subsection{在线查询的分层顺序}
对一个固定几何 $g$，神经网络首先只调用一次，得到
\begin{equation}
\left\{\widehat Z_{\rm field}(g),\widehat H_1(g),\ldots,\widehat H_r(g)\right\}.
\end{equation}
这些参数在整个 thermal trajectory 中保持不变。随后端口电流 $c$ 通过解析二次型形成体 Joule modal source：
\begin{equation}
\widehat q_{{\rm vol},j}(g,c)
=\operatorname{Re}\!\left(c^H\widehat H_j(g)c\right).
\end{equation}
热状态相关性只通过真实的 $R_{\rm wire}(a,g)$ 进入线圈热源和总阻抗。

\subsection{连续时间热模型}
生产在线模型为
\begin{equation}
\boxed{
M_r(g)\dot a
=-K_r(g)a
+\widehat q_{\rm vol}(g,c)
+q_{\rm wire}(a,g,c)
+f_T(g).
}
\end{equation}
初值 $a(0)=a_0$ 由 ODE 初值严格给定。网络不接收时间，不预测 $a(t)$，也不吸收 $M_r$ 或 $K_r$。

\subsection{端口输出}
总阻抗在任意热状态下为
\begin{equation}
\boxed{
\widehat Z(a,g)
=\widehat Z_{\rm field}(g)+R_{\rm wire}(a,g).
}
\end{equation}
因此场耦合/海水损耗对应的几何依赖与线圈温度电阻效应保持显式分离。平均输入功率由
\begin{equation}
P_{\rm in}(a,g,c)
=\frac12\operatorname{Re}\!\left(c^H\widehat Z(a,g)c\right)
\end{equation}
计算，并可与 thermal heat 和开放域能流 audit 对照。

\subsection{ETD2 与 IMEX}
对固定几何，$M_r(g),K_r(g)$ 在时间上不变。定义
\begin{equation}
L(g)=M_r(g)^{-1}K_r(g).
\end{equation}
中低 thermal rank 下可对 generalized eigenproblem
\begin{equation}
K_rv=\lambda M_rv
\end{equation}
进行一次分解，并复用于整个 trajectory。线性耗散项采用指数推进，非线性部分只包含温度相关 wire resistance 等明确热源项。

默认二阶 ETD predictor-corrector；若矩阵函数或 nonlinear source 处理不合适，则使用
\begin{equation}
(M_r+hK_r)a_{n+1}
=M_ra_n+hq(a_n,g,c)
\end{equation}
的 linearly implicit IMEX 作为稳健备选。数值时间积分误差必须与 surrogate、thermal ROM 和 truth discretization error 分开报告。

\subsection{自适应步长}
自适应 ETD 使用 embedded lower-order estimate 或 step-doubling 控制局部时间误差。步长控制只依赖 thermal integration error，不通过人为限制保证 surrogate 正确性。

对特别长时间查询，允许步长随接近稳态而增大，但必须保持 state-domain 与 constitutive validity 检查。

\subsection{稳态单独求解}
$t=\infty$ 不通过超长时间积分逼近，而直接求
\begin{equation}
\boxed{
-K_r(g)a_*
+\widehat q_{\rm vol}(g,c)
+q_{\rm wire}(a_*,g,c)
+f_T(g)=0.
}
\end{equation}
可采用 Newton、damped Newton 或稳健非线性 root solve。候选稳态必须检查 reduced thermal residual 和温度 constitutive domain。

\subsection{批量几何查询}
对于同一几何的多个时间、电流或初值查询，$\widehat Z_{\rm field}$ 与 $\widehat H_j$ 只计算一次并缓存。对于批量不同几何，可直接批量执行 MLP 与 POD 解码。生产推理的主要成本因此为
\begin{equation}
\text{one geometry NN forward}
+N_t\times(\text{small thermal ROM operations}),
\end{equation}
而不是每个 thermal stage 重复求解高维 Maxwell 系统。

\subsection{未来温度相关 EM 参数的扩展}
若将来引入真正温度相关的海水电导率或介电参数，则代理输入扩展为 $(s_{\rm em},g)$，并在 thermal trajectory 中按需要更新 EM tensors。该扩展必须以 constitutive sensitivity 证明为依据；在当前材料模型下禁止人为引入不存在的热状态依赖。

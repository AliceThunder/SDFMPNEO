\section{Physics Gate：代理训练前的物理与离散验收}

本节定义正式 surrogate training 之前必须通过的底层验证。任一关键 Gate 未通过时，不进入生产训练。

\subsection{Gate 0A：Maxwell formulation、reciprocity 与开放域}
生产 truth model 必须明确验证 constitutive reciprocity、open-boundary treatment、domain convergence 与 low-frequency formulation suitability。在代表性 geometry 上逐步扩大计算域或比较 validated ABC/PML/open-boundary，并监控
\begin{equation}
Z_{\rm field},\qquad D_{\rm vol},\qquad D_{\rm out}^{\rm phys},\qquad \text{mutual impedance},\qquad \text{key fields}.
\end{equation}
若材料或边界破坏 reciprocity，则不得继续硬编码 $Z^T=Z$。

\subsection{Gate 0B：端口定义与独立功率闭合}
冻结 peak-phasor convention、端口方向、source normalization、terminal/feed/return-path 与 reaction-voltage convention。对每个 audit geometry 独立构造
\begin{equation}
D_{\rm vol}=X^HH_\sigma X,
\qquad
D_{\rm out}^{\rm phys}\succeq0,
\end{equation}
并检查
\begin{align}
Z_{\rm field}^T&\approx Z_{\rm field},\\
D_{\rm vol}&\succeq-\varepsilon I,\\
D_{\rm out}^{\rm phys}&\succeq-\varepsilon I,\\
\operatorname{Herm}(Z_{\rm field})&\approx D_{\rm vol}+D_{\rm out}^{\rm phys}.
\end{align}
禁止把 $D_{\rm out}$ 定义成 $\operatorname{Herm}Z-D_{\rm vol}$ 后再声称 truth power balance 已验证。

PML/ABC artificial absorption 属于 outward/domain-truncation power，不进入 physical thermal heat。physical seawater loss、wire/internal loss 与 outward loss 必须互斥分区。

\subsection{Gate 0C：Joule 双线性型与 geometry-dependent modal consistency}
conductivity loss operator 必须由统一 edge-space bilinear form 组装。对当前 geometry 的 thermal mode $\phi_j(g)$：
\begin{equation}
[W_j(g)]_{mn}
=\int_\Omega\sigma(x;g)\phi_j(x;g)N_m\cdot N_n\,dx,
\end{equation}
\begin{equation}
H_j(g)=X(g)^HW_j(g)X(g).
\end{equation}
若 EM/thermal spaces 不同，$\phi_j(g)$ 在 EM quadrature 上的 transfer/interpolation 必须通过 constant-preservation、积分一致性和 mesh-refinement audit。

必须验证
\begin{equation}
\sum_kQ_{{\rm vol},k}
\approx\frac12E^HH_\sigma E,
\end{equation}
\begin{equation}
\phi_j(g)^TQ_{\rm vol}
\approx\frac12\operatorname{Re}(c^HH_j(g)c),
\end{equation}
以及
\begin{equation}
P_{\rm vol}\approx\frac12c^HD_{\rm vol}c.
\end{equation}

对当前 geometry 确定性计算
\begin{equation}
\phi_j^{\min}(g),\qquad\phi_j^{\max}(g),
\end{equation}
并检查 truth 与 surrogate 均满足
\begin{equation}
\boxed{
\phi_j^{\min}(g)D_{\rm vol}(g)
\preceq H_j(g)
\preceq\phi_j^{\max}(g)D_{\rm vol}(g).
}
\end{equation}

\subsection{Gate 0D：source regularization、无双重计损与几何连续性}
每个生产 geometry 必须满足 conductor/package 包封、无非法穿透/最小间隙、边界裕量与 material-fraction closure。source 必须具有明确 terminal orientation 与 continuity interpretation。

零半径 line current 的 self field/self impedance 不能由 mesh size 决定，必须使用与真实 conductor scale 绑定的 finite-support/stranded/regularized source model。若 wire ohmic loss 已由独立 $R_{\rm wire}$ 处理，不得在 $D_{\rm vol}$ 中再次计入同一铜损。

对 $g\to g+\delta g$ 检查 source deposition、material fractions、$Z(g)$、$D_{\rm vol}(g)$、deterministic $\Phi(g)$ 和 $H_j(g)$ 不出现由 midpoint/stencil/mode-index switching 造成的非物理跳跃。

\subsection{Gate 0E：空间离散与 thermal time-resolution consistency}
至少选中心、边界和困难 geometry 做 mesh refinement，监控
\begin{equation}
Z_{\rm field},\quad D_{\rm vol},\quad D_{\rm out}^{\rm phys},\quad H_j(g),\quad P_{\rm vol},\quad T_{\max},\quad a_*.
\end{equation}

thermal basis time-scale policy 必须和 spatial resolution 匹配。对 diffusivity $\alpha$ 与 anchor time $\tau$，若
\begin{equation}
\sqrt{\alpha\tau}\ll h_T
\end{equation}
其中 $h_T$ 是 relevant thermal resolution，则该 anchor 主要在解析离散 source placement。除非应用确实要求且 full-order mesh 已解析该尺度，否则不能把它作为 production basis rank 的硬目标。

\subsection{Gate 0F：geometry-aware thermal basis generator}
正式 thermal approximation 为
\begin{equation}
\boxed{\theta(x,t;g)\approx\Phi(x;g)a(t;g)}
\end{equation}
且首版
\begin{equation}
\boxed{
\Phi(g)=
[\Phi_{\rm bg},\mathcal T_{\rm tx}(g)\Psi_{\rm tx},\mathcal T_{\rm rx}(g)\Psi_{\rm rx}].
}
\end{equation}

Gate 必须验证：
\begin{enumerate}
  \item canonical block ordering 与 mode semantics 跨 geometry 不变；
  \item rigid translation/rotation transport 正确，interpolation/conservative remap 不引入非物理 source/energy drift；
  \item $\Phi(g)$ 对小 geometry perturbation 连续；
  \item 对生产 geometry，$\Phi(g)$ 满列秩；
  \item
  \begin{equation}
  M_r(g)=\Phi(g)^TM_T(g)\Phi(g)\succ0,
  \qquad
  K_r(g)=\Phi(g)^TK_T(g)\Phi(g)\succ0;
  \end{equation}
  \item $M_r/K_r$ conditioning 在目标域内可接受；
  \item size/deformation variation 在首版 rigid transport 下的误差通过 held-out audit；若不通过，再增加 deterministic scale-aware transform。
\end{enumerate}

禁止用 neural network 预测 $\Phi(g)$ 作为首版补丁，也禁止通过一个固定 global basis 逐位置堆热点 mode 来掩盖 transport 失配。

\subsection{Gate 0G：canonical rank、resolvent 与 held-out trajectory}
canonical background/TX/RX modes 的自动 rank 必须覆盖完整 current-induced heat-source span、wire/source patterns、允许的 initial-condition family 与选定的可解析 time scales。

对任意 source/initial-condition resolvent anchor
\begin{equation}
A_su=b,\qquad A_s=K+sM\succ0,
\end{equation}
Galerkin error 使用
\begin{equation}
\boxed{
\eta_s^2
=\frac{r^TA_s^{-1}r}{b^TA_s^{-1}b}
=\frac{\|u-\tilde u\|_{A_s}^2}{\|u\|_{A_s}^2}.
}
\end{equation}

validation 不能只报告一个 worst relative number。必须记录 worst anchor 的 geometry、source type、canonical block、shift/time scale、relative error 与 absolute energy/power scale。

完全 held-out geometries 上必须直接比较 full thermal 与 geometry-aware ROM 的可解析短时、中间时间、长时间和 steady outputs，包括 $T_{\min}$、$T_{\max}$、wire-temperature functional 与关键安全指标。

\subsection{Gate 0H：初值、点值正性与零源耗散}
full initial field 使用当前 geometry 的 $M$-orthogonal projection。只要求 $t=0$ projection error 小不足以保证 homogeneous evolution 精确，必须额外做 trajectory audit。

对静态 geometry 的零源 reduced system
\begin{equation}
M_r\dot a=-K_ra
\end{equation}
定义
\begin{equation}
V(a;g)=\frac12a^TM_r(g)a,
\end{equation}
则
\begin{equation}
\dot V=-a^TK_r(g)a\le0.
\end{equation}
这保证 quadratic dissipativity，不保证 pointwise positivity/maximum principle。生产验证必须监控 $T_{\min}$、$T_{\max}$；若应用要求严格 positivity/bounds，则升级 ROM/integrator。

\subsection{Gate 0I：wire-temperature、steady state 与 circuit feedback}
wire resistance 必须通过明确 conductor-temperature functional
\begin{equation}
\bar\theta_p=\ell_p^{(T)T}(g)\Phi(g)a
\end{equation}
进入 constitutive law。该 functional 必须在 full-vs-ROM audit 中验证。

非线性 steady candidate 必须通过 residual、constitutive-domain 与 closed-loop Jacobian local-stability audit。若存在多个 stable equilibria，$t=\infty$ 语义必须与 initial-condition basin 一致；无法判断时报告 ambiguity。

若实际 system 由 source/load/compensation network 决定 current，则显式接 circuit equations，并检查 near-resonance/high-Q conditioning。若 circuit ring-up time 不再远短于 thermal/envelope time scale，必须引入 circuit dynamic states。

\subsection{Gate 0J：静态 geometry 适用边界}
当前一次 thermal query 默认 geometry 静止。若未来 $g=g(t)$，由于
\begin{equation}
\theta=\Phi(g(t))a(t),
\end{equation}
必须加入
\begin{equation}
\Phi^TM_T\dot\Phi\,a
\end{equation}
等 transport terms，同时更新 geometry-dependent EM tensors 和 reduced operators。忽略该项的“逐步换 basis”不属于当前 validated model。

\subsection{Gate 通过后的冻结对象}
Physics Gate 通过后应冻结并版本化：
\begin{itemize}
  \item frequency、phasor convention、reciprocity assumptions 与 port/reaction-voltage definition；
  \item Maxwell formulation、domain/open-boundary、mesh、source regularization 与 material/loss masks；
  \item $H_\sigma/Z/D_{\rm vol}/D_{\rm out}^{\rm phys}$ extraction；
  \item canonical thermal mode library、local frames、transport/interpolation rule、mode ordering 与 time-scale policy；
  \item $g\mapsto\Phi(g)$ generator、$W_j(g)/H_j(g)$ extraction 与 geometry-dependent modal-bound definition；
  \item thermal full model、coercivity/nullspace/positivity policy、wire-temperature functional、initial-condition family；
  \item $\mathcal G_{\rm prod}$、operating/state domains、current/circuit mode 与 static/dynamic geometry policy。
\end{itemize}
任何上述版本改变都触发 downstream tensor dataset/model invalidation。

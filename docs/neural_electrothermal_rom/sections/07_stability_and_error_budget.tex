\section{稳定性、误差传播与证书层级}

\subsection{误差源必须分层}
最终输出误差不能用单一 neural validation loss 代表。生产系统至少包含
\begin{equation}
\boxed{
E_{\rm total}
\lesssim
E_{\rm model}+E_{\rm domain}+E_{\rm discretization}+E_{\rm solve}
+E_{\rm tensor\,surrogate}+E_{\rm thermal\,ROM}+E_{\rm transport}
+E_{\rm init}+E_{\rm time}.
}
\end{equation}
其中新增的
\begin{equation}
E_{\rm transport}
\end{equation}
专门表示 deterministic geometry-aware basis transport/interpolation、local-frame mapping 和必要时的 scale/deformation approximation 误差。它不能混入 neural surrogate error。

\subsection{Joule tensor 误差到 reduced source 误差}
令
\begin{equation}
\Delta H_j(g)=\widehat H_j(g)-H_j(g).
\end{equation}
任意端口电流 $c$ 下
\begin{equation}
\left|\widehat q_{{\rm vol},j}-q_{{\rm vol},j}\right|
\le\frac12\|\Delta H_j(g)\|_2\|c\|_2^2.
\end{equation}
因此 current-controlled operating domain 给定 $\|c\|\le C_c$ 时，可直接得到 modal-source bound。完整 source-vector error 还必须与当前 geometry 的 reduced norm 和 $M_r(g)$ conditioning 一起传播。

\subsection{阻抗、总耗散与 outward loss}
令
\begin{equation}
\Delta D=\widehat D_{\rm vol}-D_{\rm vol},
\qquad
\Delta Z=\widehat Z_{\rm field}-Z_{\rm field}.
\end{equation}
有
\begin{equation}
|\Delta P_{\rm vol}|\le\frac12\|\Delta D\|_2\|c\|_2^2,
\end{equation}
\begin{equation}
\|\Delta v_{\rm field}\|_2\le\|\Delta Z\|_2\|c\|_2.
\end{equation}

联合可行层保证
\begin{equation}
\widehat D_{\rm vol}\succeq0,
\qquad
\widehat D_{\rm out}^{\rm imp}
=\operatorname{Herm}(\widehat Z)-\widehat D_{\rm vol}\succeq0,
\end{equation}
但 $\widehat D_{\rm out}^{\rm imp}$ 仍必须与独立 truth $D_{\rm out}^{\rm phys}$ 比较。

\subsection{geometry-aware basis 本身的误差}
真实 thermal field 与 ROM reconstruction 写成
\begin{equation}
\theta(t;g)=\Phi(g)a(t;g)+\theta_{\rm tail}(t;g).
\end{equation}
$\theta_{\rm tail}$ 现在包含至少三类来源：
\begin{itemize}
  \item canonical background/local mode truncation；
  \item rigid transport/interpolation 不足；
  \item 当前首版未显式建模的 size/deformation dependence。
\end{itemize}
因此 held-out geometry 上出现 thermal error 时，必须先分解它属于 canonical rank 还是 transport/model mismatch，而不是一律通过增加 global modes 处理。

生产域内必须检查
\begin{equation}
\lambda_{\min}(M_r(g))>0,
\qquad
\lambda_{\min}(K_r(g))>0,
\end{equation}
并监控 condition numbers。若 $\Phi(g)$ 在某些 geometry 上接近线性相关，则即使 full-order thermal system 良态，reduced coordinates 也会放大误差；这种问题属于 basis-generator error，不属于 neural error。

\subsection{resolvent error 与 time-scale interpretation}
对任意 source/initial-condition anchor
\begin{equation}
A_su=b,
\qquad A_s=K+sM\succ0,
\end{equation}
Galerkin approximation $\tilde u$ 满足
\begin{equation}
\boxed{
\frac{\|u-\tilde u\|_{A_s}^2}{\|u\|_{A_s}^2}
=\frac{r^TA_s^{-1}r}{b^TA_s^{-1}b}.
}
\end{equation}
该量是 anchor-level relative energy error，但必须结合 anchor 的绝对能量、source norm 或相关 power scale 解读。一个绝对功率极小的方向即使 relative error 接近 1，也不能自动被等同于主工程工况误差。

此外，只有在 $\sqrt{\alpha\tau}$ 与 thermal mesh 可解析尺度相容时，$s=1/\tau$ anchor 才能被解释为可解析 thermal dynamics 的有效约束。极短时间若主要反映离散 source placement，应归入 discretization/transport diagnosis，而不是强迫 ROM 通过堆 rank 拟合。

\subsection{trajectory error 才是生产 thermal 指标}
resolvent anchors 不是全时间 certificate。完全 held-out geometries 上必须直接比较 full thermal 与 geometry-aware ROM 的
\begin{equation}
T(x,t),\quad T_{\min}(t),\quad T_{\max}(t),\quad \bar T_{\rm wire}(t),\quad a_*,
\end{equation}
至少覆盖可解析短时、中间时间、长时间和 steady state。

长时间 finite-horizon error 来自同一个 reduced ODE 的连续积分误差传播，不需要用一个与查询 horizon 数值相同的 resolvent anchor 单独定义。steady limit 由 $s=0$ anchor、trajectory audit 与稳定 equilibrium audit共同约束。

\subsection{current-controlled thermal dynamics 的误差传播}
对同一 geometry-aware ROM，truth reduced model 为
\begin{equation}
M_r\dot a=-K_ra+q_{\rm vol}+q_{\rm wire}+f_T,
\end{equation}
代理仅改变 $q_{\rm vol}$。若
\begin{equation}
F(a)=M_r^{-1}[-K_ra+q_{\rm wire}(a,g,c)+f_T]
\end{equation}
在目标 state domain 内具有 Lipschitz constant $L_F$，且
\begin{equation}
\|M_r^{-1}(\widehat q_{\rm vol}-q_{\rm vol})\|\le\varepsilon_F,
\end{equation}
则标准扰动界给出
\begin{equation}
\|e(t)\|
\le e^{L_Ft}\|e(0)\|
+\begin{cases}
\varepsilon_F\dfrac{e^{L_Ft}-1}{L_F},&L_F>0,\\
\varepsilon_F t,&L_F=0.
\end{cases}
\end{equation}
该 bound 只覆盖 tensor-source perturbation；basis truncation/transport、full initial projection、time integration 等误差必须另外计入。

\subsection{circuit-controlled 模式}
若
\begin{equation}
A_c(a,g)c=v_{\rm src},
\qquad
A_c=Z_{\rm field}+R_{\rm wire}+Z_{\rm ext},
\end{equation}
则 surrogate impedance error 先改变 $c$，再通过 quadratic Joule map 影响热源。near-resonance/high-Q 时 circuit conditioning 必须显式进入 error budget。

\subsection{零源耗散与稳定性}
对静态 geometry，若 $M_r(g),K_r(g)\succ0$，定义
\begin{equation}
V(a;g)=\frac12a^TM_r(g)a,
\end{equation}
则零源系统满足
\begin{equation}
\dot V=-a^TK_r(g)a\le0.
\end{equation}
这保证 reduced zero-source dissipativity，但不保证 pointwise positivity、maximum principle 或 closed-loop global stability。

如果 geometry 随时间变化，则 $M_r(g(t))$ 与 basis transport 会引入额外项，上述静态 Lyapunov identity 不能直接照搬。

\subsection{输出误差}
对静态 geometry：
\begin{equation}
T=T_{\rm amb}+\Phi(g)a+T_{\rm tail},
\end{equation}
故
\begin{equation}
\|\widehat T-T\|_\infty
\le\|\Phi(g)\|_{2\to\infty}\|\hat a-a\|_2
+\|T_{\rm tail}\|_\infty
+E_{\rm time,T}.
\end{equation}
其中 $T_{\rm tail}$ 必须显式包含 canonical truncation、transport/interpolation 与 initial-condition tail，不能默认为零。

\subsection{证书层级}
所有 ``certificate'' 或 ``validated'' 字样必须区分：
\begin{enumerate}
  \item 严格证书：数学上覆盖完整声明参数域且前提已验证；
  \item 条件定理：只在 stated assumptions 成立时生效；
  \item 冻结测试验证：有限 held-out geometry/current/state/circuit/initial-condition set 上的最大误差；
  \item 经验诊断：POD 谱、training/validation loss、projection correction、basis conditioning 等。
\end{enumerate}
Physics Gate 和 held-out trajectory audit 通常属于冻结数值验证，不得自动升级为全域严格证书。

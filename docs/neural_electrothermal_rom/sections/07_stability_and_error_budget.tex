\section{稳定性、误差传播与证书层级}

\subsection{误差源必须分层}
最终输出误差不能用单一 neural validation loss 代表。生产系统至少包含
\begin{equation}
\boxed{
E_{\rm total}
\lesssim
E_{\rm model}
+E_{\rm domain}
+E_{\rm discretization}
+E_{\rm solve}
+E_{\rm tensor\,surrogate}
+E_{\rm thermal\,ROM}
+E_{\rm init}
+E_{\rm time}.
}
\end{equation}
其中：
\begin{itemize}
  \item $E_{\rm model}$：filament/stranded conductor approximation、physical source regularization、材料 constitutive law、wire impedance/resistance、feed/return path、热边界/流体简化与 quasi-steady circuit assumption 等模型误差；
  \item $E_{\rm domain}$：有限电磁/热计算域和边界截断误差；
  \item $E_{\rm discretization}$：Maxwell/thermal 空间离散、几何 deposition、quadrature 与跨空间 transfer 误差；
  \item $E_{\rm solve}$：truth linear/nonlinear/circuit solve 的代数误差；
  \item $E_{\rm tensor\,surrogate}$：$Z/D_{\rm vol}/H$ 参数代理、POD 与可行投影带来的误差；
  \item $E_{\rm thermal\,ROM}$：thermal subspace/projection/truncation error；
  \item $E_{\rm init}$：full initial field 到 ROM 的投影误差及其 homogeneous-response 传播；
  \item $E_{\rm time}$：ETD/IMEX 等时间离散误差。
\end{itemize}
不同量纲和范数的误差不能直接数值相加；上式表示经相应稳定性/敏感度常数传播后的结构化预算。

\subsection{Joule tensor 误差到 thermal source 误差}
令
\begin{equation}
\Delta H_j=\widehat H_j-H_j.
\end{equation}
由于采用峰值 phasor，任意端口电流 $c$ 下
\begin{equation}
\left|\widehat q_{{\rm vol},j}-q_{{\rm vol},j}\right|
=\frac12\left|\operatorname{Re}(c^H\Delta H_jc)\right|
\le \frac12\|\Delta H_j\|_2\,\|c\|_2^2.
\end{equation}
因此只要 current-controlled operating domain 给出 $\|c\|\le C_c$，tensor operator-norm error 就直接给出整个 complex current space 的 modal-source error bound。对完整 reduced source vector 的界应按所选 reduced norm 对各 modal bounds 组合，不能把单模态 bound 直接当成全向量误差。

\subsection{总耗散、outward loss 与阻抗代理误差}
令
\begin{equation}
\Delta D=\widehat D_{\rm vol}-D_{\rm vol},
\qquad
\Delta Z=\widehat Z_{\rm field}-Z_{\rm field}.
\end{equation}
则
\begin{equation}
\left|\Delta P_{\rm vol}\right|
\le\frac12\|\Delta D\|_2\|c\|_2^2,
\end{equation}
且
\begin{equation}
\|\Delta v_{\rm field}\|_2
\le\|\Delta Z\|_2\|c\|_2,
\end{equation}
\begin{equation}
\left|\Delta P_{\rm field}\right|
\le\frac12\|\operatorname{Herm}(\Delta Z)\|_2\|c\|_2^2.
\end{equation}

联合可行层按构造保证
\begin{equation}
\widehat D_{\rm vol}\succeq0,
\qquad
\widehat D_{\rm out}^{\rm imp}
=\operatorname{Herm}(\widehat Z_{\rm field})-\widehat D_{\rm vol}\succeq0,
\end{equation}
但 $\widehat D_{\rm out}^{\rm imp}$ 不是 truth outward power 的定义。validation/audit 必须与独立 $D_{\rm out}^{\rm phys}$ 比较，并把
\begin{equation}
\|\widehat D_{\rm out}^{\rm imp}-D_{\rm out}^{\rm phys}\|
\end{equation}
和 projection correction $\delta_{\rm proj}$ 一并纳入 $E_{\rm tensor\,surrogate}$。大 projection correction 说明 raw surrogate 偏离物理可行集，不能因最终输出被投影后“合法”就忽略该误差。

线圈电阻/内部阻抗模型误差归入 constitutive/model error，不与 field-tensor neural error 混合。

\subsection{current-controlled thermal dynamics 的误差传播}
在相同 thermal ROM 与 wire model 下，truth reduced model 为
\begin{equation}
M\dot a=-Ka+q_{\rm vol}(g,c)+q_{\rm wire}(a,g,c)+f_T,
\end{equation}
代理模型只把 $q_{\rm vol}$ 换成 $\widehat q_{\rm vol}$。令 $e=\hat a-a$。若目标 state domain 内
\begin{equation}
F(a)=M^{-1}\left[-Ka+q_{\rm wire}(a,g,c)+f_T\right]
\end{equation}
具有 Lipschitz constant $L_F$，并满足
\begin{equation}
\|M^{-1}(\widehat q_{\rm vol}-q_{\rm vol})\|\le\varepsilon_F,
\end{equation}
则一般初始误差下
\begin{equation}
\boxed{
\|e(t)\|
\le
 e^{L_Ft}\|e(0)\|
+
\begin{cases}
\varepsilon_F\dfrac{e^{L_Ft}-1}{L_F},&L_F>0,\\[0.7em]
\varepsilon_F t,&L_F=0.
\end{cases}
}
\end{equation}
当两个 reduced models 使用同一 $a_0$ 时 $e(0)=0$；full initial field 的 projection/tail error 属于 $E_{\rm init}$ 与 $E_{\rm thermal\,ROM}$，不能混入 tensor-source bound。

这是 current-controlled、相同 ROM/constitutive model 下的 tensor-source propagation bound，不包含 model/domain/discretization/ROM/time errors。

\subsection{circuit-controlled 模式必须单独传播 $Z\to c\to q$}
若端口电流由
\begin{equation}
A_c(a,g)c=v_{\rm src},
\qquad
A_c=Z_{\rm field}+R_{\rm wire}(a,g)+Z_{\rm ext}
\end{equation}
决定，则 surrogate impedance error 会先改变 $c$。若 truth circuit matrix 可逆且
\begin{equation}
\|A_c^{-1}\Delta Z\|<1,
\end{equation}
可使用标准线性系统扰动界控制 $\|\widehat c-c\|$；该电流误差随后通过 quadratic Joule map 进入 $q_{\rm vol}$ 和 $q_{\rm wire}$。因此 circuit-controlled 误差预算必须显式包含 circuit conditioning/sensitivity，不能直接套用固定 $c$ 的上式。

接近谐振或高-Q operating point 时，$A_c$ 可能对 $Z$ 误差非常敏感；这是系统物理灵敏度，而不是 neural loss 本身能够消除的问题。若实际 circuit ring-up/settling time 与 thermal/envelope time scale 不再分离，则代数 phasor circuit solve 本身产生额外 $E_{\rm model}$；此时必须显式引入 circuit dynamic states。

\subsection{收缩情形}
若真实 reduced thermal/circuit dynamics 在目标域某能量范数下满足
\begin{equation}
\mu(J_F)\le-\gamma<0,
\end{equation}
则对应扰动可得到长期饱和型界。只有在真实 wire-heating feedback、circuit feedback 与 thermal operators 上验证该条件后，才允许宣称长期 contraction；不能因为扩散项本身耗散就默认整个电热系统 contractive。

\subsection{thermal ROM anchor error 与 trajectory error}
对任意 source/initial-condition resolvent anchor
\begin{equation}
A_su=b,
\qquad A_s=K+sM\succ0,
\end{equation}
Galerkin approximation $\tilde u=\Phi a$ 与 residual $r=b-A_s\tilde u$ 满足
\begin{equation}
\boxed{
\frac{\|u-\tilde u\|_{A_s}^2}{\|u\|_{A_s}^2}
=
\frac{r^TA_s^{-1}r}{b^TA_s^{-1}b}.
}
\end{equation}
因此这一 energy/dual-norm ratio 是 anchor-level relative solution error；未经尺度化的 Euclidean residual 不是 mesh/shift-independent 的相对解误差证书。

这些 resolvent anchors 比只检查 $K^{-1}Q$ 和 $M^{-1}Q$ 两个端点更接近完整 transient transfer behavior，但仍不是全时间严格证书。冻结 audit geometries 上必须直接比较 full thermal 与 reduced thermal 的允许 initial-condition family、短时、中间时间、长期/稳态温度与最大温升；trajectory discrepancy 是 $E_{\rm thermal\,ROM}$ 与 $E_{\rm init}$ 的主要生产验证量。

\subsection{输出误差}
若 full thermal field 写成
\begin{equation}
T=T_{\rm amb}+\Phi a+T_{\rm tail},
\end{equation}
则
\begin{equation}
\|\widehat T-T\|_\infty
\le
\|\Phi\|_{2\to\infty}\|e\|_2
+\|T_{\rm tail}\|_\infty
+E_{\rm time,T},
\end{equation}
其中 $T_{\rm tail}$ 必须明确包含 ROM truncation 与 initial-condition/full-order components，不得把未知 tail 默认为零。各项必须对应同一明确 norm/normalization。阻抗误差由 field surrogate 与 wire-impedance model 分开管理。

\subsection{证书层级}
所有 ``certificate'' 或 ``validated'' 字样必须区分：
\begin{enumerate}
  \item \textbf{严格证书：}数学上覆盖完整声明参数域且前提已验证；
  \item \textbf{条件定理：}例如 perturbation/contraction/energy-norm bound，只在条件成立时生效；
  \item \textbf{冻结测试验证：}有限 geometry/current/state/circuit/initial-condition test set 上的最大误差；
  \item \textbf{经验诊断：}POD 谱、训练/验证 loss、sampling envelope、projection correction 等。
\end{enumerate}
Physics Gate 的数值收敛实验通常属于冻结验证或数值证据，不得自动升级为全域严格证书。

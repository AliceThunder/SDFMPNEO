\section{低维参数化电磁代理}

\subsection{网络学习对象}
在当前材料模型和冻结工作频率下，昂贵电磁依赖只来自几何 $g$。因此网络不学习场 $X$，也不学习时间或端口电流，而只学习低维参数化物理对象
\begin{equation}
\boxed{
 g\longmapsto
 \left\{Z_{\rm field}(g),D_{\rm vol}(g),H_1(g),\ldots,H_r(g)\right\}.
}
\end{equation}
其中 $D_{\rm vol}$ 是总海水体耗散矩阵，$H_j$ 是 thermal modal Joule tensors。若未来存在真实的温度相关电磁 constitutive state，则输入仅扩展为 $(s_{\rm em},g)$。

\subsection{结构保持的输出编码}
对 reciprocal 系统，$Z_{\rm field}$ 为复对称矩阵；$D_{\rm vol}$ 与每个 $H_j$ 为复 Hermitian 矩阵。物理结构要求
\begin{equation}
Z_{\rm field}^T=Z_{\rm field},
\qquad
D_{\rm vol}=D_{\rm vol}^H\succeq0,
\qquad
H_j=H_j^H,
\end{equation}
并要求
\begin{equation}
\operatorname{Herm}(Z_{\rm field})-D_{\rm vol}\succeq0,
\end{equation}
使剩余实功率可以解释为非负开放域/吸收边界外流功率。

单独的 $H_j$ 因 thermal mode 可变号而一般不要求 PSD；禁止把全部 $H_j$ 强制成 Cholesky 形式。

定义固定结构化编码
\begin{equation}
y(g)=\mathcal E\!\left(Z_{\rm field},D_{\rm vol},H_1,\ldots,H_r\right)\in\R^{d_y},
\end{equation}
其中仅保存独立自由度：复对称 $Z$ 的上三角实/虚部，以及 Hermitian matrices 的实对角和严格上三角实/虚部。

\subsection{POD 是压缩，不负责创造物理可行性}
对 training truth snapshots 的结构化向量做中心化 POD/SVD：
\begin{equation}
y(g)\approx \bar y+U_K\beta(g),
\qquad U_K^TU_K=I.
\end{equation}
网络只学习
\begin{equation}
\boxed{
\beta_\theta:g\mapsto\R^K.
}
\end{equation}
如果 $y(g)$ 没有足够快的谱衰减，可以提高 $K$、采用分块 POD，或直接预测完整结构化 $y$；这不会改变系统架构。

普通线性 POD 并不自动保持 PSD cone 或联合能量可行集，因此不允许仅凭 latent reconstruction 宣称输出物理合法。结构化矩阵解码后还必须经过固定的物理可行层。

\subsection{联合物理可行层}
令 raw decode 得到
\begin{equation}
(\widetilde Z,\widetilde D_{\rm vol},\widetilde H_j).
\end{equation}
首先按代数结构精确恢复
\begin{equation}
\widetilde Z^T=\widetilde Z,
\qquad
\widetilde D_{\rm vol}=\widetilde D_{\rm vol}^H,
\qquad
\widetilde H_j=\widetilde H_j^H.
\end{equation}
随后对端口耗散块执行确定性的联合可行集映射/投影
\begin{equation}
(\widetilde Z,\widetilde D_{\rm vol})
\mapsto
(\widehat Z,\widehat D_{\rm vol})
\end{equation}
使
\begin{equation}
\boxed{
\widehat D_{\rm vol}\succeq0,
\qquad
\operatorname{Herm}(\widehat Z)-\widehat D_{\rm vol}\succeq0.
}
\end{equation}
对当前小端口数，该投影成本可忽略。它必须使用固定数学定义，并与模型一起版本化。

定义 projection correction diagnostic
\begin{equation}
\delta_{\rm proj}
=\left\|(\widehat Z,\widehat D_{\rm vol})
-(\widetilde Z,\widetilde D_{\rm vol})\right\|.
\end{equation}
生产模型要求 validation/test 上 $\delta_{\rm proj}$ 足够小。可行集投影是安全层，不允许成为掩盖大 surrogate error 的主要修正器。

\subsection{几何输入表示}
几何输入只包含定义生产参数域所需的独立变量，并使用由训练域固定的中心和尺度归一化。普通长度/位移参数可使用
\begin{equation}
\tilde g_k=\frac{g_k-c_k}{s_k}.
\end{equation}
离散 shape 类型使用明确的离散编码。

旋转变量不得在跨越周期边界时直接使用裸 Euler angle 标量。例如 yaw 覆盖 $[-\pi,\pi]$ 时，应采用 $(\sin\psi,\cos\psi)$、连续 quaternion/rotation-matrix 表示或其他无分支跳变的姿态编码。若使用 quaternion，必须固定等价符号约定，避免 $q$ 与 $-q$ 形成训练不连续。

归一化与姿态编码元数据必须随模型保存，推理时禁止重新估计。如果几何到离散 truth operator 的映射因 source deposition 或 material voxelization 出现人为跳变，应先修正底层几何离散，而不是让网络增加容量去拟合数值 staircasing。

\subsection{默认神经网络}
首版使用普通 residual MLP：
\begin{align}
h_0 &= W_{\rm in}\tilde g+b_{\rm in},\\
h_{\ell+1}
&=h_\ell+W_{\ell,2}\,\sigma(W_{\ell,1}h_\ell+b_{\ell,1}),\\
\beta_\theta&=W_{\rm out}h_L+b_{\rm out},
\end{align}
默认 $\sigma=\operatorname{SiLU}$。网络容量由 validation/test 误差和推理成本选择，不承担 Maxwell 或 thermal 方程本身。

\subsection{物理重构层}
网络输出经过 POD 解码、结构化矩阵解码和联合可行层得到
\begin{equation}
\left\{\widehat Z_{\rm field},\widehat D_{\rm vol},\widehat H_1,\ldots,\widehat H_r\right\}.
\end{equation}
任意复端口峰值电流 $c$ 的体 Joule modal source 为
\begin{equation}
\widehat q_{{\rm vol},j}(g,c)
=\frac12\operatorname{Re}\!\left(c^H\widehat H_j(g)c\right),
\end{equation}
体总损耗为
\begin{equation}
\widehat P_{\rm vol}(g,c)
=\frac12 c^H\widehat D_{\rm vol}(g)c,
\end{equation}
总阻抗为
\begin{equation}
\widehat Z(a,g)=\widehat Z_{\rm field}(g)+R_{\rm wire}(a,g).
\end{equation}
因此 current magnitude、relative phase、quadratic scaling 与 wire-resistance thermal dependence 均由显式物理层处理，不由网络学习。

\subsection{联合可行性仍不等价于 exact truth}
联合可行层保证了 reciprocal structure、Hermitian structure、非负体耗散和非负 implied outward loss，但它不能保证 $\widehat H_j$ 等于真实空间 Joule projection，也不能保证 surrogate 与 truth 的 $D_{\rm out}$ 数值相同。因此 production validation 仍必须比较 $Z$、$D_{\rm vol}$、$H_j$、current contractions、trajectory outputs 以及 projection correction；结构正确不等于数值误差为零。

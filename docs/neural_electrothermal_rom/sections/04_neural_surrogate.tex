\section{低维参数化电磁代理}

\subsection{网络学习对象}
当前材料模型和冻结工作频率下，昂贵电磁依赖主要来自几何 $g$。网络不学习场 $X$、时间、端口电流、thermal basis 或 thermal operators，而只学习固定维度的参数化物理对象
\begin{equation}
\boxed{
 g\longmapsto
 \{Z_{\rm field}(g),D_{\rm vol}(g),H_1(g),\ldots,H_r(g)\}.
}
\end{equation}
这里 fixed output dimension 来自冻结的 canonical thermal mode ordering。虽然每个空间 mode $\phi_j(x;g)$ 随几何确定性变化，但 mode index $j$ 在所有 geometry 上具有相同物理语义。

\subsection{结构保持输出编码}
对 reciprocal 系统，$Z_{\rm field}$ 为复对称矩阵；$D_{\rm vol}$ 与每个 $H_j$ 为复 Hermitian 矩阵。结构要求
\begin{equation}
Z_{\rm field}^T=Z_{\rm field},
\qquad
D_{\rm vol}=D_{\rm vol}^H\succeq0,
\qquad
H_j=H_j^H,
\end{equation}
并要求
\begin{equation}
\operatorname{Herm}(Z_{\rm field})-D_{\rm vol}\succeq0.
\end{equation}

对当前 geometry，由 deterministic thermal basis generator 得到 $\phi_j(g)$，并在 conductivity-loss support 上计算
\begin{equation}
\phi_j^{\min}(g),\qquad\phi_j^{\max}(g).
\end{equation}
因此还必须满足
\begin{equation}
\boxed{
\phi_j^{\min}(g)D_{\rm vol}(g)
\preceq H_j(g)
\preceq
\phi_j^{\max}(g)D_{\rm vol}(g).
}
\end{equation}
这些 bounds 是 deterministic geometry-derived metadata，而不是 neural output，也不是全局固定常数。

定义结构化编码
\begin{equation}
y(g)=\mathcal E\!\left(Z_{\rm field},D_{\rm vol},H_1,\ldots,H_r\right)\in\R^{d_y},
\end{equation}
只保存独立自由度：复对称矩阵上三角实/虚部，以及 Hermitian matrices 的实对角和严格上三角实/虚部。

\subsection{POD 只做压缩}
只用 training truth snapshots 对 $y(g)$ 做中心化 POD/SVD：
\begin{equation}
y(g)\approx\bar y+U_K\beta(g),\qquad U_K^TU_K=I,
\end{equation}
网络学习
\begin{equation}
\boxed{\beta_\theta:g\mapsto\R^K.}
\end{equation}
若谱衰减不好，可提高 $K$、分块 POD 或直接预测完整结构化 $y$。POD 不负责创造 PSD、Loewner 或 passivity structure。

\subsection{geometry input 与 production domain}
几何输入只包含生产参数域的独立变量，并用 training domain 固定的尺度归一化。旋转变量必须使用连续编码，例如 $(\sin\psi,\cos\psi)$、规范化 quaternion 或 rotation-matrix representation，禁止跨越 $\pm\pi$ 时直接使用有分支跳变的裸 angle 标量。

必须冻结 validated geometry domain $\mathcal G_{\rm prod}$。推理进入网络和 thermal basis generator 前都执行 geometry feasibility/domain check。域外点不能继承 validated accuracy 声明。

\subsection{默认网络}
首版使用普通 residual MLP：
\begin{align}
h_0 &= W_{\rm in}\tilde g+b_{\rm in},\\
h_{\ell+1}
&=h_\ell+W_{\ell,2}\,\sigma(W_{\ell,1}h_\ell+b_{\ell,1}),\\
\beta_\theta&=W_{\rm out}h_L+b_{\rm out},
\end{align}
默认 $\sigma=\operatorname{SiLU}$。网络容量由 held-out error 与推理成本选择，不承担 Maxwell、thermal 或 circuit 方程本身。

\subsection{联合物理可行层}
raw decode 得到 $(\widetilde Z,\widetilde D,\widetilde H_j)$ 后，先精确恢复 reciprocal/Hermitian algebraic structure。对
\begin{equation}
\widetilde Z=\widetilde R+i\widetilde X,
\end{equation}
physical feasibility layer 只修正耗散/modal blocks，使
\begin{equation}
\widehat D\succeq0,
\qquad
\widehat R-\widehat D\succeq0,
\end{equation}
以及
\begin{equation}
\boxed{
\phi_j^{\min}(g)\widehat D
\preceq\widehat H_j
\preceq\phi_j^{\max}(g)\widehat D.
}
\end{equation}
reactive block 保持 $\widehat X=\widetilde X$。对当前小端口数可用低维 convex projection 或经验证的等价解析/分步算法。

必须分别报告 $(Z,D)$ 与 $H$ projection correction。可行层是安全结构，不允许成为掩盖大 regression error 的主要修正器。

\subsection{与 geometry-aware thermal basis 的接口}
在线推理顺序固定为：
\begin{enumerate}
  \item deterministic basis generator 先由 $g$ 构造 $\Phi(g)$ 与 $\phi_j^{\min/\max}(g)$；
  \item MLP/POD decode 得到 raw $Z/D/H$；
  \item 使用当前 geometry 的 modal bounds 做 physical feasibility projection；
  \item 用
  \begin{equation}
  \widehat q_{{\rm vol},j}(g,c)
  =\frac12\operatorname{Re}(c^H\widehat H_j(g)c)
  \end{equation}
  形成 reduced thermal source；
  \item $M_r(g),K_r(g)$ 由真实 thermal operators 与 $\Phi(g)$ 投影得到。
\end{enumerate}
因此 network 与 thermal basis generator 是两个并行的 geometry-dependent maps：前者学习复杂 EM tensor dependence，后者执行已知的 deterministic geometry transport。

\subsection{联合可行性不等于 exact spatial realizability}
reciprocity、PSD、implied outward-loss nonnegativity 与 modal Loewner bounds 都是强必要结构，但仍不是“存在一个与所有预测 $H_j$ 完全一致的精确非负空间 Joule density”的充分证明。production validation 仍必须比较 truth $Z/D/H$、current contractions、independent outward power、thermal trajectories 与 projection corrections。

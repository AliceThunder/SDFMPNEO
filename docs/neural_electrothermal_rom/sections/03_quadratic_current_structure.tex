\section{端口阻抗、Joule 二次型与离散功率守恒}

\subsection{端口基响应与 reaction voltage}
令端口峰值复电流相量为 $c\in\C^{n_p}$，正式 source-shape 矩阵为实值 $S(g)$。在 $e^{+i\omega t}$ 约定下
\begin{equation}
B(g)=-i\omega S(g),\qquad A_{\rm em}(g)X(g)=B(g),
\end{equation}
任意端口电流下的场为 $E=X(g)c$。

定义 generalized reaction voltage
\begin{equation}
\boxed{v_{\rm field}=-S(g)^TE,}
\end{equation}
于是
\begin{equation}
\boxed{Z_{\rm field}(g)=-S(g)^TX(g).}
\end{equation}
只有 terminal/feed-return/source normalization 已独立校准时才把它解释为实验/电路意义的 terminal voltage。

若线圈采用独立集中 AC resistance model，总端口阻抗为
\begin{equation}
Z(a,g)=Z_{\rm field}(g)+R_{\rm wire}(a,g).
\end{equation}
在 reciprocal material/boundary 与一致端口定义下应有 $Z_{\rm field}^T=Z_{\rm field}$；被动系统要求 $\operatorname{Herm}(Z_{\rm field})\succeq0$。

\subsection{总海水体耗散矩阵}
conductivity loss bilinear form 定义为
\begin{equation}
[H_\sigma(g)]_{mn}
=\int_\Omega\sigma(x;g)N_m(x)\cdot N_n(x)\,\mathrm dx,
\end{equation}
或与 Maxwell 组装完全一致的 Hodge/quadrature 形式。于是
\begin{equation}
\boxed{D_{\rm vol}(g)=X(g)^HH_\sigma(g)X(g)\succeq0,}
\end{equation}
并有
\begin{equation}
\boxed{P_{\rm vol}(g,c)=\frac12c^HD_{\rm vol}(g)c.}
\end{equation}
$D_{\rm vol}$ 必须由与 Maxwell 相同的 loss operator 构造。

\subsection{Geometry-aware thermal modes 与 modal Joule tensors}
第 $j$ 个 thermal mode 现在是当前 geometry 下的确定性函数
\begin{equation}
\phi_j(x;g),
\end{equation}
其 mode index 来自冻结的 canonical ordering。不能把不同 geometry 上未对齐的 POD/eigenmodes 直接都叫作同一个 $j$。

对当前 mode 用与 $H_\sigma$ 相同的 FE basis/quadrature 直接组装加权 conductivity bilinear form
\begin{equation}
\boxed{
[W_j(g)]_{mn}
=\int_\Omega\sigma(x;g)\phi_j(x;g)N_m(x)\cdot N_n(x)\,\mathrm dx.
}
\end{equation}
因此 $W_j(g)=W_j(g)^H$，但当 $\phi_j$ 变号时一般不 PSD。

定义
\begin{equation}
\boxed{H_j(g)=X(g)^HW_j(g)X(g),}
\end{equation}
故 $H_j(g)=H_j(g)^H$。任意 complex current 下的 reduced volume Joule source 为
\begin{equation}
\boxed{
q_{{\rm vol},j}(g,c)
=\frac12\operatorname{Re}(c^HH_j(g)c).
}
\end{equation}
不能在构造 $H_j$ 时提前取实部，因为 Hermitian matrix 的虚反对称 part 会参与多端口相位相关的 modal power。

若取 test function $\phi\equiv1$，对应 weighted operator 必须退化为 $H_\sigma$；这是 modal Joule 与总 volume loss 的离散一致性检查。

\subsection{Geometry-dependent Loewner 必要约束}
令当前 geometry 下 mode 在实际 conductivity-loss quadrature/support 上的极值为
\begin{equation}
\phi_j^{\min}(g),\qquad\phi_j^{\max}(g).
\end{equation}
由于逐点有
\begin{equation}
\phi_j^{\min}(g)\le\phi_j(x;g)\le\phi_j^{\max}(g),
\end{equation}
可得
\begin{equation}
\boxed{
\phi_j^{\min}(g)D_{\rm vol}(g)
\preceq H_j(g)
\preceq
\phi_j^{\max}(g)D_{\rm vol}(g).
}
\end{equation}
等价地，对任意 $c$：
\begin{equation}
\phi_j^{\min}(g)P_{\rm vol}(g,c)
\le q_{{\rm vol},j}(g,c)
\le\phi_j^{\max}(g)P_{\rm vol}(g,c).
\end{equation}

这些 bounds 是 geometry-aware basis generator 的确定性输出，而不是一个跨全几何域冻结的常数表。若 rigid transport 在连续空间中严格保持幅值，极值可能不变；但在有限 domain、material support 和 interpolation 后仍应按当前 geometry 重新计算，而不是依赖该理想化不变性。

$D_{\rm vol}$ 仍不能一般由有限个 $H_j$ 求和恢复，因为 thermal modes 不构成常数函数 partition of unity。

\subsection{线圈集中电阻热}
若第 $p$ 个端口电阻为 $R_p(a,g)$，归一化 wire heat distribution 为 $\ell_p^{(Q)}(g)$，则
\begin{equation}
Q_{\rm wire}
=\sum_p\frac12R_p(a,g)|c_p|^2\ell_p^{(Q)}(g).
\end{equation}
投影到当前 geometry basis 后
\begin{equation}
[q_{\rm wire}]_j
=\phi_j(g)^TQ_{\rm wire}.
\end{equation}
wire heat、volume Joule 与 outward power 必须采用互斥物理分区，禁止 double counting。

\subsection{开放域 outward-loss matrix 必须独立计算}
开放电磁域的 outward power 写成
\begin{equation}
P_{\rm out}(g,c)=\frac12c^HD_{\rm out}^{\rm phys}(g)c,
\qquad D_{\rm out}^{\rm phys}=D_{\rm out}^{\rm phys,H}\succeq0.
\end{equation}
$D_{\rm out}^{\rm phys}$ 必须由 independent boundary Poynting form、absorbing-boundary operator 或 PML absorption operator 构造。truth audit 必须检查
\begin{equation}
\boxed{
\operatorname{Herm}(Z_{\rm field})
\approx D_{\rm vol}+D_{\rm out}^{\rm phys}.
}
\end{equation}
禁止先定义 $D_{\rm out}:=\operatorname{Herm}Z-D_{\rm vol}$ 再宣称闭合已验证。

\subsection{代理层的联合能量与 modal 可行约束}
正式 surrogate 的 fixed-dimensional output schema 为
\begin{equation}
\boxed{
\{Z_{\rm field}(g),D_{\rm vol}(g),H_1(g),\ldots,H_r(g)\}.
}
\end{equation}
固定维度来自 canonical mode ordering，而不是固定空间 basis。

对当前 geometry 的 raw decode，先恢复 reciprocal/Hermitian algebraic structure，再用当前 deterministic $\phi_j^{\min/\max}(g)$ 施加
\begin{equation}
D_{\rm vol}\succeq0,
\qquad
\operatorname{Herm}(Z_{\rm field})-D_{\rm vol}\succeq0,
\end{equation}
以及
\begin{equation}
\boxed{
\phi_j^{\min}(g)D_{\rm vol}
\preceq H_j
\preceq\phi_j^{\max}(g)D_{\rm vol}
\quad\forall j.
}
\end{equation}
reactive reciprocal block 不因耗散投影而改变。所有 projection correction 必须作为 surrogate error diagnostic。

surrogate 可定义
\begin{equation}
\widehat D_{\rm out}^{\rm imp}
=\operatorname{Herm}(\widehat Z_{\rm field})-\widehat D_{\rm vol},
\end{equation}
但 validation/audit geometry 上仍必须与独立 truth $D_{\rm out}^{\rm phys}$ 比较。

\subsection{固定频率适用范围}
上述 passivity 与 tensor structure 针对冻结工作频率。若未来把 frequency 作为 surrogate input，逐频率 PSD 仍不足以保证 causal passive broadband network；必须进一步满足 matrix-valued positive-real/causality structure。

\section{端口阻抗、Joule 二次型与离散功率守恒}

\subsection{端口基响应}
令端口复电流向量为 $c\in\C^{n_p}$，source-shape 矩阵为 $S(g)$。在 $e^{+i\omega t}$ 约定下
\begin{equation}
B(g)=-i\omega S(g),
\qquad
A_{\rm em}(g)X(g)=B(g),
\end{equation}
于是任意端口电流下的场为
\begin{equation}
E=X(g)c.
\end{equation}
一次 multi-RHS truth solve 因而覆盖同一几何下的完整端口电流空间。

\subsection{被动端口阻抗的符号}
端口电压方向固定为被动符号约定，使正实部表示端口向电磁系统输入的平均功率。对当前 source orientation，场反应电压定义为
\begin{equation}
v_{\rm field}=-S^T E,
\end{equation}
因此
\begin{equation}
\boxed{
Z_{\rm field}(g)=-S(g)^T X(g).
}
\end{equation}
若线圈采用独立的集中 AC resistance model，则总端口阻抗为
\begin{equation}
\boxed{
Z(a,g)=Z_{\rm field}(g)+R_{\rm wire}(a,g),
}
\end{equation}
其中 $R_{\rm wire}$ 为实对角、非负矩阵。该符号定义必须与离散功率恒等式同时验证。

在 reciprocal material 与一致端口定义下，应有
\begin{equation}
Z_{\rm field}^T=Z_{\rm field}
\end{equation}
到离散/求解误差精度。对被动系统还必须有
\begin{equation}
\boxed{
\operatorname{Herm}(Z_{\rm field})
=\frac12(Z_{\rm field}+Z_{\rm field}^H)\succeq0.
}
\end{equation}
reciprocity 只给出复对称性，并不能自动保证 passivity；两者是独立必须满足的物理结构。

\subsection{与 Maxwell Hodge 一致的体 Joule 功率}
令导电 Hodge 为 $H_\sigma\succeq0$。任意场 $E$ 的体平均导电损耗为
\begin{equation}
\boxed{
P_{\rm vol}(E)=\frac12 E^H H_\sigma E.
}
\end{equation}
thermal heat distribution 必须由同一个 $H_\sigma$ 分配到 cell/thermal modes，使空间 heat 的总和严格恢复上述二次型。禁止先把 edge field 任意平均到 cell center 后再平方，因为该操作一般不保持原 Maxwell 离散能量。

\subsection{复 Hermitian Joule 模态张量}
对第 $j$ 个 thermal mode，令 $W_j(g)$ 为由同一导电 Hodge 与 thermal test function 构造的实对角加权算子。定义
\begin{equation}
\boxed{
H_j(g)=X(g)^H W_j(g)X(g).
}
\end{equation}
由于 $W_j$ 为实对角矩阵，$H_j$ 必须满足
\begin{equation}
H_j=H_j^H,
\end{equation}
但当 thermal mode 变号时，$H_j$ 不必半正定。

任意复端口电流下的体 Joule modal source 为
\begin{equation}
\boxed{
q_{{\rm vol},j}(g,c)=\operatorname{Re}\!\left(c^H H_j(g)c\right).
}
\end{equation}
不能在构造 $H_j$ 时提前取实部。Hermitian 矩阵虚部的反对称部分会参与有相对相位的多端口局部/modal power；提前执行 $\operatorname{Re}(H_j)$ 会丢失真实相位耦合。

\subsection{线圈集中电阻热}
线圈不作为 Maxwell volume conductor 时，其损耗由独立的集中 resistance model 表示。若第 $p$ 个端口电阻为 $R_p(a,g)$，对应 cell heat distribution 为 $\ell_p(g)$，则
\begin{equation}
Q_{\rm wire}
=\sum_p\frac12 R_p(a,g)|c_p|^2\ell_p(g).
\end{equation}
投影到 thermal basis 后得到 $q_{\rm wire}(a,g,c)$。线圈电阻模型可以包含温度、skin-effect 等经过明确定义的 constitutive approximation，但必须与 full-conductor Maxwell model 区分，不能称为后者意义下的 ``exact conductor loss''。

\subsection{开放域离散功率恒等式}
对开放电磁域，端口输入功率除了体导电损耗外，还可能通过外边界以 Poynting flux 离开计算域。记该平均外流功率为 $P_{\rm out}\ge0$；若采用吸收边界/PML，则它由相应边界或吸收层能量项表示。truth model 必须满足
\begin{equation}
\boxed{
\frac12\operatorname{Re}\!\left(c^H Z(a,g)c\right)
=P_{\rm vol}(g,c)+P_{\rm out}(g,c)+P_{\rm wire}(a,g,c)
}
\end{equation}
到 linear-solve、quadrature/deposition、边界离散和浮点误差允许的范围。

只有在域扩展实验已经证明 $P_{\rm out}$ 对目标量可忽略时，才允许把它从近似工程功率平衡中省略。有限 PEC 截断使 $P_{\rm out}=0$ 只是边界条件的结果，不能因此自动证明它近似真实开放域。

该恒等式同时验证：
\begin{itemize}
  \item Maxwell RHS/端口方向；
  \item 阻抗符号；
  \item Joule Hodge；
  \item complex phase coupling；
  \item 开放边界能流；
  \item 集中线圈电阻项。
\end{itemize}
如果该恒等式失败，则对应 snapshot 禁止进入神经训练数据集。

\subsection{神经代理必须保留的代数结构}
生产神经网络预测 $Z_{\rm field}$ 和 $H_j$ 的低维系数，解码后必须显式满足
\begin{equation}
\widehat Z_{\rm field}^T=\widehat Z_{\rm field},
\qquad
\operatorname{Herm}(\widehat Z_{\rm field})\succeq0,
\end{equation}
以及
\begin{equation}
\widehat H_j=\widehat H_j^H.
\end{equation}
电流依赖始终通过 $c^H\widehat H_jc$ 和 $c^H\widehat Zc$ 解析进入，网络不得自行学习 current scaling 或 current phase law。

这些结构是必要条件但不是完整 Poynting consistency 的充分条件。$\widehat Z$ 与 $\widehat H_j$ 之间的功率/热源一致性仍必须作为 surrogate-level audit 单独量化。

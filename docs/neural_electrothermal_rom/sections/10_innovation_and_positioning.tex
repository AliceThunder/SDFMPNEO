\section{创新定位与综合评价}

\subsection{核心贡献链条}
项目的创新不应表述为 ``使用了一个神经网络''，而应集中在以下系统性结构：
\begin{equation}
\boxed{
\text{validated Maxwell physics}
\rightarrow
\text{energy-consistent } Z/D/H \text{ extraction}
\rightarrow
\text{transient-aware thermal basis}
\rightarrow
\text{geometry-parametric neural surrogate}
\rightarrow
\text{joint feasible physical decode}
\rightarrow
\text{exact current/circuit physics}
\rightarrow
\text{true thermal ROM dynamics}.
}
\end{equation}
神经网络替代的是随几何变化的低维电磁参数映射，而不是 Maxwell 方程、current/circuit law 或 thermal dynamics 本身。

\subsection{为什么学习 $Z/D_{\rm vol}/H$}
当前材料模型下 Maxwell operator 只依赖几何。固定几何后，一次 multi-RHS solve 同时确定整个端口电流空间的响应。因此直接学习
\begin{equation}
g\mapsto\{Z_{\rm field},D_{\rm vol},H_j\}
\end{equation}
具有以下优势：
\begin{enumerate}
  \item learning target 与最终 impedance、total loss 和 thermal source 直接相关；
  \item current magnitude/phase 由解析 quadratic forms 完整覆盖，不需要把 operating current 当网络采样维度；
  \item $D_{\rm vol}$ 把 port dissipation 与 thermal Joule 放到同一矩阵级能量框架；
  \item $\phi_j^{\min}D_{\rm vol}\preceq H_j\preceq\phi_j^{\max}D_{\rm vol}$ 进一步把 modal source 与总耗散联系起来；
  \item thermal trajectory 中无需重复计算高维电磁场。
\end{enumerate}

\subsection{与 trajectory surrogate 的区别}
直接学习
\begin{equation}
(g,c,a_0,t)\mapsto T(t)
\end{equation}
需要网络同时学习初值、时间尺度、热扩散、current scaling、circuit feedback 和稳态结构。当前方案把这些已知结构移出学习问题，只留下静态 geometry-to-tensor map，从而降低学习复杂度并提高可解释性。

\subsection{结构保持的严格含义}
本文所称 structure-preserving 只指已经明确证明或按构造保证的有限结构：
\begin{itemize}
  \item 在 reciprocal assumptions 下的 $Z^T=Z$；
  \item $D_{\rm vol}\succeq0$ 与 $\operatorname{Herm}Z-D_{\rm vol}\succeq0$；
  \item $H_j=H_j^H$ 及 modal Loewner bounds；
  \item peak-phasor 的 exact quadratic current scaling；
  \item 真实 $M_r,K_r$ 和零源 thermal energy dissipation；
  \item 显式 initial-condition/circuit/steady-state semantics。
\end{itemize}
这些条件不等价于完整 spatial realizability、pointwise thermal positivity、全域 surrogate certificate 或全局 nonlinear stability。后四者若需要，必须通过相应的 Physics Gate、verified bounds 或专门的 structure-preserving method 另行建立。

\subsection{论文/技术报告应回答的问题}
正式报告应围绕以下问题展开：
\begin{enumerate}
  \item 在 UWPT 低频 Maxwell 问题中，如何建立 reciprocity、passivity、独立 Poynting audit 与 thermal Joule consistency 同时成立的 $Z/D/H$ objects？
  \item 如何利用 multi-RHS linearity 与 Hermitian current structure 消除 operating-current sampling dimension，并完整覆盖 thermal source span？
  \item geometry-to-$Z/D/H$ map 是否具有足够低的有效复杂度，能够被紧凑神经代理学习？
  \item 联合可行投影在多大程度上只是安全层，而不是主要误差修正器？
  \item tensor surrogate、thermal ROM、initial-condition 与 circuit error 如何传播到 trajectory、steady state 与 impedance outputs？
  \item 与直接 trajectory NN、普通 response-surface 和高维 online Maxwell solve 相比，精度--训练成本--推理成本的 Pareto 前沿如何？
\end{enumerate}

\subsection{冻结结论}
在 Physics Gate 通过后，主架构固定为
\begin{equation}
\boxed{
 g\rightarrow\{Z_{\rm field},D_{\rm vol},H_j\}_\theta
 \rightarrow\text{joint physical feasibility}
 \rightarrow\text{exact current/circuit physics}
 \rightarrow\text{true thermal ROM}.
}
\end{equation}
后续可以改进 POD、网络容量、sampling、active learning、verified bounds、positivity-preserving thermal method 与 integrator，但不得绕过上述物理分层。若新的 constitutive、conductor、boundary、frequency、circuit 或 geometry-dynamics evidence 推翻当前假设，应先修改 truth model/Physics Gate，再重建 basis、dataset 和 surrogate，而不是让网络吸收缺失物理。

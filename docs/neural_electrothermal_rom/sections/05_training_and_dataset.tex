\section{数据生成与训练协议}

\subsection{训练样本定义}
当前生产代理的基本训练样本是
\begin{equation}
\boxed{
 g^{(s)}\longmapsto y^{(s)}
 =\mathcal E\!\left(Z_{\rm field}^{(s)},H_1^{(s)},\ldots,H_r^{(s)}\right).
}
\end{equation}
网络不以端口电流样本或时间轨迹为监督对象。一个几何只需一次 multi-RHS Maxwell truth solve，即可同时生成完整端口阻抗矩阵和全部 current-quadratic Joule tensors。

\subsection{truth snapshot 生成流程}
对每个几何 $g^{(s)}$：
\begin{enumerate}
  \item 先通过几何合法性、边界裕量与离散连续性检查；
  \item 组装经过 Physics Gate 冻结的 Maxwell truth model；
  \item 求解所有端口基激励得到 $X(g^{(s)})$；
  \item 检查 linear solve residual、reciprocity、passivity 与离散功率平衡；
  \item 由统一的导电 Hodge 构造 $Z_{\rm field}$ 与复 Hermitian $H_j$；
  \item 结构化编码得到 $y^{(s)}$；
  \item 保存几何、离散质量指标、边界/网格版本和物理元数据。
\end{enumerate}
任何未通过 truth audit 的 snapshot 不得进入训练集。

\subsection{数据划分}
train/validation/test 必须按几何样本划分。一个几何对应的所有端口矩阵元素和全部 thermal-mode tensors 必须属于同一 split，防止同一物理结构跨集合泄漏。

除随机/低差异划分外，测试集必须额外覆盖：
\begin{itemize}
  \item 几何参数盒的边界与角点附近；
  \item 强耦合、小间距、较大姿态偏转等困难区域；
  \item shape 类型切换后的各个离散子域；
  \item 与训练点具有明确几何距离的 held-out 区域。
\end{itemize}

\subsection{POD 只能使用训练集}
只使用 training snapshots 构造
\begin{equation}
y\approx\bar y+U_K\beta.
\end{equation}
POD rank 同时由平均能量尾部和 held-out reconstruction error 选择，不能只看累计能量比例。若不同物理块尺度差异过大，可对 $Z$、体 Joule tensors 或不同 modal groups 使用固定物理尺度归一化后再联合 POD，或采用分块 POD。

\subsection{主监督损失}
网络主目标为归一化 latent coefficient regression：
\begin{equation}
\mathcal L_\beta
=\frac1N\sum_s
\left\|W_\beta\left(\beta_\theta(g^{(s)})-\beta^{(s)}\right)\right\|_2^2.
\end{equation}
同时必须在解码后的物理对象上监控：
\begin{align}
\mathcal E_Z&=\|\widehat Z_{\rm field}-Z_{\rm field}\|,\\
\mathcal E_H&=\left(\sum_j\|\widehat H_j-H_j\|_F^2\right)^{1/2}.
\end{align}
可以增加解码后的物理辅助损失，但其作用是改善数值拟合，不用于“制造”对称/Hermitian/current-quadratic 结构；这些结构必须由解码层硬编码。

\subsection{current-space validation}
虽然电流 $c$ 不作为网络输入，但验证必须覆盖复电流方向。对固定 snapshot，随机或确定性选取单位球上的复电流 $c$，比较
\begin{equation}
\operatorname{Re}(c^H\widehat H_jc)
\quad\text{与}\quad
\operatorname{Re}(c^HH_jc),
\end{equation}
以及
\begin{equation}
\widehat Zc\quad\text{与}\quad Zc.
\end{equation}
测试集合必须包含 $0,\pi/2,\pi,3\pi/2$ 等相对相位组合，确保 Hermitian 虚部没有被错误丢弃。

\subsection{优化与停止标准}
网络训练使用标准 AdamW/mini-batch/GPU 工具链。学习率和 early stopping 只根据冻结 validation set 决定，test set 不参与模型选择。

停止标准不能只看 latent loss；至少同时要求：
\begin{itemize}
  \item validation latent/decoded tensor error 均稳定；
  \item current-space Joule/impedance error 达到目标；
  \item passivity/reciprocity 等结构化 audit 不被 surrogate reconstruction 破坏；
  \item 在 frozen electrothermal trajectory audit 上，最终温度和阻抗误差满足工程目标。
\end{itemize}

\subsection{active learning}
若初始几何采样不足，active learning 应在几何空间中增加 truth snapshots。优先指标包括：
\begin{itemize}
  \item ensemble/epistemic disagreement；
  \item 几何 novelty；
  \item decoded $Z/H$ 的 validation spot-check 误差；
  \item trajectory audit 频繁访问且 surrogate error 较大的几何区域。
\end{itemize}
新增 truth data 后，POD 与归一化元数据必须版本化，禁止无记录地改变输出坐标系。

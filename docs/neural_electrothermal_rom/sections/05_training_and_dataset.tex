\section{数据生成与训练协议}

\subsection{数据依赖顺序}
最终 $H_j(g)$ 的定义依赖当前 geometry 的 deterministic thermal mode $\phi_j(g)$，因此数据生成顺序固定为：
\begin{enumerate}
  \item 冻结 validated Maxwell/Joule truth physics，并先通过不依赖 thermal basis 的 spatial truth preflight；
  \item 构建 canonical background/TX/RX thermal mode library；
  \item 冻结 deterministic basis generator $\mathcal B:g\mapsto\Phi(g)$、mode ordering、transport/interpolation rule 与 time-scale policy；
  \item 对每个 geometry 构造 $\Phi(g),M_r(g),K_r(g)$ 与 $\phi_j^{\min/\max}(g)$；
  \item 用当前 $\phi_j(g)$ 组装 $W_j(g)$，生成 $H_j(g)=X(g)^HW_j(g)X(g)$；
  \item 形成 fixed-dimensional $Z/D_{\rm vol}/H$ tensor dataset，并执行依赖冻结 basis/tensor 的 post-basis Physics Gate；
  \item 只用 neural training split 构建 POD/normalization 并训练 surrogate；
  \item 在新的 completely-held-out geometries 上执行最终 release Go/No-Go，全部通过后才允许发布模型 artifact。
\end{enumerate}
任何 truth physics、canonical mode library 或 basis-generator version 改变都必须使 tensor labels、POD 和模型 signature 失效。release threshold 的改变不要求重新求解已冻结的 physics truth，但必须重新执行相应 release acceptance。

\subsection{阶段一：validated physics bank}
对每个候选 geometry $g^{(s)}$：
\begin{enumerate}
  \item 通过 geometry feasibility、physical source regularization、terminal/source continuity 与边界裕量检查；
  \item 求 Maxwell port basis responses $X(g^{(s)})$；
  \item 构造 $Z_{\rm field}$、$D_{\rm vol}=X^HH_\sigma X$；
  \item 独立构造 $D_{\rm out}^{\rm phys}$ 并检查
  \begin{equation}
  \operatorname{Herm}(Z_{\rm field})\approx D_{\rm vol}+D_{\rm out}^{\rm phys};
  \end{equation}
  \item 用 Hermitian port-space deterministic current combinations 生成完整 current-induced spatial Joule family，并加入 wire/source patterns；
  \item 保存 mesh/domain/formulation/constitutive/source version 与 audit metadata。
\end{enumerate}
未通过 truth audit 的 geometry 不得进入 thermal-library construction 或 neural dataset。

\subsection{阶段二：canonical thermal mode library}
不再在全局 Eulerian coordinates 中把所有 geometry snapshots 堆成一个共享 basis。canonical library 分为
\begin{equation}
\Phi_{\rm bg},\qquad\Psi_{\rm tx},\qquad\Psi_{\rm rx}.
\end{equation}
background block 在 global frame 中构建，局部 block 在各自 coil/package canonical frame 中构建。

对每个 canonical source/initial-condition anchor 与可解析 time-scale shift，统一写成
\begin{equation}
A_su=b,\qquad A_s=K+sM\succ0,
\end{equation}
并用
\begin{equation}
\boxed{
\eta_s^2
=\frac{r^TA_s^{-1}r}{b^TA_s^{-1}b}
=\frac{\|u-\tilde u\|_{A_s}^2}{\|u\|_{A_s}^2}
}
\end{equation}
作为 canonical rank/enrichment 指标或 validated estimator 的 reference quantity。

source family 必须覆盖完整 current-induced volume heat span、TX/RX wire heat、确定性 boundary/source patterns 与允许的 initial-condition family。rank 自动选择对象是各 canonical block，不是任意 global hotspot 位置。

\subsection{time-scale selection 不是越宽越好}
对 thermal diffusivity $\alpha$，若
\begin{equation}
\ell_d(\tau)=\sqrt{\alpha\tau}
\end{equation}
远小于 spatial discretization 的可解析长度，则 $s=1/\tau$ anchor 主要反映离散 source placement。除非应用要求且 full-order mesh 已解析该尺度，否则这种极短时间不作为 production basis target。

当前首版优先选择可解析的短/中时尺度并保留 $s=0$ steady anchor。长时间 horizon 由同一个 reduced ODE 连续积分完成；不要求为每个可能的长查询时间生成单独 resolvent anchor。

\subsection{阶段三：逐 geometry 生成 tensor labels}
对每个 dataset geometry，先确定性生成
\begin{equation}
\Phi(g)=
[\Phi_{\rm bg},\mathcal T_{\rm tx}(g)\Psi_{\rm tx},\mathcal T_{\rm rx}(g)\Psi_{\rm rx}],
\end{equation}
并验证 full rank、reduced SPD 与 conditioning。然后对每个 fixed canonical index $j$：
\begin{equation}
[W_j(g)]_{mn}
=\int_\Omega\sigma(x;g)\phi_j(x;g)N_m\cdot N_n\,dx,
\end{equation}
\begin{equation}
\boxed{H_j(g)=X(g)^HW_j(g)X(g).}
\end{equation}

同时计算
\begin{equation}
\phi_j^{\min}(g),\qquad\phi_j^{\max}(g),
\end{equation}
并对 truth labels 检查
\begin{equation}
\phi_j^{\min}(g)D_{\rm vol}(g)
\preceq H_j(g)
\preceq\phi_j^{\max}(g)D_{\rm vol}(g).
\end{equation}
违反该关系说明 $W_j/H_\sigma$/transfer/basis evaluation 不一致，不得进入训练集。

\subsection{数据划分与信息泄漏}
train/validation/test/audit 必须按 geometry 划分。一个 geometry 的所有 tensor elements、modal tensors 与 thermal metadata 必须属于同一 split。

更重要的是，完全 held-out end-to-end audit geometries 不能参与：
\begin{itemize}
  \item canonical thermal mode rank/tuning；
  \item local transport/interpolation parameter tuning；
  \item neural training/validation/model selection；
  \item POD construction。
\end{itemize}
它们只用于最终 full-vs-ROM、tensor surrogate、current/circuit dynamics 与 production-integrator audit。

如果一个 geometry 被用于修正 local transform、增加 canonical modes 或选择 time scales，它就不再是完全未见的 audit point。

\subsection{thermal validation 必须分解来源}
不能只报告一个 aggregate maximum relative energy error。对 validation/audit anchors 至少按以下维度分解：
\begin{itemize}
  \item geometry；
  \item source type：volume Joule basis、TX wire、RX wire、initial condition；
  \item canonical block：background/TX/RX；
  \item time scale/shift；
  \item relative energy error；
  \item anchor absolute energy、source norm 或相关 power scale。
\end{itemize}
这样才能区分“重要物理工况误差大”和“绝对功率极小的方向相对误差大”。

\subsection{POD 只能使用 neural training split}
只使用 training tensor snapshots 构造
\begin{equation}
y\approx\bar y+U_K\beta.
\end{equation}
POD rank 由谱尾与 held-out reconstruction error 共同决定。不同物理块尺度差异大时使用固定物理尺度 normalization 或分块 POD。raw decode 仍必须经过结构化 physical feasibility layer。

\subsection{监督目标与物理解码诊断}
网络主目标为 latent 或 matrix-aware decoded regression。无论采用哪种训练 loss，都必须在 validation/test 上报告：
\begin{align}
\mathcal E_Z&=\|\widehat Z-Z\|,\\
\mathcal E_D&=\|\widehat D-D\|,\\
\mathcal E_H&=\left(\sum_j\|\widehat H_j-H_j\|_F^2\right)^{1/2},
\end{align}
以及 $(Z,D)$、$H$ projection correction、raw Loewner violations 和 current-space quadratic contraction errors。

physical decoder 使用当前 geometry 的 $\phi_j^{\min/\max}(g)$。这些 quantities 不由网络预测，因此其错误归入 deterministic basis/transfer error，而不是 neural regression error。

\subsection{current-space validation}
虽然 $c$ 不作为网络输入，但 validation 必须覆盖复电流方向，包括相对相位 $0,\pi/2,\pi,3\pi/2$ 等组合，比较
\begin{equation}
\frac12\operatorname{Re}(c^H\widehat H_jc),
\qquad
\frac12c^H\widehat Dc,
\qquad
\widehat Zc
\end{equation}
与 truth。随机 current tests 是补充，不能替代 matrix-level constraints。

\subsection{completely-held-out end-to-end release audit}
最终 release audit 在训练、POD、early stopping 全部结束后才执行，并使用完全独立的 geometry set。至少包含四层：
\begin{enumerate}
  \item full thermal truth 与 geometry-aware thermal ROM 的
  \begin{equation}
  T(x,t),\quad T_{\min}(t),\quad T_{\max}(t),\quad \bar T_{\rm wire}(t),\quad a_*
  \end{equation}
  比较，覆盖可解析短时、中间时间、长时间和 steady state；
  \item truth tensors 与 surrogate tensors 的 $Z/D/H$、独立 outward loss、projection correction 与完整 complex-current contraction audit；
  \item 在同一 reduced thermal coordinates 上，truth-tensor ROM 与 surrogate-tensor ROM 的 current-controlled 和 circuit-controlled trajectory、$Z(t)$、currents、wire temperature、steady residual/stability 与 circuit conditioning 比较；
  \item 固定同一 surrogate reduced ODE 后，生产 time integrator 与高精度 stiff reference solver 的独立 time-discretization audit。
\end{enumerate}

若误差主要随 rigid translation/rotation 出现，应优先修正 deterministic transport/local-frame construction；若 rigid transform 已稳定而尺寸变化仍主导误差，再考虑 scale-aware deterministic extension。禁止首先通过向一个固定全局 basis 大量堆 mode 来掩盖几何移动导致的假高秩。

最终 audit 属于冻结 held-out numerical validation，不自动升级为覆盖连续参数域的严格数学 certificate。任一 release Gate 未通过时，训练可以保留诊断/checkpoint，但不得把该次 surrogate 发布为 production model artifact。

\subsection{active learning 与 thermal model enrichment 的边界}
Neural active learning 可以增加 geometry truth snapshots，以改善 $g\mapsto Z/D/H$。但若新 geometry 暴露的是 thermal basis-generator error，处理顺序应为：
\begin{enumerate}
  \item 判断是 transport/interpolation、canonical rank、time-scale policy 还是真正 operator variation 问题；
  \item 修正 deterministic thermal model；
  \item 版本化 basis generator；
  \item 重新生成受影响的 $H_j(g)$ labels；
  \item 再重新训练 neural surrogate。
\end{enumerate}
不能让神经网络吸收 deterministic thermal-coordinate mismatch。

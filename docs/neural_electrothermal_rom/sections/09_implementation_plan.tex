\section{实施路线与软件边界}

\subsection{唯一正式主链}
正式实现只保留一条生产主链：
\begin{equation}
\boxed{
 g
 \rightarrow \text{validated Maxwell truth physics}
 \rightarrow \{Z_{\rm field},D_{\rm vol},H_j\}
 \rightarrow \text{neural low-dimensional surrogate}
 \rightarrow \text{exact current/circuit physics}
 \rightarrow \text{true thermal ROM}
 \rightarrow a(t),T(t),Z(t).
}
\end{equation}
网络不承担 Maxwell field solve、时间积分、circuit equations 或 thermal operator prediction。

\subsection{第一层：validated spatial truth bank}
离线物理层首先对 geometry family 生成与 thermal mode 无关的基础 truth information：
\begin{enumerate}
  \item 几何合法性、physical wire/source regularization、terminal/source continuity 和 Physics Gate 检查；
  \item 组装冻结版本的 Maxwell operator 与实值端口 source basis；
  \item 求所有端口基响应 $X$；
  \item 计算 $Z_{\rm field}$、$D_{\rm vol}=X^HH_\sigma X$、空间体 Joule bilinear information 与 wire/source spatial patterns；
  \item 从开放边界/PML 的独立物理双线性型计算 $D_{\rm out}^{\rm phys}$；
  \item 验证 reciprocity、$D_{\rm vol}\succeq0$、$D_{\rm out}^{\rm phys}\succeq0$ 和
  \begin{equation}
  \operatorname{Herm}(Z_{\rm field})\approx D_{\rm vol}+D_{\rm out}^{\rm phys},
  \end{equation}
  以及 linear residual；
  \item 保存后续构建 thermal basis 所需的物理数据及完整 audit metadata。
\end{enumerate}
这一层不能依赖尚未构建的 thermal mode $\phi_j$；truth outward power 也不能通过 $\operatorname{Herm}Z-D_{\rm vol}$ 反定义后自证。

\subsection{第二层：thermal basis builder}
共享 thermal basis 在 modal tensor labels 之前构建。对每个 geometry，volume Joule 对端口 current 是 Hermitian quadratic form，因此 current-induced spatial heat family 可由有限个端口 Hermitian basis combinations 精确张成；再加上各 wire heat patterns、其他确定性热源以及目标 initial-condition family，形成完整 enrichment family。

统一 resolvent anchor 写成
\begin{equation}
A_su=b,
\qquad A_s=K+sM\succ0,
\end{equation}
其中 source anchor 使用 $b=Q_\alpha$，initial-condition anchor 使用 $b=M\theta_{0,\beta}$。Galerkin residual 为 $r=b-A_s\Phi a$，rank/enrichment criterion 使用
\begin{equation}
\boxed{
\eta_s^2
=\frac{r^TA_s^{-1}r}{b^TA_s^{-1}b}
=\frac{\|u-\Phi a\|_{A_s}^2}{\|u\|_{A_s}^2}.
}
\end{equation}
worst $\eta_s$ 超过 target 时增广基；若实现使用 approximate estimator，必须先验证其与上述能量误差的等价关系。rank 是达到目标后的结果，不作为用户手工参数。

basis version 必须记录 geometry/source/initial-condition anchor set、current-basis construction、shift set、thermal operators/boundaries、cross-space transfer、wire-temperature functional、residual norm definition 和 truth-physics version。冻结 audit geometries 上还必须通过 full-vs-ROM transient/steady trajectory 验证。

\subsection{第三层：冻结 basis 后生成 tensor dataset}
只有在 $\Phi$ 冻结后，才对每个 geometry 用同一 FE basis/quadrature 直接组装
\begin{equation}
[W_j]_{mn}=\int_\Omega\sigma\,\phi_j\,N_m\cdot N_n\,\mathrm dx,
\qquad
H_j(g)=X(g)^H W_j(g)X(g).
\end{equation}
同时记录 $\phi_j^{\min},\phi_j^{\max}$ 并验证
\begin{equation}
\phi_j^{\min}D_{\rm vol}
\preceq H_j
\preceq\phi_j^{\max}D_{\rm vol}.
\end{equation}
最终 neural dataset 保存：
\begin{itemize}
  \item canonical geometry parameters 与 validated production-domain definition；
  \item $Z_{\rm field}$ 的复对称独立自由度；
  \item $D_{\rm vol}$ 的 Hermitian 独立自由度；
  \item $H_j$ 的 Hermitian 独立自由度；
  \item $\phi_j^{\min/\max}$ 与 thermal-basis metadata；
  \item geometry split 与 completely-held-out audit split；
  \item independent truth $D_{\rm out}^{\rm phys}$ 作为 audit target；
  \item thermal-basis version；
  \item frequency/phasor/port、physical source regularization、mesh/domain/formulation/constitutive version；
  \item truth residual、matrix power-balance、reciprocity 等 audit 指标。
\end{itemize}
任何基础物理或 thermal basis 版本变化都必须使 tensor dataset signature 失效。

\subsection{输出压缩与 neural model}
只使用 neural training split 构造 output normalization 与 POD：
\begin{equation}
y\approx\bar y+U_K\beta.
\end{equation}
普通 residual MLP 学习
\begin{equation}
\beta_\theta:g\mapsto\R^K.
\end{equation}
模型文件必须持久化 geometry encoding、$\mathcal G_{\rm prod}$、output scaling、POD mean/basis、MLP weights、tensor schema、联合可行层、$\phi_j^{\min/\max}$、thermal-basis version 和 truth-physics version。

\subsection{结构化解码与联合可行层}
解码流程固定为
\begin{equation}
\beta_\theta
\rightarrow\hat y
\rightarrow
\{\widetilde Z_{\rm field},\widetilde D_{\rm vol},\widetilde H_j\}
\rightarrow
\{\widehat Z_{\rm field},\widehat D_{\rm vol},\widehat H_j\}.
\end{equation}
联合可行层保持 reactive reciprocal block 不变，并对耗散/modal blocks 施加
\begin{equation}
\widehat D_{\rm vol}\succeq0,
\qquad
\operatorname{Herm}(\widehat Z_{\rm field})-\widehat D_{\rm vol}\succeq0,
\end{equation}
以及
\begin{equation}
\phi_j^{\min}\widehat D_{\rm vol}
\preceq\widehat H_j
\preceq\phi_j^{\max}\widehat D_{\rm vol}\quad\forall j.
\end{equation}
同时保存/报告 $(Z,D)$ 与 $H$ 两类 projection correction norm，禁止用大幅物理投影掩盖 raw surrogate error。surrogate implied outward matrix 还必须与独立 truth $D_{\rm out}^{\rm phys}$ 做 held-out audit。

\subsection{在线 thermal/circuit engine}
对一个几何查询：
\begin{enumerate}
  \item 先检查 $g\in\mathcal G_{\rm prod}$ 与 geometry feasibility；域外输入不进入“validated prediction”路径；
  \item neural geometry forward 只执行一次并缓存 $\widehat Z_{\rm field},\widehat D_{\rm vol},\widehat H_j$；
  \item current-controlled 模式直接使用给定 $c$；circuit-controlled 模式由确定性 circuit equations 求 $c(a,t)$；
  \item 解析计算
  \begin{equation}
  q_{{\rm vol},j}=\frac12\operatorname{Re}(c^H\widehat H_jc),
  \qquad
  P_{\rm vol}=\frac12c^H\widehat D_{\rm vol}c;
  \end{equation}
  \item 通过明确的 conductor-temperature functional 更新 $R_{\rm wire}$ 与 wire heat；
  \item 使用真实 $M_r(g),K_r(g)$ 推进 ODE 或求与初值/稳定分支一致的 steady state；
  \item 输出 $Z(a,g)=\widehat Z_{\rm field}+R_{\rm wire}$ 及功率诊断。
\end{enumerate}

若 circuit ring-up/settling time 不再远短于 thermal/envelope time scale，则在线 engine 必须包含 circuit dynamic states，而不能继续用纯代数 phasor network solve。若 geometry 在 query 中随时间变化，也必须显式更新 geometry-dependent tensors/operators。

\subsection{验证测试}
最低测试集合必须覆盖：
\begin{itemize}
  \item Maxwell mesh/domain/formulation convergence；
  \item physical source regularization 与 self-impedance mesh convergence；
  \item terminal/source continuity、units、reaction-voltage calibration 和 geometry perturbation continuity；
  \item port reciprocity；
  \item independently-computed $D_{\rm vol}$ 与 $D_{\rm out}^{\rm phys}$；
  \item $\operatorname{Herm}Z\approx D_{\rm vol}+D_{\rm out}^{\rm phys}$；
  \item $\sum Q_{\rm vol}=\frac12E^HH_\sigma E$；
  \item direct $W_j$ assembly、$\phi_j^TQ_{\rm vol}=\frac12\operatorname{Re}(c^HH_jc)$ 与 modal Loewner bounds；
  \item arbitrary complex-current contraction；
  \item POD raw decode、joint feasible projection 和 projection-correction audit；
  \item frozen validation/test $Z/D/H/q$ error 和 implied-vs-physical outward-loss error；
  \item geometry/source/initial-condition/shift energy-norm resolvent error；
  \item full thermal versus ROM transient/steady audit；
  \item initial-condition projection/homogeneous-response audit；
  \item wire-temperature functional audit；
  \item reduced stable-equilibrium Jacobian 与 frozen full-order branch/perturbation audit；
  \item ETD/IMEX against high-accuracy reference；
  \item current-controlled and, when enabled, circuit-controlled end-to-end audit。
\end{itemize}

\subsection{训练和推理接口原则}
用户层只需要两个概念流程：
\begin{itemize}
  \item \textbf{train：}生成/复用 validated spatial truth bank，构建并冻结 thermal basis，生成 tensor dataset，构建 POD，训练 geometry surrogate，保存统一模型；
  \item \textbf{predict：}加载模型，检查 production domain，对 geometry 解码物理 tensors，执行 current/circuit physics 与 thermal dynamics。
\end{itemize}
缓存、memmap、out-of-core SVD 等都属于内部性能实现，不改变理论接口。

\subsection{禁止重新引入的耦合}
正式主实现中不允许：
\begin{itemize}
  \item 网络直接学习时间轨迹；
  \item 网络把 current、voltage/load 当普通输入去重新学习已知 quadratic/circuit law；
  \item 网络预测 $M_r,K_r$ 替代真实 thermal operators；
  \item 用 unrestricted matrices 代替 reciprocal/Hermitian/energy-feasible output；
  \item 在 thermal basis 尚未冻结时定义最终 $H_j$ labels；
  \item 用随机 current sampling 代替完整 Hermitian current-source span；
  \item 用未经尺度化的 Euclidean residual 宣称 thermal ROM 相对解误差已收敛；
  \item 只用 steady 与 initial derivative 两个端点宣称 thermal transient ROM 已收敛；
  \item 用任意 nonlinear root 代替与 initial condition/basin 一致且经稳定性验证的 steady state；
  \item 在 Physics Gate 失败的数据上继续优化 neural loss；
  \item 对 $\mathcal G_{\rm prod}$ 外输入宣称 validated surrogate accuracy；
  \item 把 algebraic solve residual 当成 mesh/domain/model correctness 的替代品。
\end{itemize}

\subsection{实现顺序}
软件实施顺序由物理依赖严格决定：
\begin{enumerate}
  \item 修并冻结 Physics Gate；
  \item 生成 validated spatial Maxwell/Joule/source truth bank；
  \item 构建 transient/initial-condition-aware shared thermal basis 并冻结 $\Phi$；
  \item 用冻结 $\Phi$ 生成最终 $Z/D_{\rm vol}/H_j$ tensor dataset；
  \item 实现 structure encode/POD/joint feasible decode；
  \item 训练 neural geometry surrogate；
  \item 接入 thermal/circuit engine 和统一 predict API；
  \item 用完全 held-out geometry 做 end-to-end audit。
\end{enumerate}
任何上游物理或 basis 版本改变都必须使下游 tensor labels、POD 和模型版本失效。

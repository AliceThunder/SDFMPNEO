\section{实施路线与软件边界}

实现只保留一条主链：
\begin{equation}
(a,g)\rightarrow G(a,g)\rightarrow \mathrm{POD}\rightarrow \beta_\theta(a,g)
\rightarrow q_\theta(a,g,u)\rightarrow a(t).
\end{equation}

\subsection{核心模块}
软件职责保持简单清晰：
\begin{verbatim}
sdfmpneo/electrothermal_tensor/
  quadratic_joule.py   # reduced EM -> exact G(a,g)
  dataset.py           # train/validation/test snapshots
  pod.py               # tensor compression
  network.py           # ordinary residual MLP
  physical_layer.py    # quadratic-current hard physics
  vector_field.py      # M,K,q,f_T composition
  integrators.py       # ETD2 / adaptive ETD2 / IMEX
  model.py             # save/load/predict
  pipeline.py          # train/retrain assembly
  cli.py               # train/retrain/predict
\end{verbatim}

\subsection{训练流程}
训练只做以下步骤：
\begin{enumerate}
  \item 在给定的 thermal-state 与 geometry 参数盒中采样 $(a,g)$；
  \item 用 reduced EM multi-RHS solve 构造 $G(a,g)$；
  \item 在 training split 上拟合 POD；
  \item 用普通 mini-batch AdamW 训练 $(a,g)\mapsto\beta$；
  \item 保存 POD、网络参数、thermal operator 和训练范围。
\end{enumerate}

标签一旦生成，调整网络或 POD 参数时可直接 retrain，不重新运行 EM。

\subsection{禁止的耦合}
实现中不允许：
\begin{itemize}
  \item 网络 forward 调用 EM solver；
  \item 将时间作为黑箱网络输入绕过 ODE；
  \item 让网络学习 $M_r(g)$ 或 $K_r(g)$；
  \item 放弃已知的 current-quadratic 结构而直接黑箱学习 $u$；
  \item 把外部确定性热源 $f_T$ 混进 Joule surrogate。
\end{itemize}

\subsection{验证}
验证不引入额外的软件体系。只保留普通数值检查：
\begin{itemize}
  \item quadratic tensor 与原 Joule heat 的数值等价；
  \item validation/test split 上的 tensor/heat-source 误差；
  \item 若需要，对典型工况比较 neural ODE 与原 reduced electrothermal ODE 的轨迹。
\end{itemize}

\subsection{性能实现}
大数据时可以在不改变接口的前提下使用 memmap、out-of-core POD、GPU mini-batch 和 batch inference。这些都只是内部性能优化，不引入新的用户流程或理论层级。

\section{实施路线与软件边界}

当前正式实现只保留一条主链：
\begin{equation}
 g
 \rightarrow A_{\rm em}(g,T),B(g)
 \rightarrow N_\theta^{\rm multi}(A,R)
 \rightarrow \mathrm{FGMRES\ closure}
 \rightarrow X
 \rightarrow q_{\rm Joule}
 \rightarrow a(t).
\end{equation}
Maxwell 始终在固定背景完整 edge space 中求解；不存在全局 Maxwell solution basis、Maxwell rank、dense $Q/S$ 特征、polynomial coefficient 网络、ILU/AMG 分支或 reduced-coefficient 网络输出。

神经网络是 Maxwell 加速主体。它读取当前真实 sparse Maxwell operator 的 fine/coarse complex coupling 与当前 residual，直接输出 full edge-space correction。FGMRES 只负责最终真实 residual 闭环。最终电磁结果必须满足
\begin{equation}
 \frac{\lVert B-A_{\rm em}X\rVert_2}{\lVert B\rVert_2}\le \varepsilon_{\rm EM}.
\end{equation}

\subsection{核心模块}
正式统一路径的职责如下：
\begin{verbatim}
sdfmpneo/
  unified_geometry.py         # analytic / implicit geometry
  unified_background.py       # fixed edge/cell physics
  unified_neural_operator.py  # multiscale sparse complex neural solver
  unified_maxwell.py          # neural rollout + true-residual FGMRES closure
  unified_dataset.py          # geometry/material operator metadata
  unified_trainer.py          # full-space solution-label-free unroll training
  unified_thermal.py          # residual-driven automatic thermal basis
  unified_model.py            # exact Joule + thermal dynamics + save/load
  unified_runtime.py          # single train/predict runtime
\end{verbatim}
历史研究模块可以保留用于追溯，但不得由顶层 API、\texttt{run.py} 或正式 CLI 自动切换成另一条模型路线。

\subsection{Multiscale sparse neural Maxwell solver}
对当前 residual $R$，fine-edge 节点特征包含 residual、$D^{-1}R$ 的归一化实虚部、diagonal magnitude/phase/loss ratio、row coupling 和 degree；固定特征包含 edge 位置与方向。

令 $\widehat A_0$ 为按行归一化的 fine complex off-diagonal Maxwell coupling。固定背景 edge topology 进一步按 stride $2,4,8$ 建立保留 edge orientation 的 group map $P_\ell$，coarse operator 由真实 sparse Maxwell coupling 聚合：
\begin{equation}
 A_\ell=P_\ell^T A_{\rm em}P_\ell,
 \qquad
 \widehat A_\ell=\mathrm{RowNormalize}(\mathrm{OffDiag}(A_\ell)).
\end{equation}
每个尺度的 message-passing block 使用
\begin{equation}
 m_\ell^{(j)}=\widehat A_\ell h_\ell^{(j)},
\end{equation}
并显式把 $\Re(m)$、$\Im(m)$ 与 hidden state 一起送入更新网络。coarse hidden state 再 broadcast 回 fine edges，与 fine branch 融合后继续 fine message passing。

因此网络不再只依赖少量 local graph hops，而是同时获得 fine local physics 与长程 multiscale propagation。网络最终直接给出
\begin{equation}
 \Delta X_\theta=N_\theta^{\rm multi}(A,R)
 \in\mathbb C^{N_E\times N_{\rm rhs}}.
\end{equation}
Jacobi 仅作为输入尺度/reference，以及非有限或近零输出时的数值安全 fallback；它不是正式主求解器。

\subsection{Full-space residual seed distribution}
训练不需要 Maxwell solution label，但 residual seed 不再限制在 port RHS 的低维张成空间。每个 operator 默认包含三类 residual：
\begin{itemize}
  \item 所有物理 port RHS；
  \item 两个 full-edge random complex residual；
  \item 两个由 coarse edge groups 生成并 broadcast 回 fine space 的 multiscale smooth residual。
\end{itemize}
full-space random residual 用于覆盖一般 Krylov/preconditioner 输入方向；smooth residual 用于显式覆盖长程、低频误差模式。所有 seed 按物理 RHS 范数归一到可比较尺度，但训练损失仍使用相对 residual，因此不依赖绝对幅值。

后续 residual 完全由同一个神经网络产生：
\begin{align}
 R_0 &= R,\\
 \Delta X_k &= N_\theta^{\rm multi}(A,R_k),\\
 R_{k+1} &= R_k-A\Delta X_k.
\end{align}
默认共享权重 unroll 三步。

\subsection{最终 residual 主导的训练目标}
三步训练目标固定为
\begin{equation}
 L_{\rm EM}=0.1L_1+0.2L_2+0.7L_3,
 \qquad
 L_k=\frac{\lVert R_k\rVert_2^2}{\lVert R_0\rVert_2^2}.
\end{equation}
最终第 3 步 residual 明确占主要权重，前两步只负责保持稳定的逐步 residual reduction。每一步 residual 都通过真实 matrix-free Maxwell operator 更新。

\subsection{优化器与学习率调度}
默认物理 batch size 为 1，gradient accumulation 为 1，因此每个 operator sample 都触发一次 optimizer update。默认学习率 schedule 为
\begin{equation}
 2\times10^{-3}
 \rightarrow 10^{-3}
 \rightarrow 5\times10^{-4}
 \rightarrow 2.5\times10^{-4},
\end{equation}
使用 validation plateau 触发，每两 epoch 验证一次，plateau patience 为 8 次 validation，最小有效相对改善为 $5\times10^{-4}$。发生实际降 LR 时 early-stop stale 计数清零；只有长期没有有效下降才停止。

\subsection{推理与精度闭环}
推理首先连续应用共享 neural correction。每个直接 neural step 都以真实 residual 检查是否下降；不下降的列不会接受该步。

如果 neural rollout 尚未达到 $\varepsilon_{\rm EM}$，FGMRES 使用同一个 multiscale neural solver 作为可变 preconditioner，只闭合剩余误差。由于训练 residual 已覆盖 full-space random 与 smooth modes，FGMRES Arnoldi/Krylov residual 不再被视为训练分布之外的输入。

网络若输出 NaN/Inf 或近零退化方向，则该次 preconditioner 调用退化到 Jacobi，以避免数值故障；这不是另一条正式求解路径。在 \texttt{maxwell\_max\_iterations} 内真实 residual 仍未达到目标时必须明确报错，不能用 surrogate 或 silent fallback 返回答案。

\subsection{训练与 solver benchmark}
训练报告除 full-space train/validation/test residual loss 外，还记录 validation/test port-only residual loss 和 residual seed composition，并在 validation/test 上报告：
\begin{itemize}
  \item neural rollout 后 relative residual 的 median/p90/max；
  \item FGMRES closure iterations 与 restarts；
  \item neural rollout wall time 与总 solve wall time；
  \item true-residual success rate 与最大最终 residual。
\end{itemize}
因此模型是否有效最终由实际 PDE solve 指标判断，而不是只由神经 loss 判断。

\subsection{Joule 与 thermal ROM}
只有通过 Maxwell true-residual 检查后的完整场 $X$ 才允许进入 Joule 与阻抗计算。海水等体积导电区域使用
\begin{equation}
 q^{\rm volume}=\frac12\sigma |E|^2,
\end{equation}
线圈 AC resistance heating 作为物理项加入。

thermal ROM 保留，因为热扩散空间通常可压缩；thermal basis 的 rank 由真实 Joule anchor 与热方程 residual 自动决定。时间演化继续求解
\begin{equation}
 M_r(g)\dot a=-K_r(g)a+q_r(a,g,u),
\end{equation}
时间不是神经网络输入。

\subsection{禁止的耦合}
正式实现中不允许：
\begin{itemize}
  \item 用全局 Maxwell solution basis 或手工 Maxwell rank 作为神经载体；
  \item 用 polynomial coefficient、ILU、AMG 等传统预条件器取代神经网络主体；
  \item 用网络直接预测最终阻抗、Joule heat 或温度；
  \item 把时间作为黑箱网络输入绕过 thermal ODE；
  \item 用 domain probe、Gate、fast/general/legacy 模式切换另一套模型；
  \item 在未满足真实 Maxwell residual 时静默返回近似答案。
\end{itemize}

\subsection{验证与正确性边界}
正式数值检查至少覆盖：
\begin{itemize}
  \item fine/coarse sparse graph 均来自真实 Maxwell complex coupling；
  \item coarse edge groups 随尺度变粗且保留 edge orientation；
  \item full-space residual seed rank 超过 port RHS span；
  \item 网络输出维度是 full edge-space correction，而非全局系数；
  \item 三步 loss 权重为 $0.1/0.2/0.7$；
  \item 非有限/退化神经输出不会污染最终物理解；
  \item FGMRES closure 满足真实 full-space sparse residual；
  \item 保存/加载后 multiscale network config 与 solver steps 不变；
  \item Joule、阻抗只使用 corrected Maxwell field；
  \item thermal rank 由 residual 目标自动决定。
\end{itemize}

小 algebraic residual 只控制离散线性系统求解误差，并不自动保证连续 Maxwell 模型或空间离散误差足够小。固定背景分辨率、edge-space consistency、sub-cell geometry/source representation、材料模型和 thermal residual 仍需单独做收敛与物理验证。

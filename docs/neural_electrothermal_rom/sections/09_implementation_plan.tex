\section{实施路线与软件边界}

\subsection{唯一正式主链}
正式实现只保留一条生产主链：
\begin{equation}
\boxed{
 g
 \rightarrow \text{validated Maxwell truth snapshot}
 \rightarrow \{Z_{\rm field},H_j\}
 \rightarrow \text{neural low-dimensional surrogate}
 \rightarrow q(g,c)
 \rightarrow \text{true thermal ROM}
 \rightarrow a(t),T(t),Z(t).
}
\end{equation}
网络不承担 Maxwell field solve、时间积分或 thermal operator prediction。所有端口电流依赖通过结构化矩阵 contraction 解析进入。

\subsection{离线 truth-data 层}
离线物理层对每个几何完成：
\begin{enumerate}
  \item 几何合法性和 Physics Gate 检查；
  \item 组装冻结版本的 Maxwell operator 与端口 source；
  \item 求所有端口基响应 $X$；
  \item 计算 $Z_{\rm field}$、空间/模态 Joule tensors $H_j$；
  \item 验证 reciprocity、passivity、开放域功率平衡和 linear residual；
  \item 保存结构化 tensor label 及完整 audit metadata。
\end{enumerate}
truth solver 是确定性物理基础设施，不属于神经代理结构本身。

\subsection{tensor dataset}
数据文件至少保存：
\begin{itemize}
  \item canonical geometry parameters；
  \item $Z_{\rm field}$ 的独立复对称自由度；
  \item $H_j$ 的独立 Hermitian 自由度；
  \item geometry/train-validation-test split；
  \item mesh/domain/formulation/constitutive version；
  \item truth residual、power-balance、reciprocity 等 audit 指标。
\end{itemize}
任何基础物理版本变化都必须使 dataset signature 失效。

\subsection{输出压缩与 neural model}
只使用 training split 构造 output normalization 与 POD：
\begin{equation}
y\approx\bar y+U_K\beta.
\end{equation}
普通 residual MLP 学习
\begin{equation}
\beta_\theta:g\mapsto\R^K.
\end{equation}
模型文件必须持久化：
\begin{itemize}
  \item geometry encoding/normalization；
  \item output scaling；
  \item POD mean/basis；
  \item MLP weights；
  \item tensor structural schema；
  \item truth-dataset/physics version。
\end{itemize}

\subsection{结构化解码}
解码流程固定为
\begin{equation}
\beta_\theta
\rightarrow\hat y
\rightarrow
\{\widehat Z_{\rm field},\widehat H_j\}.
\end{equation}
解码器按构造恢复复对称/Hermitian 结构。模型 API 不允许绕过解码器直接把 unrestricted dense output 当作物理矩阵。

\subsection{在线 thermal engine}
对一个几何查询：
\begin{enumerate}
  \item 神经网络仅执行一次 geometry forward；
  \item 缓存 $\widehat Z_{\rm field},\widehat H_j$；
  \item 对 operating current $c$ 解析计算
  \begin{equation}
  q_{{\rm vol},j}=\operatorname{Re}(c^H\widehat H_jc);
  \end{equation}
  \item 根据 thermal state 更新真实 $R_{\rm wire}(a,g)$ 与 $q_{\rm wire}$；
  \item 使用真实 $M_r(g),K_r(g)$ 推进 ODE 或直接求 steady state；
  \item 输出
  \begin{equation}
  Z(a,g)=\widehat Z_{\rm field}(g)+R_{\rm wire}(a,g).
  \end{equation}
\end{enumerate}
同一几何的多个时间/电流查询复用同一组 neural EM tensors。

\subsection{thermal basis builder}
thermal basis 仍采用 residual-driven 自动增广，但 residual 必须来自真正在线 Galerkin projection。对每个 geometry/heat anchor，steady 与 dynamic residual 分别计算；worst residual 超过 target 时增广基。

rank 是达到目标 residual 后的结果，不作为用户手工调参。basis version 与生成它的 heat-anchor/truth-physics version 一同持久化。

\subsection{验证测试}
最低测试集合必须覆盖：
\begin{itemize}
  \item Maxwell mesh/domain convergence；
  \item source/material geometry perturbation continuity；
  \item port reciprocity/passivity；
  \item $P_{\rm in}=P_{\rm vol}+P_{\rm out}+P_{\rm wire}$；
  \item $\sum Q_{\rm vol}=\frac12E^HH_\sigma E$；
  \item arbitrary complex-current Hermitian Joule contraction；
  \item POD encode/decode and structural reconstruction；
  \item frozen validation/test $Z/H/q$ error；
  \item true Galerkin thermal residual；
  \item ETD/IMEX against high-accuracy thermal reference；
  \item end-to-end temperature/impedance trajectory audit。
\end{itemize}

\subsection{训练和推理接口原则}
用户层只需要两个概念流程：
\begin{itemize}
  \item \textbf{train：}复用或生成 validated truth tensor dataset，构建 POD，训练 geometry surrogate，保存统一模型；
  \item \textbf{predict：}加载模型，对 geometry 解码 EM tensors，执行结构化电流 contraction 与 thermal dynamics。
\end{itemize}
是否缓存 truth data、采用 memmap 或 out-of-core SVD 都属于内部性能实现，不改变理论接口。

\subsection{禁止重新引入的耦合}
正式主实现中不允许：
\begin{itemize}
  \item 网络直接学习时间轨迹；
  \item 网络直接把 current 当普通输入并重新学习 quadratic/phase law；
  \item 网络预测 $M_r,K_r$ 替代真实 thermal operators；
  \item 用不保持 Hermitian/reciprocal structure 的 unrestricted tensor output；
  \item 在 Physics Gate 失败的数据上继续优化 neural loss；
  \item 把 algebraic solve residual 当成 mesh/domain/model correctness 的替代品。
\end{itemize}

\subsection{实现顺序}
软件实施顺序由物理依赖决定：
\begin{enumerate}
  \item 先修并冻结 Physics Gate；
  \item 再生成可信 tensor snapshots；
  \item 再实现结构化 encode/POD/decode；
  \item 再训练 neural geometry surrogate；
  \item 最后接入 thermal ROM、时间积分和统一 predict API。
\end{enumerate}
该顺序不是分阶段改变架构，而是同一冻结架构的依赖顺序；任何上游物理版本改变都必须使下游训练数据和模型版本失效。

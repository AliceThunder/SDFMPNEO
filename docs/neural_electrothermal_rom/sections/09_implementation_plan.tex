\section{实施路线与软件边界}

\subsection{唯一正式主链}
正式实现只保留一条生产主链：
\begin{equation}
\boxed{
 g
 \rightarrow
 \begin{cases}
 \text{deterministic }\Phi(g),M_r(g),K_r(g),\\
 \text{neural }\{Z_{\rm field}(g),D_{\rm vol}(g),H_j(g)\}
 \end{cases}
 \rightarrow \text{exact current/circuit physics}
 \rightarrow \text{true thermal ROM}
 \rightarrow a(t),T(t),Z(t).
}
\end{equation}
网络不承担 Maxwell field solve、thermal-basis prediction、thermal operator prediction、时间积分或 circuit equations。

\subsection{第一层：validated spatial truth physics}
离线物理层首先冻结与神经网络无关的 Maxwell/Joule truth 定义：
\begin{enumerate}
  \item 几何合法性、physical wire/source regularization、terminal/source continuity 和 Physics Gate；
  \item 组装冻结版本的 Maxwell operator 与实值端口 source basis；
  \item 求所有端口基响应 $X(g)$；
  \item 计算 $Z_{\rm field}$、$D_{\rm vol}=X^HH_\sigma X$、完整 current-induced spatial Joule basis 与 wire/source spatial patterns；
  \item 从开放边界/PML 独立物理双线性型计算 $D_{\rm out}^{\rm phys}$；
  \item 验证 reciprocity、passivity、matrix power balance、linear residual、mesh/domain/formulation convergence；
  \item 保存后续 thermal canonical-mode construction 所需的物理信息与完整 audit metadata。
\end{enumerate}
truth outward power 不能通过 $\operatorname{Herm}Z-D_{\rm vol}$ 反定义后自证。

\subsection{第二层：canonical thermal mode library 与 geometry-aware basis generator}
不再构建一个跨整个 production geometry domain 的固定共享 basis。首版冻结三个固定语义 block：
\begin{equation}
\boxed{
\Phi(g)=
[\Phi_{\rm bg},\;\mathcal T_{\rm tx}(g)\Psi_{\rm tx},\;\mathcal T_{\rm rx}(g)\Psi_{\rm rx}].
}
\end{equation}
$\Phi_{\rm bg}$ 负责全局/慢扩散，$\Psi_{\rm tx}$ 与 $\Psi_{\rm rx}$ 在各自 canonical local frame 中定义。首版 $\mathcal T_p(g)$ 只做 rigid translation/rotation 与固定的守恒插值。所有 geometry 上 block 顺序、列数和 mode index 的物理语义完全一致。

canonical modes 仍可由 resolvent anchors 自动选 rank。对 source 或 initial-condition anchor：
\begin{equation}
A_su=b,\qquad A_s=K+sM\succ0,
\end{equation}
理论误差指标为
\begin{equation}
\boxed{
\eta_s^2
=\frac{r^TA_s^{-1}r}{b^TA_s^{-1}b}
=\frac{\|u-\tilde u\|_{A_s}^2}{\|u\|_{A_s}^2}.
}
\end{equation}
但 rank enrichment 的目标是增加 background/local canonical modes，而不是把不同全局位置的热点逐个加入同一个固定 span。

最短 resolvent time scale 必须与 thermal mesh 可解析尺度一致。对扩散率 $\alpha$，若 $\sqrt{\alpha\tau}$ 远小于网格可解析尺度，则该 anchor 主要编码离散 source placement，不默认作为 production rank target。当前实现优先覆盖可解析的短/中时尺度并加入 $s=0$ steady anchor；长时间查询依赖 ODE 连续积分，而不是为每个大时间值额外增加 resolvent anchor。

basis-generator version 必须记录：canonical mode blocks、local frames、transport/interpolation rule、mode ordering、time-scale selection rule、source/initial-condition families、thermal operators/boundaries、cross-space transfer、wire-temperature functional 和 truth-physics version。

\subsection{第三层：逐 geometry 构造 thermal ROM 与 tensor labels}
canonical library 冻结后，对每个 geometry $g$：
\begin{enumerate}
  \item 确定性构造 $\Phi(g)$；
  \item 检查 $\Phi(g)$ 满列秩及其 Gram/reduced-operator conditioning；
  \item 组装
  \begin{equation}
  M_r(g)=\Phi(g)^TM_T(g)\Phi(g),\qquad
  K_r(g)=\Phi(g)^TK_T(g)\Phi(g);
  \end{equation}
  \item 对每个 canonical mode $\phi_j(g)$ 用与 $H_\sigma$ 相同 FE basis/quadrature 组装
  \begin{equation}
  [W_j(g)]_{mn}=\int_\Omega\sigma(x;g)\phi_j(x;g)N_m\cdot N_n\,\mathrm dx;
  \end{equation}
  \item 得到
  \begin{equation}
  \boxed{H_j(g)=X(g)^HW_j(g)X(g)};
  \end{equation}
  \item 从当前 $\phi_j(g)$ 的 conductivity-loss support 确定性计算 $\phi_j^{\min}(g),\phi_j^{\max}(g)$；
  \item 验证
  \begin{equation}
  \phi_j^{\min}(g)D_{\rm vol}(g)
  \preceq H_j(g)
  \preceq\phi_j^{\max}(g)D_{\rm vol}(g).
  \end{equation}
\end{enumerate}

最终 neural tensor dataset 保存 fixed-dimensional canonical tensor schema：geometry、$Z_{\rm field}$、$D_{\rm vol}$、$H_1\ldots H_r$、geometry-dependent modal bounds 与 neural `train/validation/test/internal-audit` split。这个 dataset 内部的 `audit` split 只用于 tensor surrogate 诊断，不等于最终 production release set。

完全 held-out release geometries 不写入上述 dataset，也不参与 POD、normalization、early stopping、canonical rank 或 transport tuning；它们在 surrogate training 完成后由独立 sampling stream 生成，只用于最终 Go/No-Go。

\subsection{输出压缩与 neural model}
只使用 neural training split 构造 output normalization 与 POD：
\begin{equation}
y\approx\bar y+U_K\beta,
\qquad
\beta_\theta:g\mapsto\R^K.
\end{equation}
模型文件必须持久化 geometry encoding、$\mathcal G_{\rm prod}$、POD、MLP、tensor schema、joint feasible decoder、canonical mode ordering、thermal basis-generator version 与 truth-physics version。

\subsection{结构化解码与 geometry-dependent 联合可行层}
网络先解码出 $\widetilde Z,\widetilde D,\widetilde H_j$。对当前 geometry，由 basis generator 提供 $\phi_j^{\min/\max}(g)$，再施加
\begin{equation}
\widehat D_{\rm vol}\succeq0,
\qquad
\operatorname{Herm}(\widehat Z_{\rm field})-\widehat D_{\rm vol}\succeq0,
\end{equation}
以及
\begin{equation}
\boxed{
\phi_j^{\min}(g)\widehat D_{\rm vol}
\preceq\widehat H_j
\preceq\phi_j^{\max}(g)\widehat D_{\rm vol}.
}
\end{equation}
reactive reciprocal block 不因耗散投影而改变；所有 projection correction 必须保存/报告。

\subsection{在线 thermal/circuit engine}
对一个静态 geometry 查询：
\begin{enumerate}
  \item 检查 $g\in\mathcal G_{\rm prod}$ 与 geometry feasibility；
  \item 确定性生成 $\Phi(g)$、$M_r(g)$、$K_r(g)$、modal bounds 与 wire-temperature functionals；
  \item neural geometry forward 只执行一次并缓存 $\widehat Z_{\rm field},\widehat D_{\rm vol},\widehat H_j$；
  \item current-controlled 模式使用给定 $c$；circuit-controlled 模式由确定性 circuit equations 求 $c(a,t)$；
  \item 解析计算
  \begin{equation}
  q_{{\rm vol},j}=\frac12\operatorname{Re}(c^H\widehat H_jc),
  \qquad
  P_{\rm vol}=\frac12c^H\widehat D_{\rm vol}c;
  \end{equation}
  \item 更新真实 wire resistance/heat；
  \item 使用 $M_r(g),K_r(g)$ 推进 reduced ODE 或求稳定 steady state；
  \item 输出 $T=T_{\rm amb}+\Phi(g)a$、$Z(a,g)$ 与功率诊断。
\end{enumerate}

长时间有限时刻通过同一 reduced ODE 连续/链式积分到达；不需要为每个查询 horizon 重新训练或构建长时间专用 basis。

若 geometry 在 query 中随时间变化，则必须重新推导运动 basis dynamics。因为
\begin{equation}
\theta=\Phi(g(t))a(t),
\end{equation}
有额外项 $\Phi^TM_T\dot\Phi\,a$；当前静态 geometry engine 不支持忽略该项的直接复用。

\subsection{验证测试}
最低测试集合必须覆盖：
\begin{itemize}
  \item Maxwell mesh/domain/formulation convergence、source regularization、terminal/source continuity 与独立 Poynting balance；
  \item canonical thermal transport 的 rigid-motion correctness、interpolation conservation 与 geometry perturbation continuity；
  \item $\Phi(g)$ full-rank、$M_r(g),K_r(g)\succ0$ 与 conditioning；
  \item $W_j(g)$ direct assembly、modal contraction 与 geometry-dependent Loewner bounds；
  \item thermal resolvent error 按 geometry/source/block/time-scale 分解，并同时报告绝对 anchor energy/power；
  \item completely-held-out geometry 上 full thermal versus geometry-aware ROM 的短时、中间、长时和 steady trajectory audit；
  \item initial-condition projection/homogeneous-response、wire-temperature functional、$T_{\min}/T_{\max}$；
  \item frozen validation/test $Z/D/H/q$ error、projection correction 与 implied-vs-physical outward-loss error；
  \item production ETD/IMEX against high-accuracy reference on the same surrogate reduced ODE；
  \item current-controlled 和 circuit-controlled end-to-end audit；
  \item uncertified artifact 不得由 production predict 入口加载。
\end{itemize}

特别地，如果 held-out error 随 geometry translation/rotation 激增，不优先通过增加大量 global thermal modes 修补；应先检查 transport/local-frame 设计。若 rigid transport 后主要剩余误差与尺寸变化相关，再考虑 deterministic scale-aware extension。

\subsection{训练和推理接口原则}
用户层仍只有两个概念流程：
\begin{itemize}
  \item \textbf{train：}验证 truth physics，构建/冻结 canonical thermal library 与 basis generator，逐 geometry 生成 tensor labels，训练 geometry surrogate，执行 completely-held-out release Go/No-Go；只有全部通过才保存统一 production model；
  \item \textbf{predict：}加载已通过 release metadata 验证的 production model，检查 production domain，确定性生成 geometry-aware thermal ROM，对 geometry 解码 EM tensors，执行 current/circuit physics 与 thermal dynamics。
\end{itemize}

\subsection{禁止重新引入的耦合}
正式主实现中不允许：
\begin{itemize}
  \item 网络直接学习时间轨迹；
  \item 网络预测 $\Phi(g)$、$M_r(g)$ 或 $K_r(g)$；
  \item 用一个固定全局 basis 通过堆 mode 记忆所有移动热源位置；
  \item 网络把 current、voltage/load 当普通输入重新学习已知 quadratic/circuit law；
  \item 用 unrestricted matrices 代替 reciprocal/Hermitian/energy-feasible output；
  \item thermal basis-generator 尚未冻结时定义最终 $H_j(g)$ labels；
  \item 用随机 current sampling 代替完整 Hermitian current-source span；
  \item 在 diffusion length 远小于 thermal mesh resolution 时盲目把极短 time-scale anchor 当成 production rank target；
  \item 用任意 nonlinear root 代替稳定且与初值语义一致的 steady state；
  \item 在 Physics Gate 或 final release Gate 失败的数据/模型上继续发布 production artifact。
\end{itemize}

\subsection{实现顺序}
软件实施顺序由物理依赖严格决定：
\begin{enumerate}
  \item 修并冻结 pre-basis spatial truth Gate；
  \item 生成/验证 Maxwell/Joule/source truth physics；
  \item 构建 canonical background/TX/RX thermal mode library；
  \item 冻结 deterministic $g\mapsto\Phi(g)$ generator、固定 mode ordering 与 time-scale policy；
  \item 逐 geometry 组装 $M_r/K_r$、modal bounds 与最终 $Z/D_{\rm vol}/H_j$ tensor dataset；
  \item 运行依赖冻结 basis/tensor 的 post-basis Physics Gate；
  \item 实现 structure encode/POD/joint feasible decode；
  \item 训练 neural geometry surrogate；
  \item 接入 geometry-aware thermal/circuit engine 和统一 predict API；
  \item 用完全 held-out geometry 做 full thermal/tensor/current/circuit/time-integrator release audit；
  \item 全部 release Gate 通过后发布 production artifact。
\end{enumerate}
任何上游物理、canonical mode library 或 basis-generator 版本改变都必须使下游 tensor labels、POD 和模型版本失效。
